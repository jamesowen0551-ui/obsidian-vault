# Format Specification — 研究专题笔记格式规范

本文档定义研究专题（Obsidian vault）中所有 Markdown 笔记的统一格式规范。

## 一、YAML Frontmatter

每篇笔记顶部必须包含 YAML frontmatter，用 `---` 包裹。

### 单篇文献笔记

```yaml
---
title: 作者 (年份) 论文标题
authors: Author A, Author B
year: YYYY
journal: Journal Name, Vol(X), pp. NNN–NNN
created: YYYY-MM-DD
tags:
  - 领域标签1
  - 领域标签2
  - 文献笔记
---
```

### 专题索引 (MOC)

```yaml
---
title: 专题名称
created: YYYY-MM-DD
tags:
  - MOC
  - 领域标签1
  - 领域标签2
---
```

### 综合短评

```yaml
---
title: 短评标题
created: YYYY-MM-DD
type: 综合短评
tags:
  - 综合短评
  - 领域标签1
---
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `title` | string | ✅ | 笔记标题 |
| `authors` | string | 文献笔记必填 | 作者姓名 |
| `year` | number | 文献笔记必填 | 发表年份 |
| `journal` | string | 文献笔记必填 | 期刊/出版社 |
| `created` | date | ✅ | 笔记创建日期 `YYYY-MM-DD` |
| `tags` | list | ✅ | 标签列表 |
| `type` | string | 短评必填 | `综合短评` |
| `status` | string | 可选 | `PDF未获取` 等状态标注 |

## 二、Callout 类型

Obsidian callout 使用 `> [!type]` 语法。

| Callout | 用途 | 出现位置 |
|---------|------|---------|
| `[!abstract]` | 一句话总结论文/专题核心发现 | 笔记开头 |
| `[!info]` | 版本说明、获取状态、PDF链接 | abstract 之后 |
| `[!question]` | 综合短评要回答的核心问题 | 短评开头 |
| `[!warning]` | 版权受限、获取困难等提醒 | info 替代 |

### Abstract Callout 规范

```markdown
> [!abstract] 一句话总结
> 用一句话精确概括本文的核心贡献或发现，控制在 80 字以内。
```

### Info Callout 规范

```markdown
> [!info] 版本说明
> - 原文期刊/会议信息
> - PDF 获取状态（已下载 / 版权受限 / 建议获取途径）
> - 工作论文版本 vs 正式发表版本的区别
```

## 三、章节结构

### 单篇文献笔记标准章节

```markdown
## 研究问题与核心发现

## 理论框架

## 实证方法（如适用）

## 关键概念速查

| 概念 | 本文中的含义 |
| --- | --- |
| 术语1 | 定义... |

## 对"用户研究主题"研究的含义

## 理论定位

## 局限与待跟进问题

## 相关笔记

- [[相关笔记1]]
- [[相关笔记2]]
```

### 专题索引标准章节

```markdown
# 专题名称

> [!abstract] 专题概览
> 用一段话概括本专题的研究线索和核心问题。

---

## 主题一：...

### 📖 核心笔记

### 📄 必读文献

### 📚 延伸阅读

### 💬 相关对话存档

---

## 主题二：...

## ✅ 待办

## ✍️ 综合短评

## 🔗 相关
```

### 综合短评标准章节

```markdown
# 短评标题

> [!question] 要回答的问题
> 明确写出要回答的核心问题。

**一句话结论：** ...

---

## 一、现象/事实核对

## 二、机制对比

## 三、统一视角

## 四、实践含义

## 五、开放问题

## 相关笔记
```

## 四、Wiki 链接规范

使用 Obsidian wiki link 语法 `[[文件名|显示文本]]`。

### PDF 链接

```markdown
原文：[[PDF文件名.pdf|原文 PDF]]
```

### 笔记间链接

```markdown
- [[文件名|显示标题]]
```

### 相关笔记区块

每篇文献笔记末尾必须包含 "相关笔记" 区块，链接到同专题的其他笔记：

```markdown
## 相关笔记

- [[Werner_1997_详细笔记|Werner (1997) 信用分解定理]]
- [[BIS_WP381_详细笔记|Cecchetti & Kharroubi (2012) ...]]
```

## 五、数学公式

使用标准 LaTeX 语法，用 `$` 包裹行内公式，`$$` 包裹行间公式。

```markdown
行内：$C \cdot V = P \cdot Q$

行间：
$$
\frac{\Delta C_R}{C_R} = \frac{\Delta (P_R Y)}{P_R Y}
$$
```

## 六、表格规范

| 对齐 | 语法 |
|------|------|
| 左对齐 | `:---` |
| 右对齐 | `---:` |
| 居中 | `:---:` |

表格后必须跟空行再开始下一段。

## 七、命名规范

### 文件命名

| 类型 | 格式 | 示例 |
|------|------|------|
| 单篇文献 | `作者_年份_详细笔记.md` | `Werner_1997_详细笔记.md` |
| 专题索引 | `00 专题名称.md` | `00 股债相关性与A股因子研究.md` |
| 综合短评 | `综合短评 标题.md` | `综合短评 反转效应与股债冲击不对称.md` |
| 文献清单 | `文献清单.md` | `股债相关性文献清单.md` |
| PDF 文件 | `作者_年份_标题.pdf` | `Werner_1997_Quantity_Theorem.pdf` |

### 标签命名

- 使用中文或英文，保持一致
- 避免过于细分的标签（如不要用 `Campbell2020` 作为标签）
- 标准标签：`文献笔记`, `MOC`, `综合短评`, `文献清单`
