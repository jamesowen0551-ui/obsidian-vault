# A Turbulent Exit

- **作者**：Zoltan Pozsar, James Sweeney
- **出处**：Credit Suisse, Global Money Notes #2
- **日期**：2015-08-28
- **原文**：[[A Turbulent Exit.pdf]]

## 核心论点

美联储从零利率下限的历史性首次加息（liftoff）将是史无前例的，原因有三：

1. 将使用**新工具**（IOER + 隔夜 RRP）加息；
2. 加息引发的岸上与离岸**资金流量**将远超以往加息周期；
3. 加息发生在被 **Basel III 彻底重新设计**的金融体系中——银行资产负债表首次在加息周期中接受流动性与融资规则的压力测试。

无论美联储沟通多么透明，新工具 + 新体系的组合可能纯粹出于"机械"原因在货币、外汇和国债市场引发动荡。

## 主要预测

1. 加息当天美联储将启用**全额配售（full allotment）o/n RRP 工具**；
2. 联邦基金有效利率将落在约 **35 bp**，有上行风险；
3. 3 个月 Libor 将落在约 **55 bp**，上行风险明显；
4. 加息利好部分银行、损害另一些银行——"水涨不会皆船高"；
5. 存款流动迫使银行校准 HQLA 组合，**国债曲线 3–5 年段**波动率可能飙升；
6. 全额 RRP 可能加速外汇储备管理者**从欧元转向美元**。

## 关键框架：RRP 作为"货币胡佛大坝"

- 简单方案（发行"美联储票据"置换超额准备金）因《联邦储备法》不允许而不可行；
- RRP 不是新工具，但这次用法不同：固定利率而非固定规模、对手方是货币基金而非交易商、置换的是准备金而非债券；
- 大坝意象：美联储资产负债表规模不变（河还在），但负债结构从"银行持有准备金"重新分配为"货币基金持有 RRP"——加息后可能有 2 万亿美元存款从银行流向货币基金。
