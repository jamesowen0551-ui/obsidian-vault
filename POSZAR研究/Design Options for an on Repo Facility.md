# Design Options for an o/n Repo Facility

- **作者**：Zoltan Pozsar
- **出处**：Credit Suisse, Global Money Notes #25
- **日期**：2019-09-09（回购危机爆发前一周！）
- **原文**：[[Design Options for an on Repo Facility.pdf]]

## 核心论点

美联储操作框架的根本缺陷：隔夜利率目标区间**只在下限有工具把守**（o/n 逆回购），**上限无人把守**。解决方案是设立隔夜回购便利（standing repo facility, SRF）：

- 定价在 o/n RRP 利率**之上 25bp**；
- 对大型全球银行**无污名（without stigma）**开放；
- 明确目标是**让抵押品与准备金等价**——"均衡器"（equalizer）火箭筒。

## "德拉吉式"品质

这种工具会有重大市场影响而市场实际上不需要用它：银行目前持有大量**预防性准备金**，主要因为危机中债券变现不确定；若 SRF 使变现容易且有保障，预防性准备金就不再必要——银行可把准备金卖出去，只在危机时才动用美联储。**两全其美：融资条件放松而美联储资产负债表不扩张**。

## 结构与机制

- **Part I：层级为核心**。回购市场不是一个市场一个利率，而是多个分段的集合，由交易商资产负债表撮合；现金贷方（FICC 会员与否，如货币基金可用 o/n RRP）、抵押品供方各有层级，你借/贷的利率取决于你在层级中的位置；
- **Part II**：回购市场如何处理超额准备金与超额抵押品的失衡，银行乃至美联储如何最终吸收这些失衡；
- **Part III**：两种定价方案 + 三种设计方案，结论是面向银行、以"抵押品=准备金"为目标的方案最优；
- **Part IV**：市场影响；资产购买应是 SRF 的**补充而非替代**。

## 障碍与替代

绿灯不在纽约联储而在监管方——副主席 Quarles 偏好 HQLA 组合中持有准备金而非债券。若无"均衡器火箭筒"，就只能继续降息，因为其他设计在曲线倒挂时会有"变现过多国债"的风险。若 SRF 在酝酿，交易是**收（receive）交叉货币基差**。

## 阅读价值

回购危机前夜的预言书：一周后（2019-09-17）回购利率暴涨验证了全文逻辑；美联储 2021 年才推出 SRF，设计思路与此文高度重合。
