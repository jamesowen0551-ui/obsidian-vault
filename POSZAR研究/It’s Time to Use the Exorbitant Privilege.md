# It's Time to Use the Exorbitant Privilege

- **作者**：Zoltan Pozsar
- **出处**：Credit Suisse, Global Money Notes #21
- **日期**：2019-03-25
- **原文**：[[It’s Time to Use the Exorbitant Privilege.pdf]]

## 核心论点

缩表不会马上结束、隔夜回购便利（SRF）尚需时日设计——但**帮助是现在就需要**。缩表持续消灭准备金、恶化银行体系的日内流动性状况，而 12 月 31 日的年末转换已证明某些日子日内流动性已是严重约束。**给外国 RRP 工具设上限（capping）可立即向银行体系注入约 2000 亿美元准备金**，改善日内流动性、缓解季末压力，为美联储设计新回购工具赢得宝贵时间。

## 外国 RRP 工具的制度细节

- 历史比三方回购市场还长，因此以**双边方式结算**——早上 8:30 返现金（而非三方回购的下午 3:30），故在 Basel III 时代它提供宝贵的**日内流动性服务**；
- 历来支付市场利率（现在由 SOFR 定价流程推导），且**历来有额度上限**——量价双重限制确保它不影响市场；
- **2015 年初被取消上限**后，从无人问津变成"你从未听说过的最重要政策工具"；其条款不公开，类似银行与其机构客户间的私密账户安排。

## 政策逻辑

- 设上限将提高外国央行对国库券的需求、增加其在 FX 互换市场贷出美元，缓解使收益率曲线倒挂的**安全资产过剩（safe asset glut）**；
- 2015 年美联储曾用它缓解安全资产**短缺**，如今为何不愿用它缓解过剩？
- 150 场客户会议中唯一听到的反对理由是"不想惹外国央行不高兴"——Pozsar 借德斯坦（"嚣张特权"命名者）反讽：**是时候动用这份嚣张特权了**。

## 阅读价值

提出以外国 RRP 上限作为"以空间换时间"的紧急工具，延续 GMN#4 对该隐秘工具的持续追踪，数月后 2019 年回购危机验证其对准备金稀缺的诊断。
