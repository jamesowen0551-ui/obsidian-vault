好问题！简单来说：

**Memory（记忆）** 是关于"你"的。它记录的是我们过去对话中积累的关于你的信息——比如你的工作背景、兴趣爱好、偏好习惯等。这些信息帮助我在新对话中更好地理解你的语境，不用每次都重新介绍自己。你可以让我记住或忘记某些事情，也可以在设置里管理。

**Skills（技能）** 是关于"怎么做事"的。它们是预置的操作指南，告诉我在创建特定类型文件时应该遵循什么流程和最佳实践——比如怎么生成 .docx、.pptx、.xlsx、PDF 等。每次我需要创建文件之前，会先读取对应的 Skill 文件来确保输出质量。

打个比方：Memory 像是我对老朋友的了解（"Ada 做利率债研究、弹肖邦"），Skills 像是我手边的工具说明书（"生成 Word 文档时要这样操作"）。一个面向人，一个面向任务。
