## 4.0 引言：非线性到底"非"在哪里

**非线性序列**：若 $x_t$ 的生成机制由当期和过去的"冲击与新息进入方式"决定、且该方式不是线性叠加，则称 $x_t$ 为非线性时间序列。

线性序列总可以写成 Wold 分解形式：
$$x_t = \mu + \sum_{i=0}^{\infty}\psi_i a_{t-i},\qquad \psi_0 = 1 \tag{4.1}$$
其中 $a_t$ 是 iid 新息。**线性模型只有一个平衡点（均衡）**，预测函数随预测期 horizon 增长要么趋于常数（平稳情形）要么线性发散。而**非线性模型可以有多个均衡**，因而能表现出线性模型永远无法产生的现象：

- **极限环（limit cycles）**：不靠随机冲击也能自我维持的周期运动；
- **振幅依赖的频率**：周期长短随振幅变化；
- **跳跃与不对称性**（如失业率"升得快、降得慢"）；
- **混沌（chaos）**：确定性系统产生看似随机的轨道，对初始条件极端敏感。

> 关键提醒：**平稳性在非线性模型中变得复杂**——AR 系数小于 1 不再充分。需要"几何遍历性"（geometric ergodicity）等更精细的条件。而且非线性模型**没有预测解析式**，horizon > 1 时只能靠模拟（参数自助法，见 4.4）。

## 4.1 非线性模型大家族

### 4.1.1 双线性模型（Bilinear Model）

Granger & Andersen (1978) 提出，形式：
$$x_t = c + \sum_{i=1}^{p}\phi_i x_{t-i} - \sum_{j=1}^{q}\theta_j a_{t-j} + \sum_{i=1}^{m}\sum_{j=1}^{s}\beta_{ij}x_{t-i}a_{t-j} + a_t \tag{4.4}$$

即在 ARMA($p,q$) 上**追加"状态 × 新息"的乘积项** $\beta_{ij}x_{t-i}a_{t-j}$。这正是"双线性"的含义：固定 $x$ 对 $a$ 线性，固定 $a$ 对 $x$ 线性，但联合非线性。

**例 4.1（等权指数，CRSP equal-weighted index 月对数收益）**：拟合双线性模型
$$x_t = 0.011 + 0.162x_{t-1} - 0.494x_{t-2} - 0.019a_t - 0.332x_{t-1}a_{t-1} - 0.012x_{t-2}a_{t-1} \tag{4.6}$$
（简化示意，书中有完整估计与残差方差）。与纯 AR 模型相比，双线性项显著；但用平方残差 Q 统计量检验后，双线性模型的改善有限——**双线性模型处理条件均值非线性，但对波动聚集（条件异方差）无能为力**，这是它的主要局限，也是 GARCH 类模型更流行的原因。

### 4.1.2 门限自回归模型（TAR / SETAR）★ 本章最重要

**动机**：分段线性逼近——把状态空间按门限切成几个区间（regime，机制），每个机制内用普通线性 AR。Tong (1978, 1990) 的 SETAR（self-exciting TAR，自激励门限自回归）用**序列自身的滞后值** $x_{t-d}$ 当门限变量。

**k 机制 TAR 模型**：
$$x_t = \phi_0^{(j)} + \phi_1^{(j)}x_{t-1} + \cdots + \phi_p^{(j)}x_{t-p} + a_t^{(j)},\quad \text{当 } \gamma_{j-1} \le x_{t-d} < \gamma_j \tag{4.9}$$
其中 $\gamma_0=-\infty < \gamma_1 < \cdots < \gamma_k = \infty$ 是门限，$d$ 是延迟参数（delay）。参数：每个机制一组 AR 系数 $\{\phi_i^{(j)}\}$ 和新息方差 $\sigma_j^2$。

**平稳性条件（2 机制 AR(1) 情形）**：记两机制系数为 $\phi_1^{(1)}, \phi_1^{(2)}$，几何遍历的充分条件是
$$\phi_1^{(1)} < 1,\qquad \phi_1^{(2)} < 1,\qquad \phi_1^{(1)}\phi_1^{(2)} < 1$$
注意：**允许单个系数 $\ge 1$（局部爆炸），只要另一机制把它"拉回来"**——例如 $\phi^{(1)}=1.5$、$\phi^{(2)}=0.5$，乘积 $0.75<1$ 仍可遍历。这是线性模型绝对没有的性质。

**例：2 机制 TAR(1)（式 4.8）**
$$x_t = \begin{cases} -1.5x_{t-1} + a_t & x_{t-1} < 0 \\ 0.5x_{t-1} + a_t & x_{t-1} \ge 0 \end{cases}$$
该模型有三点深刻性质：
1. **无常数项，但无条件均值非零**（约 $-0.33$ 量级）——非线性模型中常数项≠均值；
2. **不是时间可逆的**：时间倒放后动态结构不同（线性高斯序列必时间可逆，故时间不可逆是检验非线性的一个角度）；
3. 能在负机制产生大幅波动、正机制温和回复，表现出**不对称周期**。

**例 4.2（美国季度失业率）**：差分序列 $y_t = x_t - x_{t-1}$ 拟合两机制 TAR：
$$\Delta x_t = \begin{cases} 0.01 + 0.73\Delta x_{t-1} + 0.10\Delta x_{t-2} + a_{1t} & \Delta x_{t-2} \le 0.1 \\ 0.18 + 0.80\Delta x_{t-1} - 0.56\Delta x_{t-2} + a_{2t} & \Delta x_{t-2} > 0.1 \end{cases} \tag{4.10/4.11}$$
（门限变量为 $\Delta x_{t-2}$，门限 0.1，机制 1 有 460 个观测、机制 2 有 262 个）。经济解释：失业率**轻微变化时近似 AR(1)（稳定经济）**；**大幅跳升（≥0.1，衰退期、政府干预多发期）时 AR(2) 带复特征根——产生周期性振荡**。详见 4.5 应用节。

**例 4.3（IBM 日收益，AR(2)–TAR–GARCH(1,1)）**：把门限思想用到**波动方程**：
$$r_t = 0.033 - 0.023r_{t-2} + a_t,\quad a_t = \sigma_t\epsilon_t \tag{4.12}$$
$$\sigma_t^2 = 0.075 + 0.041a_{t-1}^2 + 0.903\sigma_{t-1}^2 + \begin{cases} 0.058a_{t-1}^2 + 0.070\sigma_{t-1}^2 & a_{t-1} < 0 \\ 0 & a_{t-1}\ge 0 \end{cases} \tag{4.13/4.14}$$
即以 $a_{t-1}<0$ 为门限（坏消息），坏消息同时抬高 $a^2$ 项和 $\sigma^2$ 项的系数。与第3章 GJR-GARCH 比较：TAR-GARCH 让杠杆效应**不仅作用于新息平方项，也作用于持久性项**，拟合更好（残差平方 Q 统计量更干净）。

### 4.1.3 平滑转移自回归（STAR）

TAR 的机制切换是**硬切换**（指示函数），STAR 把它换成**连续的平滑转移函数**：
$$x_t = c_1 + \sum_{i=1}^{p}\phi_{1,i}x_{t-i} + F\!\left(\frac{x_{t-d}-\Delta}{s}\right)\left(c_2 + \sum_{i=1}^{p}\phi_{2,i}x_{t-i}\right) + a_t \tag{4.15}$$
常用 logistic 转移函数 $F(z) = 1/(1+e^{-z})$；$\Delta$ 是转移位置（相当于门限），$s$ 控制平滑程度——$s\to 0$ 时退化为 TAR 硬切换，$s\to\infty$ 时退化为线性 AR。

**估计难点**：$\Delta$ 和 $s$ 与转移层系数乘在一起，**难以识别，t 值往往只有 1 左右**。实际做法：把转移参数固定（如固定 $s$ 很大或直接乘以 1000 做成近似开关）。

**例 4.4（3M 公司月收益 STAR–ARCH(2)）**：
$$r_t = 0.0148 + a_t,\quad a_t = \sigma_t\epsilon_t$$
$$\sigma_t^2 = \left(0.003 + 0.205a_{t-1}^2 + 0.092a_{t-2}^2\right) + \frac{0.001 - 0.239a_{t-1}^2}{1+\exp(-1000\,a_{t-1})} \tag{4.16/4.17}$$
转移参数固定为 1000（近似硬切换于 $a_{t-1}=0$）。含义：**坏消息时 $\sigma_t^2 \approx 0.004 - 0.034a_{t-1}^2 + 0.092a_{t-2}^2$（系数为负、异乎寻常），好消息时是正常 ARCH(2)**——再次说明金融市场波动对消息方向高度不对称。

### 4.1.4 马尔可夫转换模型（MSA, Markov Switching）★

**与 SETAR 的根本区别**：
- **SETAR**：机制由**可观测的** $x_{t-d}$ **确定性地**决定；
- **MSA**：机制由**不可观测的隐马尔可夫链** $s_t$ **随机地**决定。

两状态 MSA：
$$x_t = \begin{cases} c_1 + \sum_{i=1}^p \phi_{1,i}x_{t-i} + a_{1t} & s_t = 1 \\ c_2 + \sum_{i=1}^p \phi_{2,i}x_{t-i} + a_{2t} & s_t = 2 \end{cases} \tag{4.18}$$
转移概率：$P(s_t=2|s_{t-1}=1) = w_1$，$P(s_t=1|s_{t-1}=2) = w_2$。**状态 $i$ 的期望持续期 = $1/w_i$**（几何分布均值），可直接解释为经济周期长度。

**估计**：Hamilton (1989, 1990) 的 EM 算法（滤波+平滑递推）或 McCulloch & Tsay (1994) 的 MCMC。

**例 4.5（美国实际 GNP 季度增长率，表 4.1）**：Hamilton 经典应用。MCMC 估计结果：
- **状态 1（扩张）**：均值增长 **0.965%**，期望持续 **11.31 个季度**（$w_1\approx 0.088$）；
- **状态 2（收缩）**：均值增长 **−1.288%**，期望持续 **3.69 个季度**（$w_2\approx 0.271$）。

两个状态与 NBER 经济周期日期高度吻合——MSA 把"经济周期"内生地从数据里识别了出来，这是它在宏观经济学中流行的原因。

### 4.1.5 非参数方法

**思想**：不预设函数形式，直接用数据"平滑"估计条件均值 $\mu(x)$ 与条件波动 $\sigma(x)$：
$$\mu(x) = E(x_t|x_{t-1}=x),\qquad \sigma^2(x) = E[(x_t-\mu(x))^2|x_{t-1}=x] \tag{4.19/4.20}$$

**核回归（Nadaraya–Watson 估计）**：
$$\hat\mu(x) = \frac{\sum_{t=1}^{T} K_h(x - x_{t-1})\,x_t}{\sum_{t=1}^{T} K_h(x-x_{t-1})} \tag{4.23}$$
$K_h(\cdot)$ 是带宽为 $h$ 的核函数，常用：
- **高斯核**：$K(x) = \frac{1}{\sqrt{2\pi}}\exp(-x^2/2)$
- **Epanechnikov 核**：$K(x) = \frac{3}{4}(1-x^2)$（$|x|\le1$，其余为 0，效率最优）

**带宽选择**（bias–variance 权衡：$h$ 大→方差小偏差大；$h$ 小→反之）：
- **Plug-in（正态参考法则）**：高斯核 $h = 1.06\,s\,T^{-1/5}$；Epanechnikov 核 $h = 2.34\,s\,T^{-1/5}$（$s$ 为样本标准差）；
- **留一交叉验证**：$CV(h) = \frac{1}{T}\sum_{t=1}^{T}[x_t - \hat\mu_{-t}(x_{t-1})]^2$，选最小化 CV 的 $h$。

**局部线性回归**（修正核回归的边界偏差）：在每个 $x$ 处解加权最小二乘
$$\min_{\alpha,\beta}\sum_{t=1}^{T} K_h(x-x_{t-1})\big[x_t - \alpha - \beta(x_{t-1}-x)\big]^2 \tag{4.24}$$
$\hat\alpha$ 即 $\hat\mu(x)$；Fan (1993) 证明局部线性有 minimax 效率。lowess（Cleveland 1979）是其稳健版本。

**例 4.6（3 个月期国库券利率）**：对利率一阶差分做 lowess 平滑，估计漂移函数 $\mu(\cdot)$ 与波动函数 $\sigma(\cdot)$：漂移在利率低时**小正**、利率高时**明显为负**——**均值回归的非参数证据**；波动随利率水平上升。这是第 8 章连续时间利率模型（CIR 等）的非参数预演。

### 4.1.6 函数系数自回归（FAR）

$$x_t = \phi_0(x_{t-d}) + \phi_1(x_{t-d})x_{t-1} + \cdots + \phi_p(x_{t-d})x_{t-p} + a_t \tag{4.27}$$
AR 系数本身是某个门限变量的**未知函数**（Chen & Tsay 1993a 提出；Cai, Fan & Yao 2000 用局部线性估计）。TAR 是它的阶梯函数特例，STAR 是平滑特例。

### 4.1.7 非线性可加自回归（NAAR）

$$x_t = f_0 + \sum_{i=1}^{p} f_i(x_{t-i}) + a_t \tag{4.28}$$
每个滞后项各配一个一维非参数函数 $f_i$。**避免维数灾难**（curse of dimensionality：$p$ 维非参数回归需要样本量指数增长）。Chen, Liu & Tsay (1995) 给出可加性检验。

### 4.1.8 非线性状态空间模型

$$x_t = G(S_t) + \epsilon_t,\qquad S_t = F(S_{t-1}) + \eta_t \tag{4.29}$$
观测方程与状态方程都允许非线性函数 $F, G$。Carlin, Polson & Stoffer (1992) 提出用 **MCMC（Gibbs 抽样）**统一处理非正态、非线性状态空间——这是后来粒子滤波等方法的先驱。

### 4.1.9 神经网络（Neural Networks）

**结构（以 2–3–1 前馈网络为例）**：输入层 2 个节点 → 隐藏层 3 个节点 → 输出层 1 个节点。

**隐藏层节点**：
$$h_j = f_j\!\left(\alpha_{0j} + \sum_{i\to j} w_{ij}x_i\right) \tag{4.31}$$
- $\alpha_{0j}$：偏置（bias），$w_{ij}$：权重（weights）；
- 激活函数常用 **logistic**：$f(z) = \dfrac{e^z}{1+e^z}$。

**输出层**：
$$o = f_o\!\left(\alpha_{0o} + \sum_{j\to o} w_{jo}h_j\right) \tag{4.32}$$
$f_o$ 取线性（回归）或 **Heaviside 函数**（$z>0$ 取 1、否则取 0；用于分类，叫 threshold neuron）。

**整体函数**：
$$o = f_o\!\left[\alpha_{0o} + \sum_{j\to o} w_{jo}\, f_j\!\left(\alpha_{0j} + \sum_{i\to j}w_{ij}x_i\right)\right] \tag{4.33}$$
若允许输入**直连输出**（skip-layer）：
$$o = f_o\!\left[\alpha_{0o} + \sum_{i\to o}\alpha_{io}x_i + \sum_{j\to o}w_{jo}f_j(\cdot)\right] \tag{4.34}$$
输出激活为线性时，直连项就是线性回归——**式 (4.34) 是线性模型的真推广**。

**参数量**：2–3–1 网络（式 4.33）有 $3\times2 + 3 + 3 + 1 = 13$ 个参数；带 skip-layer 的 3–2–1 有 15 个。函数形式已知但节点数、偏置、权重未知 → 称为**半参数函数**。

**万能逼近性质（universal approximation）**：Hornik, Stinchcombe & White (1989)、Hornik (1993)、Chen & Chen (1995) 证明——**只要隐藏层节点足够多，单隐层前馈网络可以在紧集上一致逼近任何连续函数**。所以神经网络本质是"一般连续非线性函数的参数化工具"。

**训练与预测**：分两步——(1) 训练（定结构、估偏置与权重，最小化 $\sum(r_t - o_t)^2$，用**反向传播 BP 算法**（Bryson & Ho 1969，梯度法从输出层反向逐层修正）；(2) 推断（预测）。数据切成**估计子样本 + 预测子样本**，用预测精度做交叉验证选网络。

**例 4.7（IBM 月对数收益，1926–1999）**：
- 训练样本 1926–1997（864 个观测），建 3–2–1 skip-layer 网络，输入 $r_{t-1},r_{t-2},r_{t-3}$：
$$\hat r_t = 3.22 - 1.81f_1(r_{t-1}) - 2.28f_2(r_{t-1}) - 0.09r_{t-1} - 0.05r_{t-2} - 0.12r_{t-3} \tag{4.35}$$
两个 logistic 函数分别为 $f_1 = \dfrac{\exp(-8.34-18.97r_{t-1}+2.17r_{t-2}-19.17r_{t-3})}{1+\exp(\cdot)}$，$f_2 = \dfrac{\exp(39.25-22.17r_{t-1}-17.34r_{t-2}-5.98r_{t-3})}{1+\exp(\cdot)}$。残差标准误 **6.56**。
- 对比 AR(1)：$r_t = 1.101 + 0.077r_{t-1} + a_t$，$\sigma_a = 6.61$（式 4.36）。
- **样本外预测比较（1998–1999，MSFE）**：基准（样本均值/带漂移随机游走）**91.85**；AR(1) **91.70**；3–2–1 网络 **91.74**。**神经网络与 AR(1) 几乎打平**！
- ⚠️ 备注很重要：用 S-Plus `nnet` 默认初始权重估计，**结果对初值敏感**——同一网络样本外 MSE 可在 **89.46 到 93.65** 间波动；改隐藏节点数波动更大。

**例 4.8（方向预测）**：定义方向变量 $d_t = \mathbb{1}\{r_t \ge 0\}$，用 $r_t, d_t$ 各前 4 阶滞后共 8 个输入、4 个隐藏节点建 **8–4–1 网络**（输出层 Heaviside），预测"下月上涨概率"。与"带漂移随机游走"模拟 500 次比较：随机游走预测错误数的均值/中位数为 **10.53/11**（24 个月中最少错 5 个、最多 17 个）——**8–4–1 网络并没有跑赢这个简单基准**。

> **作者的深意**：例 4.7 + 4.8 合起来是一个诚实的警示——**神经网络灵活强大，但对金融收益率的可预测性贡献甚微**，且训练不稳定。非线性≠可预测。

## 4.2 非线性检验（Nonlinearity Tests）

总原则：不存在"万能检验"——非线性有无数种形式，每个检验只对某类备择有功效。分为**非参数检验**（不指定备择模型）与**参数检验**（针对特定备择）。

### 4.2.1 非参数检验

**(1) 平方残差的 Q 统计量（McLeod & Li 1983）**：对 ARMA($p,q$) 残差 $a_t$ 的**平方**算 Ljung–Box：
$$Q(m) = T(T+2)\sum_{i=1}^{m}\frac{\hat\rho_i^2(a_t^2)}{T-i}$$
原假设：$a_t^2 = \beta_0 + \beta_1 a_{t-1}^2 + \cdots + \beta_m a_{t-m}^2 + e_t$ 中 $\beta_1=\cdots=\beta_m=0$。渐近 $\chi^2_{m-p-q}$。与 Engle (1982) 的 ARCH-LM 检验渐近等价——主要抓**条件异方差**。

**(2) 双谱检验（Bispectral test）**：同时检验**线性性**与**高斯性**。理论基础：线性序列的三阶矩
$$c(u,v) = g\sum_{k=-\infty}^{\infty}\psi_k\psi_{k+u}\psi_{k+v},\quad g = E(a_t^3) \tag{4.37}$$
其傅里叶变换（双谱）$b_3(w_1,w_2)$ 满足归一化后
$$b(w_1,w_2) = \frac{|b_3(w_1,w_2)|^2}{p(w_1)p(w_2)p(w_1+w_2)} = \text{常数}\quad \forall (w_1,w_2) \tag{4.39}$$
（$p(w)$ 为谱密度）。**线性 ⇒ $b$ 为常数；线性高斯 ⇒ $g=0$ ⇒ 双谱恒为零**。在频率网格上估计 $b$ 并用类似 Hotelling $T^2$ 的统计量检验其恒定性。

**(3) BDS 检验（Brock, Dechert & Scheinkman 1987）**：检验 **iid 假设**（不只针对二、三阶性质）。借用混沌分析的**相关积分**（correlation integral）：
$$C_k(\delta) = \lim_{T_k\to\infty}\frac{2}{T_k(T_k-1)}\sum_{i<j} I_\delta(X_i, X_j) \tag{4.40}$$
把序列嵌入 $k$ 维：$X_t^k = (x_t, x_{t+1},\dots,x_{t+k-1})'$（称 **k-history**）。若 $\{x_t\}$ iid，则 $k$ 维空间中的点无结构，必有
$$C_k(\delta) = [C_1(\delta)]^k$$
（直觉：均匀 iid 时，2-history 落在 $[a,b]^2$ 的频率 = 落在 $[a,b]$ 的频率的平方）。检验统计量：
$$D_k(\delta,T) = \frac{\sqrt{T}\,\{C_k(\delta,T) - [C_1(\delta,T)]^k\}}{\sigma_k(\delta,T)} \xrightarrow{d} N(0,1) \tag{4.41}$$
应用要点：**先剔除线性相关性**（对 AR 残差做）；结果对 $\delta$ 与 $k$ 的选择敏感（$k$ 大时尤其）。

### 4.2.2 参数检验

**(1) RESET 检验（Ramsey 1969）**：对 AR($p$) $x_t = X'_{t-1}\phi + a_t$（$X_{t-1}=(1,x_{t-1},\dots,x_{t-p})'$）：
- 第一步：OLS 拟合，得拟合值 $\hat x_t$、残差平方和 $SSR_0$；
- 第二步：回归 $\hat a_t = X'_{t-1}\alpha_1 + M'_{t-1}\alpha_2 + v_t$，其中 $M_{t-1} = (\hat x_t^2, \dots, \hat x_t^{s+1})'$，得 $SSR_1$；
- F 统计量：
$$F = \frac{(SSR_0 - SSR_1)/g}{SSR_1/(T-p-g)},\quad g = s+p+1 \tag{4.44}$$
原假设下服从 $F_{g,\,T-p-g}$。注意 $\hat x_t^k$ 间高度共线，实践中常用 $M_{t-1}$ 的主成分。

**(2) Keenan 检验（1985）**：只用 $\hat x_t^2$，分两步消共线性：
- 2(a)：回归 $\hat x_t^2 = X'_{t-1}\beta + u_t$，取残差 $\hat u_t$；
- 2(b)：回归 $\hat a_t = \hat u_t\alpha + v_t$，检验 $\alpha=0$。

**(3) Tsay 的 Ori-F 检验（1986）**：改进 RESET 功效，取 $M_{t-1} = \mathrm{vech}(X_{t-1}X'_{t-1})$（**半向量化**：只取对角线及以下元素）。$p=2$ 时 $M_{t-1} = (x_{t-1}^2, x_{t-1}x_{t-2}, x_{t-2}^2)'$，维数 $g = p(p+1)/2$。直接对
$$x_t = X'_{t-1}\phi + M'_{t-1}\alpha + e_t$$
做偏 F 检验 $\alpha=0$，自由度 $g$ 与 $T-p-g-1$。Luukkonen, Saikkonen & Teräsvirta (1988) 进一步加入三次项 $x_{t-i}^3$（LST 检验）。

**(4) 门限检验（针对 SETAR 备择）**：

*似然比检验的困难*：原假设 $H_0$：线性 AR($p$)（式 4.45）；备择 $H_a$：2 机制 SETAR（式 4.46，门限 $r_1$）。对数似然比 $l(r_1) = l_1(r_1) - l_0$ 是 $r_1$ 的函数，但**原假设下 $r_1$ 无定义**——$r_1$ 是"仅在备择下出现的讨厌参数（nuisance parameter）"，导致**似然比的渐近分布不是常规 $\chi^2$**（Davis 1987；Andrews & Ploberger 1994 建议用 $\sup_{r_1\in[v,u]} l(r_1)$ 或其在区间 $[v,u]$ 上的平均；Chan 1991 给出 TAR 似然比的百分点表）。

*Tsay (1989) 的 TAR-F 检验（arranged autoregression，排列自回归）*：把 SETAR 转成**变点问题**：
- 把门限变量排序 $x_{(1)} \le x_{(2)} \le \cdots \le x_{(T-d)}$，按排序重新写回归：
$$x_{(j)+d} = \beta_0 + \sum_{i=1}^{p}\beta_i x_{(j)+d-i} + a_{(j)+d} \tag{4.47}$$
当 $x_{(j)}$ 越过 $r_1$，系数从 $\phi^{(1)}$ 跳到 $\phi^{(2)}$——**门限 = 排列空间中的变点**。排列不改变 $x$ 对其滞后的动态依赖，只是从"时间空间"换到"门限空间"。
- 步骤：① 用前 $m$ 个（如 30）点估 $\hat\beta_{i,m}$；② 计算第 $m+1$ 点的**预测残差**并标准化得 $\hat e_{(m+1)+d}$；③ 递归最小二乘更新；④ 重复至样本末尾。
- 原假设（无变点）下，标准化预测残差应近似 iid $(0,1)$ 且与回归元不相关——据此构造 F 统计量，渐近 $F_{p+1,\,T-d-m-p}$。
- **优点**：避开讨厌参数问题、无需知道 $r_1$、无需指定机制数；**缺点**：若真模型是已知新息分布的 2 机制 SETAR，功效不如似然比。

## 4.3 建模（Modeling）—— 一套流程

1. **先建充分的线性模型**（它是非线性检验的基准）；
2. 金融序列用 Ljung–Box 和 Engle 检验查条件异方差；一般序列用 4.2 各检验；
3. 若非线性显著，**结合分析者经验与问题实质**选择非线性模型类别（波动问题查平方序列 PACF 定 ARCH 阶；TAR 用 Tong 1990 / Tsay 1989, 1998 的程序）；
4. 样本量大时可用**非参数探索**（Chen & Tsay 1993a；Cai-Fan-Yao 2000）或 **MARS**（Lewis & Stevens 1991）探索结构；
5. 用 **AIC**（Akaike 1974）或 Chen, McCulloch & Tsay (1997) 的广义机会比在竞争模型间筛选；
6. **预测前必须仔细检查模型**（残差诊断）。

> 高阶模型难估难解释——**宁简勿繁**。

## 4.4 预测（Forecasting）

**核心困难**：非线性模型 horizon > 1 时**没有预测解析式**（线性模型里条件期望可递推，非线性中 $E[f(x)] \ne f(E[x])$）。解法：**参数自助法**。

### 4.4.1 参数自助法（Parametric Bootstrap）

预测原点 $T$、horizon $\ell$：
1. 从模型指定的新息分布中抽一个新息；
2. 用模型 + 数据 + 已有预测值算 $x_{T+i}$；
3. 顺序生成一条路径 $x_{T+1}, \dots, x_{T+\ell}$；
4. 重复 $M$ 次（书中用 $M=3000$）得 $\{x_{T+\ell}^{(j)}\}_{j=1}^M$；
- **点预测** = 样本均值 $x_T(\ell)$；
- 附带收获：$M$ 个实现构成 $x_{T+\ell}$ 的**经验（条件预测）分布**，可算区间预测、尾部概率等。

### 4.4.2 预测评估

数据分**估计子样本**与**预测子样本**；可用滚动法（rolling：预测原点前移，把新数据点移入估计集）。没有公认单一准则，三类度量：

**(1) 方向度量**：2×2 列联表（预测涨/跌 × 实际涨/跌，$m_{11}, m_{12}, m_{21}, m_{22}$），卡方统计量
$$\chi^2 = \sum_{i=1}^2\sum_{j=1}^2 \frac{(m_{ij} - m_{i0}m_{0j}/m)^2}{m_{i0}m_{0j}/m} \sim \chi^2_1$$
例：8–4–1 神经网络方向预测列联表（涨预测对 12、错 2；跌预测对 2、错 8），$\chi^2 = 0.137$，$p=0.71$——**没有显著跑赢随机**（预测涨不错，预测跌很差）。

**(2) 幅度度量**：
$$MSE(\ell) = \frac{1}{m}\sum_{j=0}^{m-1}[x_{T+\ell+j} - x_{T+j}(\ell)]^2 \tag{4.49}$$
$$MAD(\ell) = \frac{1}{m}\sum_j |x_{T+\ell+j} - x_{T+j}(\ell)| \tag{4.50}$$
$$MAPE(\ell) = \frac{1}{m}\sum_j \left|\frac{x_{T+j}(\ell)}{x_{T+j+\ell}} - 1\right| \tag{4.51}$$
不同 $\ell$ 可能选出不同模型；各准则有局限（Clements & Hendry 1993）。

**(3) 分布度量**：用参数自助法得经验预测分布，计算实际值 $x_{T+\ell}$ 在该分布中的**分位数** $u_T(\ell)$。模型正确 ⇒ $\{u_{T+j}(\ell)\}$ 应为 $[0,1]$ 均匀分布样本——用 **Kolmogorov–Smirnov 统计量**检验，既可诊断模型又可比较预测（评估"年底涨 10% 概率"这类陈述必须用分布度量）。

## 4.5 应用：美国季度失业率（1948–1993，季节调整）★ 全章集大成案例

序列特征：**逆经济周期**；**升得快、降得慢**（强烈暗示非线性）。

**步骤 1：基准线性模型**（Montgomery et al. 1998）：
$$(1 - 0.31B^4)(1 - 0.65B)\Delta x_t = (1 - 0.78B^4)a_t,\quad \hat\sigma_a^2 = 0.090 \tag{4.52}$$
（系数标准误 0.11、0.06、0.07）。注意：**数据已季节调整却仍需要季节项** → 季节调整程序没除净季节性。

**步骤 2：非线性检验**：对 $\Delta x_t$ 拟合 AR(5) 后做 4.2 节各检验（表 4.3），**全部拒绝线性**；对 AR(2) 到 AR(10) 的所有阶数都拒绝。

**步骤 3：TAR 模型**（式 4.53，同例 4.2）：
$$\Delta x_t = \begin{cases} 0.01 + 0.73\Delta x_{t-1} + 0.10\Delta x_{t-2} + a_{1t} & \Delta x_{t-2} \le 0.1 \\ 0.18 + 0.80\Delta x_{t-1} - 0.56\Delta x_{t-2} + a_{2t} & \Delta x_{t-2} > 0.1 \end{cases}$$
- 机制 1（变化温和，经济稳定）：近似 AR(1)（滞后 2 系数不显著）；$\sigma_1^2 = 0.76$（原文如此，应为 0.076 量级）；
- 机制 2（失业率大幅跳升 ≥ 0.1，对应衰退、政府干预与产业重组期）：AR(2) + 正常数（失业率有上升趋势），**AR(2) 多项式含复特征根 → 周期振荡**。

**步骤 4：MSA 模型**（MCMC 估计，式 4.54）：
$$\Delta x_t = \begin{cases} -0.07 + 0.38\Delta x_{t-1} - 0.05\Delta x_{t-2} + \epsilon_{1t} & s_t=1 \\ 0.16 + 0.86\Delta x_{t-1} - 0.38\Delta x_{t-2} + \epsilon_{2t} & s_t=2 \end{cases}$$
- 条件均值：状态 1 = **−0.10（扩张期）**，状态 2 = **0.31（收缩期）**；
- 方差：$\sigma_{\epsilon_1}^2 = 0.031$，$\sigma_{\epsilon_2}^2 = 0.192$（收缩期波动是扩张期 6 倍多）；
- 转移概率：$P(s_t=2|s_{t-1}=1) = 0.084\,(0.060)$，$P(s_t=1|s_{t-1}=2) = 0.126\,(0.053)$；
- 状态 2 与 TAR 机制 2 结构相似（上升趋势 + 复特征根）。

**步骤 5：预测比较（表 4.4，滚动预测，起点 1968.II，1–5 步）**：

| 组 | 结论 |
|---|---|
| **全样本** | TAR 与线性基本持平（相对 MSE 0.98–1.04）；MSA 明显更差（1.19–1.61） |
| **衰退期起点** | **TAR 显著优于线性**：相对 MSE 0.85/0.91/0.83/**0.72**/**0.72**（4、5 步改善近 30%）；MSA 也有些改善但不如 TAR |
| **扩张期起点** | **线性模型反而最好**（TAR 1.06–1.17，MSA 1.31–1.87） |
| 预测误差均值 | 衰退期线性模型严重低估失业率上升（5 步偏差 1.38 vs TAR 0.86 vs MSA 0.14） |

> **本章最重要的实证结论**：非线性模型的价值集中在**经济收缩期**——恰恰是人们最关心预测、政府干预最频繁的时期。扩张期用线性模型就够了。

## 第四章核心速查表

| 主题 | 一句话 |
|---|---|
| 非线性本质 | 多均衡、极限环、不对称、混沌；无 Wold 分解；平稳性需几何遍历 |
| 双线性 | ARMA + $x_{t-i}a_{t-j}$ 交叉项；管均值不管波动 |
| TAR/SETAR | 按 $x_{t-d}$ 分机制分段线性；允许局部爆炸（$\phi^{(1)}\phi^{(2)}<1$ 即可） |
| STAR | logistic 平滑切换；$\Delta, s$ 难识别，常固定 $s$ |
| MSA | 隐马尔可夫链随机切换；$1/w_i$ = 状态持续期；EM 或 MCMC 估计 |
| 非参数 | 核回归/局部线性估计 $\mu(x),\sigma(x)$；带宽决定偏差-方差权衡 |
| FAR/NAAR | 系数是函数 / 逐滞后一维函数（治维数灾难） |
| 神经网络 | 单隐层万能逼近；BP 训练；**对初值敏感**；金融收益上难赢 AR(1) |
| 非线性检验 | Q(平方残差)、双谱（线性+高斯）、BDS（iid，最敏感）；RESET/Keenan/Ori-F（二次型方向）；TAR-F（排列自回归，避开讨厌参数） |
| 预测 | 参数自助法 $M=3000$；评估用方向 χ² / MSE-MAD-MAPE / 分位数均匀性(KS) |
| 失业率案例 | 非线性模型的优势集中在**经济收缩期**（TAR 4–5 步 MSE 改善 ~28%） |
