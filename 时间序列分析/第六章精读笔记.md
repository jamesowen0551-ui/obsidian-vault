## 引言：两类随机过程

- **离散时间过程**：价格只在离散时点变化（第 1–5 章全部属于此类；第 5 章的逐笔价格变化是"离散时间离散值"过程）；
- **连续时间过程**：价格时刻在变化（可看作"真值"永续波动），我们只是离散地观测它。
- 按时间连续/离散 × 取值连续/离散，共四类过程。
- 跳跃使市场**不完全**（incomplete），期权无法完美对冲——只能假定跳跃风险可分散，或定义风险度量并最小化之。

## 6.1 期权（Options）

- **看涨期权（call）**：持有人有权在约定日期前以约定价**买入**标的；**看跌期权（put）**：有权**卖出**。
- 术语：**执行价/敲定价格**（strike/exercise price $K$）、**到期日**（expiration/maturity $T$）。
- **美式期权**：到期前任意时刻可行权；**欧式期权**：只能在到期日行权。
- 期权价值依赖于标的价格：看涨期权在 $P_T > K$ 时值 $P_T - K$，否则为 0。

## 6.2 连续时间随机过程

**记号**：$x(\eta, t)$ 是 $\eta$（随机结果）与 $t$（时间）的二元函数；固定 $\eta$ 是一条时间序列实现；固定 $t$ 是一个随机变量。简写 $\{x_t\}$。

### 6.2.1 Wiener 过程（标准布朗运动）★ 连续时间的"白噪声"

**定义（本书的简易版）**：过程 $\{w_t\}$ 是 Wiener 过程若
1. $\Delta w_t = \epsilon\sqrt{\Delta t}$，$\epsilon \sim N(0,1)$；
2. $\Delta w_t$ 与一切 $w_j$（$j\le t$）独立（**Markov 性**——给定现在，过去与未来无关；金融上对应**弱式有效市场**）。

推论：$w_t - w_0 \sim N(0, t)$——**方差随时间线性增长**。

**Donsker 定理**：$w_{n,t} = \frac{1}{\sqrt n}\sum_{i=1}^{[nt]}z_i$（$z_i$ iid 标准正态）依分布收敛到 Wiener 过程。R 模拟：
```r
n = 3000; epsi = rnorm(n,0,1); w = cumsum(epsi)/sqrt(n); plot(w,type='l')
```

**正式定义**（概率空间 $(\Omega, F, P)$ 上）：路径几乎必然**连续**、**独立增量**、**平稳增量**；增量 $w_t - w_s \sim N(\mu(t-s), \sigma^2(t-s))$；标准布朗运动要求 $w_0=0, \mu=0, \sigma^2=1$。

> **关键性质**：布朗运动路径**几乎处处不可微**（$dw_t/dt$ 不存在）——普通微积分失效，必须发展 **Ito 随机微积分**。这就是 6.3 节的动机。

### 6.2.2 广义 Wiener 过程

加入**漂移率 $\mu$** 与**方差率 $\sigma^2$**（常数）：$dx_t = \mu\,dt + \sigma\,dw_t$。期望变化率 $\mu$、方差变化率 $\sigma^2$。

### 6.2.3 Ito 过程（随机扩散方程）★

再进一步让 $\mu,\sigma$ 依赖于状态与时间：
$$dx_t = \mu(x_t, t)\,dt + \sigma(x_t, t)\,dw_t \tag{6.2}$$
积分形式 $x_t = x_0 + \int_0^t\mu(x_s,s)ds + \int_0^t\sigma(x_s,s)dw_s$（最后一项是**随机积分**）。$\mu$ 叫**漂移函数**，$\sigma$ 叫**扩散函数**。Wiener 过程是 $\mu=0,\sigma=1$ 的特例。

## 6.3 Ito 引理（Ito's Lemma）★ 本章数学核心

### 6.3.1 普通微分复习

$G(x)$ 可微：Taylor 展开后高阶项消失，$dG = \frac{\partial G}{\partial x}dx$；二元时 $dG = \frac{\partial G}{\partial x}dx + \frac{\partial G}{\partial y}dy$。

### 6.3.2 随机微分：为什么多出一项

$G(x_t, t)$，$x_t$ 为 Ito 过程。离散化 $\Delta x = \mu\Delta t + \sigma\epsilon\sqrt{\Delta t}$（式 6.4）。关键计算：
$$(\Delta x)^2 = \mu^2(\Delta t)^2 + \sigma^2\epsilon^2\Delta t + 2\mu\sigma\epsilon(\Delta t)^{3/2} = \sigma^2\epsilon^2\Delta t + H(\Delta t)$$
**$(\Delta x)^2$ 含有 $\Delta t$ 阶的项，不能丢！** 而且 $E(\sigma^2\epsilon^2\Delta t) = \sigma^2\Delta t$、$\mathrm{Var}(\sigma^2\epsilon^2\Delta t) = 2\sigma^4(\Delta t)^2 \to 0$（用 $E(\epsilon^4)=3$）——**$\sigma^2\epsilon^2\Delta t$ 收敛到非随机的 $\sigma^2 dt$**。因此
$$(\Delta x)^2 \to \sigma^2\,dt \quad (\Delta t\to 0)$$
代入 Taylor 展开（式 6.3），二阶项留下，得到：

**Ito 引理**：$dx_t = \mu(x_t,t)dt + \sigma(x_t,t)dw_t$，$G(x_t,t)$ 可微，则
$$\boxed{dG = \left[\frac{\partial G}{\partial x}\mu + \frac{\partial G}{\partial t} + \frac12\frac{\partial^2 G}{\partial x^2}\sigma^2\right]dt + \frac{\partial G}{\partial x}\sigma\,dw_t} \tag{6.6}$$

与普通微积分相比多了**二阶修正项** $\frac12\frac{\partial^2G}{\partial x^2}\sigma^2 dt$——这是布朗运动二次变差非零的直接后果。

**例 6.1**：$G = w_t^2$（$\mu=0,\sigma=1$）：$dw_t^2 = dt + 2w_t\,dw_t$（式 6.7）。注意比普通微积分的 $d(x^2)=2x\,dx$ 多了 $dt$。

### 6.3.3 应用：几何布朗运动的对数

股价常假设为**几何布朗运动（GBM）**：
$$dP_t = \mu P_t\,dt + \sigma P_t\,dw_t \tag{6.8}$$
对 $G = \ln P_t$ 用 Ito 引理（$\frac{\partial G}{\partial P} = \frac1{P_t}$，$\frac{\partial^2G}{\partial P^2} = -\frac{1}{P_t^2}$）：
$$d\ln P_t = \left(\mu - \frac{\sigma^2}{2}\right)dt + \sigma\,dw_t$$
> **对数价格服从广义 Wiener 过程**，漂移 $\mu - \sigma^2/2$、方差率 $\sigma^2$。于是 $t$ 到 $T$ 的**对数收益正态**：均值 $(\mu-\sigma^2/2)(T-t)$、方差 $\sigma^2(T-t)$。这个 $-\sigma^2/2$ 修正是 Ito 引理最著名的产物。

### 6.3.4 $\mu$ 和 $\sigma$ 的估计

等间隔（$\Delta$ 年）观测 $P_0,\dots,P_n$，对数收益 $r_t = \ln P_t - \ln P_{t-1} \sim N((\mu-\sigma^2/2)\Delta,\ \sigma^2\Delta)$，序列不相关。设样本均值 $\bar r$、样本 SD $s_r$：
$$\hat\sigma = \frac{s_r}{\sqrt\Delta},\qquad \hat\sigma \text{ 的标准误} \approx \frac{\hat\sigma}{\sqrt{2n}}$$
$$\hat\mu = \frac{\bar r}{\Delta} + \frac{\hat\sigma^2}{2} = \frac{\bar r}{\Delta} + \frac{s_r^2}{2\Delta}$$

**例 6.2（IBM 1998 日收益，252 个交易日）**：$\bar r = 0.002276$，$s_r = 0.01915$，$\Delta = 1/252$ → $\hat\sigma = 0.3040$（年化 30.4%），$\hat\mu = 0.6198$（年化期望收益 **61.98%**）。Q(10)=4.9 不相关 ✔；但偏度 −0.464(0.153)、超额峰度 2.396(0.306) 显示**正态假设存疑**。

**例 6.3（Cisco 2007 日收益，251 个观测）**：$\bar r = -3.81\times10^{-5}$，$s_r = 0.0174$ → $\hat\sigma = 27.5\%$，$\hat\mu = -0.94\%$。

## 6.4 股价与对数收益的分布

GBM 下：
$$\ln P_T \mid P_t \sim N\!\left[\ln P_t + \left(\mu-\frac{\sigma^2}{2}\right)(T-t),\ \sigma^2(T-t)\right] \tag{6.10}$$
由对数正态性质：
$$E(P_T) = P_t e^{\mu(T-t)},\qquad \mathrm{Var}(P_T) = P_t^2 e^{2\mu(T-t)}\left[e^{\sigma^2(T-t)}-1\right]$$
（均值公式确认 $\mu$ 确实是期望收益率。）

**数值例**：现价 \$50、$\mu=15\%$、$\sigma=40\%$，半年后 $E = 50e^{0.075} = 53.89$，$\mathrm{Var} = 241.92$，SD = **\$15.55**。

**年化连续复利收益率** $r = \frac{1}{T-t}\ln(P_T/P_t)$ 的分布：
$$r \sim N\!\left(\mu - \frac{\sigma^2}{2},\ \frac{\sigma^2}{T-t}\right)$$
例：$\mu=15\%, \sigma=10\%$，2 年期：$r \sim N(0.145, 0.071^2)$，95% CI = $0.145 \pm 1.96\times0.071 = (0.6\%, 28.4\%)$。**期限越长，年化收益率估计越准（SD 按 $1/\sqrt{T-t}$ 缩）**。

## 6.5 Black–Scholes 微分方程的推导 ★

设 $P_t$ 服从 GBM（式 6.8），衍生品价格 $G_t = G(P_t, t)$。Ito 引理：
$$dG_t = \left(\frac{\partial G_t}{\partial P_t}\mu P_t + \frac{\partial G_t}{\partial t} + \frac12\frac{\partial^2 G_t}{\partial P_t^2}\sigma^2P_t^2\right)dt + \frac{\partial G_t}{\partial P_t}\sigma P_t\,dw_t$$

**关键构造（无套利对冲）**：$P_t$ 与 $G_t$ 由**同一个** Wiener 过程驱动，故可造一个**消去随机性**的组合：
$$V_t = -G_t + \frac{\partial G_t}{\partial P_t}P_t \quad(\text{卖空 1 份衍生品 + 买入 } \partial G/\partial P \text{ 股股票}) \tag{6.13}$$
$$\Delta V_t = \left(-\frac{\partial G_t}{\partial t} - \frac12\frac{\partial^2G_t}{\partial P_t^2}\sigma^2P_t^2\right)\Delta t \tag{6.15}$$
不含 $\Delta w_t$ → **组合瞬时无风险** → 无套利要求它赚无风险利率：$\Delta V_t = rV_t\Delta t$。整理得 **Black–Scholes 偏微分方程**：
$$\boxed{\frac{\partial G_t}{\partial t} + rP_t\frac{\partial G_t}{\partial P_t} + \frac12\sigma^2P_t^2\frac{\partial^2G_t}{\partial P_t^2} = rG_t} \tag{6.17}$$
边界条件：欧式看涨 $G_T = \max(P_T-K, 0)$；欧式看跌 $G_T = \max(K-P_T, 0)$。

**例 6.4（远期合约验证）**：$G_t = P_t - Ke^{-r(T-t)}$ 代入——$\frac{\partial G}{\partial t} = -rKe^{-r(T-t)}$、$\frac{\partial G}{\partial P}=1$、二阶导 0，方程两边相等 ✔。

## 6.6 Black–Scholes 定价公式

### 6.6.1 风险中性世界

注意 B-S 方程中**漂移 $\mu$ 消失了**——方程与风险偏好无关！因此可以**假设投资者风险中性**：
- 所有证券的期望收益率 = 无风险利率 $r$；
- 任何现金流按无风险利率贴现。

### 6.6.2 公式

欧式看涨：
$$c_t = e^{-r(T-t)}E^*[\max(P_T-K,0)] \tag{6.18}$$
风险中性下 $\mu=r$，$\ln P_T$ 正态，积分（附录 A 详推）得：
$$\boxed{c_t = P_t\Phi(h_+) - Ke^{-r(T-t)}\Phi(h_-)} \tag{6.19}$$
$$h_+ = \frac{\ln(P_t/K) + (r+\sigma^2/2)(T-t)}{\sigma\sqrt{T-t}},\qquad h_- = h_+ - \sigma\sqrt{T-t}$$

**两种解读**：
1. $P_t\Phi(h_+)$ = "当且仅当 $P_T>K$ 时收到股票"的现值；$-Ke^{-r(T-t)}\Phi(h_-)$ = "当且仅当 $P_T>K$ 时支付执行价"的现值；
2. **$\Phi(h_+) = \partial G_t/\partial P_t$ 就是对冲组合的持股数（delta）**；$c_t = P_t\Phi(h_+) + B_t$，第二项 $Ke^{-r(T-t)}\Phi(h_-)$ 是**借款额**——期权 = 买股票 + 借钱的复制组合。

欧式看跌：
$$p_t = Ke^{-r(T-t)}\Phi(-h_-) - P_t\Phi(-h_+) \tag{6.20}$$

**平价关系（put–call parity）**：
$$c_t + Ke^{-r(T-t)} = p_t + P_t$$
证明：组合 A（1 看涨 + $Ke^{-r(T-t)}$ 现金）与组合 B（1 看跌 + 1 股）到期收益都是 $\max(P_T, K)$ → 今日价值必等。

**例 6.5**：$P_t=80, K=90, T-t=0.25, \sigma=0.2, r=0.08$ → $h_+=-0.9278, h_-=-1.0278$，$\Phi$ 值 0.1767/0.1520 → **$c_t = \$0.73$**（股价需涨 \$10.73 才回本）；$p_t = \$8.95$。
**例 6.6**：$K=81$（更现实）→ $h_+=0.125775$ → **$c_t=\$3.49$**（涨 \$4.49 回本），$p_t=\$2.89$。

### 6.6.3 欧式期权的下界

组合论证（A：看涨 + $Ke^{-r(T-t)}$ 现金；B：1 股股票；A 到期价值 $\max(P_T,K) \ge P_T$ = B）：
$$c_t \ge \max\left(P_t - Ke^{-r(T-t)},\ 0\right),\qquad p_t \ge \max\left(Ke^{-r(T-t)} - P_t,\ 0\right)$$
**例 6.7**：$P_t=30, K=28, r=6\%, T-t=0.5$ → 下界 \$2.83。若看涨市价 \$2.50 → **套利**：买期权 + 卖空股票 = 现金流入 \$27.50，投资半年得 \$28.34；到期若 $P_T>28$ 行权平仓赚 \$0.34；若 $P_T=27$ 买回股票平仓赚 \$1.34。

### 6.6.4 五要素的边际效应（图 6.3–6.7）

| 变量 | 对看涨 $c_t$ | 极限/备注 |
|---|---|---|
| 现价 $P_t$ ↑ | **正相关** | $P_t\to0 \Rightarrow c\to0$；$P_t\to\infty \Rightarrow c\to\infty$ |
| 执行价 $K$ ↑ | **负相关** | $K\to0 \Rightarrow c\to P_t$；$K\to\infty \Rightarrow c\to0$ |
| 期限 $T-t$ | 复杂 | $P_t<K$：$T-t\to0 \Rightarrow c\to0$；$P_t>K$：$\to P_t-K$（短期）/ $\to P_t$（长期） |
| 波动率 $\sigma$ ↑ | **正相关** | $\ln(P_t/K)+r(T-t)\ge0$ 时 $\sigma\to0 \Rightarrow c\to P_t-Ke^{-r(T-t)}$；$\sigma\to\infty \Rightarrow c\to P_t$ |
| 利率 $r$ ↑ | **正相关** | $r\to\infty \Rightarrow c\to P_t$ |

看跌相反（图 6.6/6.7 联合效应：波动率高 + 执行价远低于现价 → 看涨贵；波动率高 + 执行价远高于现价 → 看跌贵）。

## 6.7 Ito 引理的多维推广

$k$ 维过程 $dx_{it} = \mu_i(\mathbf{x}_t)dt + \sigma_i(\mathbf{x}_t)dw_{it}$，$dw_{it}$ 与 $dw_{jt}$ 相关 $\rho_{ij}$（式 6.21）。则 $G(\mathbf{x}_t,t)$：
$$dG_t = \left[\sum_{i=1}^k\frac{\partial G_t}{\partial x_{it}}\mu_i + \frac{\partial G_t}{\partial t} + \frac12\sum_{i,j}\frac{\partial^2G_t}{\partial x_{it}\partial x_{jt}}\sigma_i\sigma_j\rho_{ij}\right]dt + \sum_{i=1}^k\frac{\partial G_t}{\partial x_{it}}\sigma_i dw_{it} \tag{6.24}$$
（利率期限结构的两因子模型是其典型应用。）

## 6.8 随机积分

积分是微分的逆：$\int_0^t dx_s = x_t - x_0$；$\int_0^t dw_s = w_t$（因 $w_0=0$）。

**与确定性的差别**：对 $dw_t^2 = dt + 2w_t dw_t$ 两边积分得
$$\int_0^t w_s\,dw_s = \frac12(w_t^2 - t)$$
——**比普通积分 $\int y\,dy = y^2/2$ 多了 $-t/2$**（Ito 修正的积分形式）。

**GBM 求解**：$d\ln x_t = (\mu-\sigma^2/2)dt + \sigma dw_t$ 直接积分：
$$P_t = P_0\exp\left[\left(\mu-\frac{\sigma^2}{2}\right)t + \sigma w_t\right] \tag{6.25}$$

## 6.9 跳跃扩散模型（Jump Diffusion）

**动机**：纯扩散模型解释不了**波动率微笑**（implied volatility 对执行价呈凸形：价外/价内期权的隐含波动率高于平价，外汇市场尤其明显）和收益的**尖峰厚尾**。Merton(1976) 引入跳跃，Kou(2002) 给出解析解。

**预备：Poisson 过程**（连续时间离散值）：$X_t$ = $[0,t]$ 内特殊事件发生次数，
$$\Pr(X_t = m) = \frac{(\lambda t)^m}{m!}e^{-\lambda t}$$
$\lambda$ 是**强度**（rate）。

**Kou (2002) 跳跃扩散模型**：
$$\frac{dP_t}{P_t} = \mu\,dt + \sigma\,dw_t + d\left[\sum_{i=1}^{n_t}(J_i - 1)\right] \tag{6.26}$$
- $n_t$：强度 $\lambda$ 的 Poisson 过程（跳跃次数）；$J_i-1$：第 $i$ 次跳跃的价格比例；
- **跳跃幅度 $X = \ln J$ 服从双指数（Laplace）分布**：
$$f_X(x) = \frac{1}{2\eta}e^{-|x-\kappa|/\eta},\quad 0<\eta<1 \tag{6.27}$$
可写为 $X-\kappa = \pm\xi$（各 0.5 概率，$\xi$ 为均值 $\eta$、方差 $\eta^2$ 的指数变量）。性质：$E(X)=\kappa$，$\mathrm{Var}(X)=2\eta^2$，$E(e^X) = \frac{e^\kappa}{1-\eta^2}$。双指数峰部尖、尾部厚（图 6.8 与正态对比）；$n_t, w_t, J_i$ 相互独立。

**求解**（逐段无跳跃区间用 GBM，跳跃点乘以 $J_i$）：
$$P_t = P_0\exp\left[\left(\mu-\frac{\sigma^2}{2}\right)t + \sigma w_t\right]\prod_{i=1}^{n_t}J_i \tag{6.29}$$

**小时间间隔的简单收益近似**（用 $e^x\approx1+x+x^2/2$ 和 $(\Delta w_t)^2\approx\Delta t$，单跳跃概率 $\lambda\Delta t$、多跳跃 $o(\Delta t)$ 忽略）：
$$\frac{P_{t+\Delta t}-P_t}{P_t} \approx \mu\Delta t + \sigma\epsilon\sqrt{\Delta t} + I\times X \tag{6.30}$$
$I$ 为 Bernoulli（$P(I=1)=\lambda\Delta t$），$X$ 双指数。无跳跃时退化回 GBM。

**收益分布（Kou 2002，式 6.31）**：$G = \mu\Delta t+\sigma\epsilon\sqrt{\Delta t}+IX$ 的 pdf 有解析式（正态 pdf 与双指数-正态卷积的混合）：
$$E(G) = \mu\Delta t + \kappa\lambda\Delta t,\qquad \mathrm{Var}(G) = \sigma^2\Delta t + \lambda\Delta t\left[2\eta^2 + \kappa^2(1-\lambda\Delta t)\right]$$
图 6.9（$\mu=20\%, \sigma=20\%, \Delta t=1/252, \lambda=10, \kappa=-0.02, \eta=0.02$，即**每年约 10 次跳跃、平均跳幅 −2%、跳幅 SD 2%**）：分布明显**尖峰厚尾**（leptokurtic），与正态的峰部、左右尾对比清晰。

### 6.9.1 跳跃扩散下的期权定价

有跳跃 → **市场不完全** → 标准对冲失效。处理：假设证券数量足够多使**跳跃风险可分散**，市场不为此支付风险溢价。风险中性测度下
$$P_t = P_0\exp\left[\left(r-\frac{\sigma^2}{2}-\lambda\psi\right)t + \sigma w_t\right]\prod_{i=1}^{n_t}J_i$$
其中 $\psi = \frac{e^\kappa}{1-\eta^2}-1$（跳跃的期望补偿）。欧式看涨：
$$c_t = E^*\left[e^{-r(T-t)}\left(P_T-K\right)^+\right] \tag{6.32}$$
**Kou (2002) 解析公式（式 6.33）**：无穷级数，含 $A_{1,n,j}, A_{2,n,j}, A_{3,n,j}$ 三项和 Hh 函数
$$Hh_n(x) = \frac{1}{n!}\int_x^\infty(s-x)^ne^{-s^2/2}ds,\quad Hh_{-1}(x)=e^{-x^2/2},\quad Hh_0(x)=\sqrt{2\pi}\Phi(-x)$$
递推：$nHh_n(x) = Hh_{n-2}(x) - xHh_{n-1}(x)$（式 6.35）。实践中**截断前 10 项即足够精确**；$\lambda=0$ 时退化为 B-S 公式。看跌用平价关系：$p_t = c_t + Ke^{-r(T-t)} - P_t$。

**例 6.8**：$P_t=80, K=81, r=0.08, T-t=0.25$，加跳跃 $\lambda=10,\kappa=-0.02,\eta=0.02$ → **$c_t=\$3.92$**（无跳跃时 \$3.49），**$p_t=\$3.31$**（原 \$2.89）。**加入跳跃使两类期权都变贵**（总不确定性上升）。注意实际中引入跳跃会改变 $\sigma$ 的估计。

## 6.10 连续时间模型的估计（方法综述）

直接从离散观测估计扩散方程（Ito 过程）的四类方法：
1. **最大似然**（离散采样下转移密度难求；Lo 1988；Ait-Sahalia 2002 给出封闭形式近似）；
2. **矩方法/GMM**（Conley, Hansen, Luttmer & Scheinkman 1997）；
3. **非参数方法**（Ait-Sahalia 1996, 2002）；
4. **半参数与再投影法**（Gallant & Long 1997；Gallant & Tauchen 1997）；
5. 近年流行 **MCMC**（Eraker 2001；Elerian, Chib & Shephard 2001）。

## 附录 A：B-S 公式的积分推导

$c_t = e^{-r(T-t)}\left[\int_{\ln K}^\infty e^xf(x)dx - K\int_{\ln K}^\infty f(x)dx\right]$（$x=\ln P_T$ 正态）。
- 第二项：$1 - \mathrm{CDF}[\ln K] = \Phi(h_-)$；
- 第一项：**配平方** $x - \frac{[x-\ln P_t-(r-\sigma^2/2)(T-t)]^2}{2\sigma^2(T-t)} = -\frac{[x-\ln P_t-(r+\sigma^2/2)(T-t)]^2}{2\sigma^2(T-t)} + \ln P_t + r(T-t)$，提出 $P_te^{r(T-t)}$ 后剩 $N(\ln P_t+(r+\sigma^2/2)(T-t),\ \sigma^2(T-t))$ 的尾部 = $\Phi(h_+)$。
合并：$c_t = P_t\Phi(h_+) - Ke^{-r(T-t)}\Phi(h_-)$ ✔。

## 附录 B：标准正态 CDF 近似

$$\Phi(x) \approx 1 - f(x)\left[c_1k + c_2k^2 + c_3k^3 + c_4k^4 + c_5k^5\right],\quad x\ge0$$
$k = 1/(1+0.2316419x)$，$c_1=0.319381530, c_2=-0.356563782, c_3=1.781477937, c_4=-1.821255978, c_5=1.330274429$；$x<0$ 用 $1-\Phi(-x)$。验证：$\Phi(1.96)=0.975002$ ✔。

## 第六章核心速查表

| 主题 | 一句话 |
|---|---|
| Wiener 过程 | $\Delta w_t = \epsilon\sqrt{\Delta t}$；独立平稳增量；**路径不可微** → 需 Ito 微积分 |
| Ito 引理 | $dG = [G_x\mu + G_t + \frac12G_{xx}\sigma^2]dt + G_x\sigma dw$；多出的二阶项源于 $(dx)^2\to\sigma^2dt$ |
| GBM | $dP = \mu Pdt + \sigma Pdw \Rightarrow d\ln P = (\mu-\sigma^2/2)dt + \sigma dw$；**$-\sigma^2/2$ 修正** |
| 参数估计 | $\hat\sigma = s_r/\sqrt\Delta$（SE $\approx\hat\sigma/\sqrt{2n}$）；$\hat\mu = \bar r/\Delta + \hat\sigma^2/2$ |
| B-S 方程 | 对冲组合 $V=-G+\frac{\partial G}{\partial P}P$ 无风险 → $\frac{\partial G}{\partial t}+rPG_P+\frac12\sigma^2P^2G_{PP}=rG$ |
| B-S 公式 | $c = P\Phi(h_+) - Ke^{-r(T-t)}\Phi(h_-)$；$\Phi(h_+)$ = delta = 复制组合持股数 |
| 平价关系 | $c + Ke^{-r(T-t)} = p + P$；下界 $c\ge P-Ke^{-r(T-t)}$ |
| 边际效应 | 看涨：$P\uparrow, \sigma\uparrow, r\uparrow$ → $c\uparrow$；$K\uparrow$ → $c\downarrow$ |
| 随机积分 | $\int_0^t w_sdw_s = \frac12(w_t^2-t)$（比普通积分多 $-t/2$） |
| 跳跃扩散 | $dP/P = \mu dt + \sigma dw + d\sum(J_i-1)$；Poisson 跳跃 + 双指数幅度（Kou 2002 解析解） |
| 跳跃的期权含义 | 市场不完全 → 假设跳跃风险可分散；公式 = 无穷级数（截断 10 项）；$\lambda=0$ 退化 B-S |
