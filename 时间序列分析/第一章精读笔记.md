## 0. 引言（无编号节，书 pp. 1–2）

### 0.1 金融时间序列分析是什么

- 定义：研究**资产随时间估值（asset valuation over time）的理论与实践**。
- 它是一门**高度经验性（highly empirical）**的学科，但理论是统计推断的基础。
- 与一般时间序列分析的关键区别：**金融理论和经验数据都内含不确定性**。
  - 例：资产"波动率"有多种定义，且对股票收益率序列而言，波动率**不可直接观测**（not directly observable）。
  - 正因为这层额外的不确定性，统计理论和方法在金融时间序列分析中格外重要。

### 0.2 本书目标

1. 提供金融时间序列的基本知识；
2. 介绍分析这些序列有用的统计工具；
3. 通过各类计量方法的金融应用积累实战经验。

## 1.1 资产收益率（Asset Returns，pp. 2–6）

设 $P_t$ = 资产在时点 $t$ 的价格。**先假设资产不分红**。

### 1.1.1 单期简单收益率

从 $t-1$ 持有到 $t$：

**简单总收益率（simple gross return）**：
$$1 + R_t = \frac{P_t}{P_{t-1}} \quad\text{或}\quad P_t = P_{t-1}(1+R_t) \tag{1.1}$$

**单期简单净收益率（simple net return / simple return）**：
$$R_t = \frac{P_t}{P_{t-1}} - 1 = \frac{P_t - P_{t-1}}{P_{t-1}} \tag{1.2}$$

### 1.1.2 多期简单收益率

从 $t-k$ 持有到 $t$（k 期）的**简单总收益率**：

$$1 + R_t[k] = \frac{P_t}{P_{t-k}} = \frac{P_t}{P_{t-1}}\cdot\frac{P_{t-1}}{P_{t-2}}\cdots\frac{P_{t-k+1}}{P_{t-k}} = \prod_{j=0}^{k-1}(1+R_{t-j})$$

- 即 k 期总收益率 = 所含 k 个单期总收益率的**连乘**，故称**复合收益率（compound return）**。
- k 期简单净收益率：$R_t[k] = (P_t - P_{t-k})/P_{t-k}$。

### 1.1.3 年化收益率

- 实务中讨论收益率必须说明**时间区间**（月收益？年收益？）；若未指明，**默认区间是一年**。
- 若资产持有了 k 年，**年化（平均）收益率**定义为：

$$\text{Annualized}\{R_t[k]\} = \left[\prod_{j=0}^{k-1}(1+R_{t-j})\right]^{1/k} - 1$$

- 它是 k 个单期总收益率的**几何平均**，等价写法：

$$\text{Annualized}\{R_t[k]\} = \exp\left(\frac{1}{k}\sum_{j=0}^{k-1}\ln(1+R_{t-j})\right) - 1$$

- 因为算术平均比几何平均好算，且单期收益率通常很小，可用**一阶 Taylor 展开近似**：

$$\text{Annualized}\{R_t[k]\} \approx \frac{1}{k}\sum_{j=0}^{k-1}R_{t-j} \tag{1.3}$$

- ⚠️ 注意：某些应用中这个近似的精度**可能不够**。

### 1.1.4 连续复利（Continuous Compounding）

**复利效果演示**：银行存款年利率 10%，本金 \$1.00。

- 每年付息 1 次：一年后净值 $1 \times (1+0.1) = \$1.1$
- 每半年付息 1 次：每期利率 $10\%/2 = 5\%$，一年后 $1 \times (1+0.1/2)^2 = \$1.1025$
- 一般地，每年付息 m 次：每期利率 $10\%/m$，一年后净值 $1\times(1+0.1/m)^m$
- $m \to \infty$ 时趋于 $\exp(0.1) \approx 1.1052$ —— 即**连续复利**的结果

**表 1.1 复利效果（期限 1 年，年利率 10%，本金 \$1）**：

| 类型 | 付息次数 | 每期利率 | 净值 |
|---|---|---|---|
| 按年 | 1 | 0.1 | \$1.10000 |
| 按半年 | 2 | 0.05 | \$1.10250 |
| 按季 | 4 | 0.025 | \$1.10381 |
| 按月 | 12 | 0.0083 | \$1.10471 |
| 按周 | 52 | 0.1/52 | \$1.10506 |
| 按日 | 365 | 0.1/365 | \$1.10516 |
| 连续 | ∞ | — | \$1.10517 |

**一般公式**：连续复利下资产净值

$$A = C\exp(r \times n) \tag{1.4}$$

其中 r = 年利率，C = 初始本金，n = 年数。反解出**现值（present value）**：

$$C = A\exp(-r \times n) \tag{1.5}$$

即：n 年后价值 A 美元的资产，在连续复利率 r 下的现值为 C。

### 1.1.5 连续复合收益率（对数收益率）

简单总收益率的自然对数称为**连续复合收益率**或**对数收益率（log return）**：

$$r_t = \ln(1 + R_t) = \ln\frac{P_t}{P_{t-1}} = p_t - p_{t-1} \tag{1.6}$$

其中 $p_t = \ln P_t$。

**对数收益率的两大优点**：

**优点 1：多期收益率的可加性**

$$r_t[k] = \ln(1+R_t[k]) = \ln\prod_{j=0}^{k-1}(1+R_{t-j}) = r_t + r_{t-1} + \cdots + r_{t-k+1}$$

连乘变连加——统计上好处理得多。

**优点 2：统计性质更易处理（tractable）**——详见 1.2 节分布讨论。

### 1.1.6 组合收益率（Portfolio Return）

- 组合 p 由 N 个资产构成，资产 i 的权重 $w_i$ = 组合市值中投于该资产的百分比。
- 组合的**简单净收益率**是成分资产简单净收益率的**加权平均**：

$$R_{p,t} = \sum_{i=1}^{N} w_i R_{it}$$

- ⚠️ 组合的**对数收益率没有**这个精确性质。只有当各 $R_{it}$ 都很小时才有近似：

$$r_{p,t} \approx \sum_{i=1}^{N} w_i r_{it}$$

该近似常用于组合收益率研究。

> **记住这个分工**：时间维度聚合（多期）→ 对数收益率（连加）；截面维度聚合（组合）→ 简单收益率（加权平均）。

### 1.1.7 分红调整（Dividend Payment）

设 $D_t$ = 资产在 $t-1$ 到 $t$ 之间支付的红利，$P_t$ = t 期末价格（**不含**红利）。则：

$$R_t = \frac{P_t + D_t}{P_{t-1}} - 1, \qquad r_t = \ln(P_t + D_t) - \ln P_{t-1}$$

### 1.1.8 超额收益率（Excess Return）

**定义**：资产收益率与某**参考资产**收益率之差。参考资产通常取**无风险资产**，如短期美国国库券。

$$Z_t = R_t - R_{0t}, \qquad z_t = r_t - r_{0t} \tag{1.7}$$

- 金融含义：超额收益率可看作一个**套利组合的收益**——零净初始投资，**做多该资产、做空参考资产**。

> **备注（多/空机制）**：
> - **多头（long）** = 持有资产。
> - **空头（short）** = 卖出自己不拥有的资产：先从持有者处**借入**资产卖出，日后须买回**相同数量**的股份归还出借人。
> - 因为归还的是"等数量股份"而非"等金额"，价格下跌对空头有利。
> - 空头存续期间若派发现金红利，红利归股票的买方；**卖空者须自掏腰包向出借人补偿等额红利**。

### 1.1.9 关系汇总

**简单收益率 ↔ 对数收益率**：

$$r_t = \ln(1+R_t), \qquad R_t = e^{r_t} - 1$$

若以**百分比**计：

$$r_t = 100\ln\left(1 + \frac{R_t}{100}\right), \qquad R_t = 100\left(e^{r_t/100} - 1\right)$$

**时间聚合**：

$$1 + R_t[k] = \prod_{j=0}^{k-1}(1+R_{t-j}) \quad\text{（连乘）}$$
$$r_t[k] = r_t + r_{t-1} + \cdots + r_{t-k+1} \quad\text{（连加）}$$

**现值终值**（连续复利率 r）：$A = Ce^{rn}$，$C = Ae^{-rn}$。

> **例 1.1**：资产月对数收益率 4.46% → 对应月简单收益率 $100(e^{4.46/100}-1) = 4.56\%$。
> 若一个季度内三个月的对数收益率分别为 4.46%、−7.34%、10.77% → 季度对数收益率 = 4.46 − 7.34 + 10.77 = **7.89%**（直接相加）。

## 1.2 收益率的分布性质（pp. 7–21）

- 研究设置：N 个资产、T 个时期，$r_{it}$ = 资产 i 在时刻 t 的对数收益率。
- 研究对象：$\{r_{it};\ i=1,\dots,N;\ t=1,\dots,T\}$；同样也可研究简单收益率 $\{R_{it}\}$ 或对数超额收益率 $\{z_{it}\}$。
- 目标：理解收益率**跨资产、跨时间**的行为。

### 1.2.1 统计分布与矩复习

记号：$\mathbb{R}^k$ = k 维欧氏空间；随机向量 $X = (X_1,\dots,X_k)'$，$Y = (Y_1,\dots,Y_q)'$；本书多数情况假设随机向量连续。

**联合分布**：

$$F_{X,Y}(x,y;\theta) = P(X \le x,\ Y \le y;\ \theta)$$

若联合密度 $f_{x,y}(x,y;\theta)$ 存在，则 $F_{X,Y}(x,y;\theta) = \int_{-\infty}^{x}\int_{-\infty}^{y} f_{x,y}(w,z;\theta)\,dz\,dw$。

**边际分布**：把 Y"积分积掉"：

$$F_X(x;\theta) = F_{X,Y}(x, \infty, \dots, \infty;\ \theta)$$

**标量情形（k=1）**：$F_X(x) = P(X \le x)$ 即**累积分布函数（CDF）**。性质：
- 单调不减（$x_1 \le x_2 \Rightarrow F_X(x_1) \le F_X(x_2)$）
- $F_X(-\infty) = 0$，$F_X(\infty) = 1$

**分位数（quantile）**：给定概率 p，X 的 100p 分位数是满足 $p \le F_X(x_p)$ 的**最小**实数：

$$x_p = \inf_x \{x \mid p \le F_X(x)\}$$

（本书用 CDF 计算检验统计量的 p 值。）

**条件分布**：

$$F_{X|Y\le y}(x;\theta) = \frac{P(X\le x,\ Y\le y;\ \theta)}{P(Y\le y;\ \theta)}$$

密度存在时，给定 $Y=y$ 的条件密度：

$$f_{x|y}(x;\theta) = \frac{f_{x,y}(x,y;\theta)}{f_y(y;\theta)} \tag{1.8}$$

其中边际密度 $f_y(y;\theta) = \int_{-\infty}^{\infty} f_{x,y}(x,y;\theta)\,dx$。

**关键恒等式**（联合 = 条件 × 边际）：

$$f_{x,y}(x,y;\theta) = f_{x|y}(x;\theta) \times f_y(y;\theta) \tag{1.9}$$

> 这个恒等式在时间序列分析中被**大量使用**（如极大似然估计）。

**独立性**：$X \perp Y \iff f_{x|y}(x;\theta) = f_x(x;\theta)$，此时 $f_{x,y} = f_x \cdot f_y$。

**矩**：

- $\ell$ 阶矩：$m'_\ell = E(X^\ell) = \int x^\ell f(x)\,dx$；一阶矩 = **均值** $\mu_x$（中心位置）
- $\ell$ 阶中心矩：$m_\ell = E[(X-\mu_x)^\ell]$；二阶中心矩 = **方差** $\sigma_x^2$（离散程度），其正平方根 $\sigma_x$ = 标准差
- 前两个矩唯一确定正态分布；对其他分布还需高阶矩
- 三阶中心矩度量**对称性**，四阶中心矩度量**尾部行为**

**偏度与峰度**（标准化的三、四阶中心矩）：

$$S(x) = E\left[\frac{(X-\mu_x)^3}{\sigma_x^3}\right], \qquad K(x) = E\left[\frac{(X-\mu_x)^4}{\sigma_x^4}\right]$$

- $K(x) - 3$ 称**超额峰度（excess kurtosis）**（正态分布 $K=3$）。

**样本对应量**（样本 $\{x_1,\dots,x_T\}$）：

$$\hat\mu_x = \frac{1}{T}\sum_{t=1}^{T}x_t, \qquad \hat\sigma_x^2 = \frac{1}{T-1}\sum_{t=1}^{T}(x_t-\hat\mu_x)^2$$

$$\hat S(x) = \frac{1}{(T-1)\hat\sigma_x^3}\sum_{t=1}^{T}(x_t-\hat\mu_x)^3, \qquad \hat K(x) = \frac{1}{(T-1)\hat\sigma_x^4}\sum_{t=1}^{T}(x_t-\hat\mu_x)^4$$

（式 1.10–1.13）这些是理论矩的**一致估计**。

**均值检验**：$H_0: \mu_x = 0$ vs $H_a: \mu_x \neq 0$，统计量

$$t = \frac{\hat\mu_x}{\hat\sigma_x/\sqrt{T}}$$

渐近服从 $t_{T-1}$（大 T 时近似标准正态）；$|t| > Z_{\alpha/2}$ 时拒绝 $H_0$。

### 正态性检验（书 pp. 9–10）

正态假设下的渐近结果（Snedecor & Cochran, 1980, p. 78）：

$$\hat S(x) \overset{a}{\sim} N(0,\ 6/T), \qquad \hat K(x) - 3 \overset{a}{\sim} N(0,\ 24/T)$$

**偏度检验** $H_0: S(r)=0$ vs $H_a: S(r)\neq 0$：

$$t = \frac{\hat S(r)}{\sqrt{6/T}}$$

$|t| > Z_{\alpha/2}$ 或 p 值 < α 时拒绝。

**超额峰度检验** $H_0: K(r)-3=0$：

$$t = \frac{\hat K(r) - 3}{\sqrt{24/T}} \overset{a}{\sim} N(0,1)$$

**Jarque–Bera 联合检验**（Jarque & Bera, 1987）：

$$JB = \frac{\hat S^2(r)}{6/T} + \frac{[\hat K(r)-3]^2}{24/T} \overset{a}{\sim} \chi^2(2)$$

p 值 < α 时拒绝正态性。

> **例 1.2（IBM 日简单收益率，1970–2008，T = 9845）**：
> - 样本偏度 0.0614 → $t = 0.0614/\sqrt{6/9845} = 0.0614/0.0247 = 2.49$，p ≈ 0.013 → 5% 水平下**显著右偏**
> - 超额峰度 9.92 → **厚尾**明确
> - （R/S-Plus 演示见附录笔记部分）

### 1.2.2 收益率的分布（pp. 14–18）

**最一般的模型**：全部 N×T 个对数收益率的联合分布

$$F_r(r_{11},\dots,r_{N1};\ r_{12},\dots,r_{N2};\ \dots;\ r_{1T},\dots,r_{NT};\ Y;\ \theta) \tag{1.14}$$

- $Y$ = **状态向量**：概括资产收益率所处经济环境的变量
- $\theta$ = 唯一决定分布的参数向量
- 多数金融研究把 $Y$ 视为给定，关注给定 $Y$ 下 $\{r_{it}\}$ 的**条件分布**
- 实证分析 = 估计未知参数 $\theta$ + 对收益率行为做统计推断
- 该式太一般、无实用价值，但提供了把任何计量模型"放到合适位置"的**统一框架**

**两类研究视角**：
- CAPM（Sharpe, 1964）等金融理论：关注**单时点截面**联合分布 $\{r_{1t},\dots,r_{Nt}\}$
- 本书第 2–7 章：关注**单资产时间维度**联合分布 $\{r_{i1},\dots,r_{iT}\}$

**核心分解**（省略下标 i 与参数 θ）：

$$F(r_{i1},\dots,r_{iT}) = F(r_{i1})\,F(r_{i2}|r_{i1})\cdots F(r_{iT}|r_{i,T-1},\dots,r_{i1}) = F(r_{i1})\prod_{t=2}^{T}F(r_{it}\,|\,r_{i,t-1},\dots,r_{i1}) \tag{1.15}$$

- 该分解凸显 $r_{it}$ 的**时间依赖性**
- **主要问题 = 条件分布 $F(r_{it}|r_{i,t-1},\cdot)$ 的设定**，特别是它如何随时间演化
- 不同的分布设定 → 不同的金融理论。例：**随机游走假说**的一个版本就是 $F(r_{it}|r_{i,t-1},\dots) = F(r_{it})$（条件分布 = 边际分布）→ 收益率时序独立 → **不可预测**

**密度形式**（低频收益率视为连续变量时）：

$$f(r_{i1},\dots,r_{iT};\theta) = f(r_{i1};\theta)\prod_{t=2}^{T}f(r_{it}\,|\,r_{i,t-1},\dots,r_{i1};\theta) \tag{1.16}$$

- **高频收益率的离散性**问题（价格以最小报价单位跳动）→ 第 5 章处理

> **备注（十进制报价改革）**：2000-08-28 NYSE 以 7 只股票试点十进制报价，AMEX 以 6 只股票和 2 个期权类别试点；NYSE 于 2000-09-25、12-04 分别增加 57 只和 94 只；**2001-01-29 起 NYSE/AMEX 全部股票采用十进制报价**。

**条件分布 vs 边际分布**：(1.16) 说明研究收益率时条件分布更本质；但边际分布仍有意义——用历史数据估计边际分布更容易，且当收益率序列相关很弱时，边际分布 ≈ 条件分布。

**文献中边际分布的四种候选**：

**① 正态分布**：传统假设 $\{R_{it}\}$ iid $N(\mu, \sigma^2)$。
- 优点：统计性质易处理
- 困难：
  1. 简单收益率有下界 −1，正态分布取值于整个实轴、无下界
  2. 多期简单收益率是单期的**乘积**，不再是正态
  3. 实证收益率普遍有**正超额峰度**，正态不成立

**② 对数正态分布**：假设对数收益率 $r_t$ iid $N(\mu, \sigma^2)$，则简单收益率 $R_t$ iid 对数正态：

$$E(R_t) = \exp\left(\mu + \frac{\sigma^2}{2}\right) - 1, \qquad \text{Var}(R_t) = \exp(2\mu + \sigma^2)\left[\exp(\sigma^2) - 1\right] \tag{1.17}$$

- 这两个公式在**用对数收益率模型做预测**时很有用
- 反向换算：设 $m_1, m_2$ 为简单收益率的均值与方差，则对应对数收益率：

$$E(r_t) = \ln\left[\frac{m_1+1}{\sqrt{1 + m_2/(1+m_1)^2}}\right], \qquad \text{Var}(r_t) = \ln\left[1 + \frac{m_2}{(1+m_1)^2}\right]$$

- 优点：iid 正态之和仍正态 → $r_t[k]$ 也正态；$r_t$ 无下界问题；$1+R_t = e^{r_t}$ 自动满足下界
- 缺点：仍与"正超额峰度"不符

**③ 稳态分布（Stable Distribution）**：
- 是正态的自然推广：**加法封闭**（stable under addition），契合对数收益率的可加性
- 能捕捉历史收益率的超额峰度
- 致命伤：非正态稳态分布**方差不存在（无限）**，与多数金融理论冲突；且统计建模困难
- 例：Cauchy 分布——关于中位数对称，但方差无限

**④ 正态的尺度混合（Scale Mixture）/ 有限混合**：
- 尺度混合：$r_t \sim N(\mu, \sigma^2)$，但 $\sigma^2$ 是**随机变量**，服从某个正值分布（例：$\sigma^{-2}$ 服从 Gamma 分布）
- 有限混合：

$$r_t \sim (1-X)\,N(\mu, \sigma_1^2) + X\,N(\mu, \sigma_2^2)$$

X 为 Bernoulli：$P(X=1) = \alpha$，$0 < \alpha < 1$，$\sigma_1^2$ 小、$\sigma_2^2$ 大。
- 例：α = 0.05 → 95% 的收益率来自 $N(\mu,\sigma_1^2)$，5% 来自 $N(\mu,\sigma_2^2)$；大方差分布给尾部加了质量
- 优点：保持正态的可处理性、**高阶矩有限**、能捕捉超额峰度
- 缺点：混合参数（如 α）难估计

> **图 1.1**：标准正态、Cauchy、正态有限混合三个密度的比较。Cauchy 密度为 $f(x) = 1/[\pi(1+x^2)]$。尾部厚度排序：**Cauchy > 正态混合 > 标准正态**。

### 1.2.3 多元收益率（p. 18）

- $\boldsymbol{r}_t = (r_{1t},\dots,r_{Nt})'$ = t 时刻 N 个资产的对数收益率向量
- 第 8、10 章关心 $\{\boldsymbol r_t\}_{t=1}^T$ 的联合分布，同样按 (1.15) 分解，焦点是条件分布 $F(\boldsymbol r_t|\boldsymbol r_{t-1},\dots,\boldsymbol r_1,\theta)$ 的设定——**特别是条件期望与条件协方差矩阵如何随时间演化**（第 8、10 章主题）

**均值向量与协方差矩阵**（随机向量 $X=(X_1,\dots,X_p)'$）：

$$E(X) = \boldsymbol\mu_x = [E(X_1),\dots,E(X_p)]', \qquad \text{Cov}(X) = \boldsymbol\Sigma_x = E[(X-\boldsymbol\mu_x)(X-\boldsymbol\mu_x)']$$

**样本版本**：

$$\hat{\boldsymbol\mu}_x = \frac{1}{T}\sum_{t=1}^{T}\boldsymbol x_t, \qquad \hat{\boldsymbol\Sigma}_x = \frac{1}{T-1}\sum_{t=1}^{T}(\boldsymbol x_t - \hat{\boldsymbol\mu}_x)(\boldsymbol x_t - \hat{\boldsymbol\mu}_x)'$$

协方差阵存在时，样本统计量是理论值的**一致估计**。金融文献常用**多元正态**假设刻画 $\boldsymbol r_t$。

### 1.2.4 收益率的似然函数（p. 19）

利用分解 (1.15)：若条件分布 $f(r_t|r_{t-1},\dots,r_1,\theta)$ 为 $N(\mu_t, \sigma_t^2)$（θ 由 $\mu_t$、$\sigma_t^2$ 中的参数构成），则数据的**似然函数**：

$$f(r_1,\dots,r_T;\theta) = f(r_1;\theta)\prod_{t=2}^{T}\frac{1}{\sqrt{2\pi}\,\sigma_t}\exp\left[-\frac{(r_t-\mu_t)^2}{2\sigma_t^2}\right] \tag{1.18}$$

其中 $f(r_1;\theta)$ 是首个观测的边际密度。最大化此函数的 θ 即 **MLE（极大似然估计）**。

**对数似然**（实践中更好处理，因 ln 单调）：

$$\ln f(r_1,\dots,r_T;\theta) = \ln f(r_1;\theta) - \frac{1}{2}\sum_{t=2}^{T}\left[\ln(2\pi) + \ln\sigma_t^2 + \frac{(r_t-\mu_t)^2}{\sigma_t^2}\right]$$

条件分布非正态时可类似写出。

> 💡 **这是全书的统一估计框架**：后面 ARMA 模型对 $\mu_t$ 建模、GARCH 对 $\sigma_t^2$ 建模，都套用这个对数似然。

## 附录：R 包使用（pp. 24–25）

- 读数据：`da = read.table("file.txt", header=T)`
- 描述统计：`library(fBasics); basicStats(x)` 一键输出 nobs、最值、四分位数、均值、中位数、标准误、95% 置信区间、方差、标准差、偏度、（超额）峰度
- ⚠️ **R 中 `kurtosis` 报告的是超额峰度（减过 3）；S-Plus 中 `kurtosis` 是原始峰度（不减 3）**——例 1.2 中 R 输出 9.92 vs S-Plus 输出 12.92，同一数据
- 时间序列对象：`gm1 = ts(gm, frequency=12, start=c(1975,1))`
  - `frequency=12`：时间单位为年、每年 12 个等间隔观测；`start=c(1975,1)`：始于 1975 年 1 月
  - 用 ts 对象后，`plot()`、`acf()` 的横轴自动是正确的时间刻度（**图 1.7/1.8**：GM 月收益率 1975–2008 的时序图与 ACF 图，有/无 ts 对象的对比）
- R 与 S-Plus 多数命令相同

## R / S-Plus 演示详解（例 1.2 配套，pp. 11–14）

数据：`d-ibm3dx7008.txt`（9845 行 × 5 列：Date, rtn, vwretd, ewretd, sprtrn），即 IBM、价值加权、等权、S&P 的日收益率，1970-01-02 起。

**R 演示**：
```r
library(fBasics)
da = read.table("d-ibm3dx7008.txt", header=T)
ibm = da[,2];  sibm = ibm*100        # IBM 百分比简单收益率
basicStats(sibm)                      # 全部描述统计
# 关键输出：Mean 0.040161, Stdev 1.692544, Skewness 0.061399,
#          Kurtosis(超额) 9.916359, Min -22.963, Max 13.1636

# 偏度检验
s1 = skewness(sibm)
t1 = s1/sqrt(6/9845)     # → 2.487093
pv = 2*(1-pnorm(t1))     # → 0.01287919（5% 水平显著）

# 对数收益率
libm = log(ibm+1)*100
t.test(libm)             # t=1.5126, df=9844, p=0.1304
                         # → 不能拒绝均值为 0（95% CI: [-0.00764, 0.05929]）
normalTest(libm, method='jb')   # JB = 60921.93, p < 2.2e-16
                                # → 强烈拒绝正态性
```

**S-Plus 演示**：加载 `module(finmetrics)`，用 `summaryStats()`；其余命令与 R 基本一致；注意 kurtosis 口径差异（见上）。
