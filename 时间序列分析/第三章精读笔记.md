## 引言：为什么波动率重要

**本章目标**：研究对资产收益率**波动率**建模的方法与计量模型，统称**条件异方差模型（conditional heteroscedastic models）**。

**波动率 = 标的资产收益率的条件标准差**。核心应用：

1. **期权定价**：Black–Scholes 欧式看涨期权公式
$$c_t = P_t\Phi(x) - Ke^{-r\ell}\Phi(x - \sigma_t\sqrt{\ell}), \quad x = \frac{\ln(P_t/K) + r\ell}{\sigma_t\sqrt{\ell}} + \frac{1}{2}\sigma_t\sqrt{\ell} \tag{3.1}$$
K = 执行价，ℓ = 到期时间（年），r = 连续复利无风险利率，$\sigma_t$ = **年化条件标准差**——直接决定期权价格（推导见第 6 章；到期前随时可行权的是**美式期权**）
2. **风险管理**：计算 VaR 的简单途径（第 7 章）
3. **资产配置**：均值–方差框架下的关键输入
4. **统计意义**：波动率建模可提高参数估计效率与区间预测精度
5. **波动率指数本身已成金融工具**：CBOE 的 VIX 于 2004-03-26 开始有期货交易

**本章模型清单**：ARCH（Engle 1982）、GARCH（Bollerslev 1986）、EGARCH（Nelson 1991）、TGARCH/GJR（Glosten–Jagannathan–Runkle 1993；Zakoian 1994）、CHARMA（Tsay 1987）、RCA（Nicholls–Quinn 1982）、SV（Melino–Turnbull 1990；Taylor 1994；Harvey–Ruiz–Shephard 1994；Jacquier–Polson–Rossi 1994）。多元波动率模型见第 10 章。

---

## 3.1 波动率的特征

**特殊之处：波动率不可直接观测**。日收益一天只有一个观测，无法直接算日波动率；有盘中高频数据可估计（见 3.15），但需注意：股票波动率 = 盘中波动 + **隔夜波动**，高频盘中收益对隔夜波动信息很有限。不可观测性也使得**评估波动率模型的预测表现**变得困难。VIX 是**隐含波动率**。

**波动率的四大经验特征**（模型发展的驱动力）：

1. **波动率聚类（volatility clustering）**：某些时期高、某些时期低
2. **连续演化**：波动率跳跃很罕见
3. **不发散**：在固定范围内变化 → 统计上波动率**通常是平稳的**
4. **杠杆效应（leverage effect）**：波动率对大涨和大跌**反应不对称**（大跌后波动率上升更多）

许多模型就是为弥补前人模型无法刻画这些特征而提出的（如 EGARCH 专为捕捉不对称性）。

## 3.2 模型结构

基本思想：**收益率序列 {r_t} 序列不相关（或只有低阶弱相关），但它是相依序列**。
- 例（Intel 月对数收益 1973–2008，图 3.1/3.2）：收益率本身 ACF 基本不显著（仅 lag 7 略有）；但 **|rₜ| 和 rₜ² 的 ACF 显著** → 序列不相关但**不独立**。波动率模型就是要刻画这种依赖。

**条件矩分解**：给定 $F_{t-1}$（t−1 时刻信息集）：
$$\mu_t = E(r_t|F_{t-1}), \qquad \sigma_t^2 = \text{Var}(r_t|F_{t-1}) \tag{3.2}$$

**均值方程**：一般形式
$$r_t = \mu_t + a_t, \qquad \mu_t = \sum_{i=1}^{p}\phi_i y_{t-i} - \sum_{i=1}^{q}\theta_i a_{t-i}, \quad y_t = r_t - \phi_0 - \sum_{i=1}^{k}\beta_i x_{it} \tag{3.3}$$
- 即第 2 章"带时间序列误差的回归"的应用
- 均值方程的阶依赖数据频率（指数日收益常有弱相关，月收益可能没有）
- 解释变量灵活：周一哑变量（周末效应）、CAPM 形式 $r_t = \phi_0 + \beta r_{m,t} + a_t$ 等

**波动率方程**：
$$\sigma_t^2 = \text{Var}(r_t|F_{t-1}) = \text{Var}(a_t|F_{t-1}) \tag{3.4}$$
**$\sigma_t^2$ 随时间的演化方式区分不同的波动率模型**。

**两大类**：
1. 用**确定函数**刻画 $\sigma_t^2$ 演化 → GARCH 家族
2. 用**随机方程**刻画 $\sigma_t^2$ 演化 → 随机波动率（SV）模型

术语：$a_t$ = t 时刻收益率的**冲击/新息**；$\sigma_t$ = $\sigma_t^2$ 的正平方根；(3.3) = **均值方程**；$\sigma_t^2$ 的模型 = **波动率方程**。

## 3.3 建模步骤（四步）

1. **定均值方程**：检验序列相关；多数收益率序列相关很弱 → 往往只需**减去显著非零的样本均值**；某些日收益需简单 AR；个别情况加解释变量（周末/一月效应哑变量）
2. 对残差 $a_t = r_t - \hat\mu_t$ **检验 ARCH 效应**
3. 若 ARCH 效应显著 → 设定波动率模型并**联合估计**均值与波动率方程
4. **检验拟合模型**，必要时候改进

### 3.3.1 ARCH 效应检验（两种）

**① McLeod–Li (1983)**：对 $\{a_t^2\}$ 直接算 Ljung–Box Q(m)，$H_0$：$a_t^2$ 前 m 阶 ACF 全为 0。

**② Engle (1982) LM 检验**：等价于回归
$$a_t^2 = \alpha_0 + \alpha_1 a_{t-1}^2 + \cdots + \alpha_m a_{t-m}^2 + e_t, \quad t = m+1,\dots,T$$
中检验 $H_0: \alpha_1 = \cdots = \alpha_m = 0$ 的 F 统计量：
$$F = \frac{(\text{SSR}_0 - \text{SSR}_1)/m}{\text{SSR}_1/(T-2m-1)} \overset{a}{\sim} \chi^2(m)$$
其中 $\text{SSR}_0 = \sum(a_t^2 - \bar\omega)^2$（$\bar\omega$ = $a_t^2$ 样本均值），$\text{SSR}_1 = \sum \hat e_t^2$。

**例（Intel 月对数收益，T=432）**：收益率 Q(12)=18.26（p=0.11）无序列相关；但 ARCH 检验 LM=53.62（p≈0）、$a_t^2$ 的 Q(12)=89.85（p=5.3×10⁻¹⁴）→ **ARCH 效应高度显著**。

## 3.4 ARCH 模型（Engle 1982）

**基本思想**：(a) 冲击 $a_t$ **序列不相关但相依**；(b) 依赖可用**滞后值的简单二次函数**刻画。

**ARCH(m)**：
$$a_t = \sigma_t\epsilon_t, \qquad \sigma_t^2 = \alpha_0 + \alpha_1 a_{t-1}^2 + \cdots + \alpha_m a_{t-m}^2 \tag{3.5}$$
- $\{\epsilon_t\}$ iid，均值 0、方差 1；$\alpha_0 > 0$，$\alpha_i \ge 0$（保证 $\sigma_t^2 > 0$；可加正则条件保证无条件方差有限）
- $\epsilon_t$ 常取标准正态、标准化 t、或 GED（广义误差分布）
- 结构含义：**过去大冲击 → 大的 $\sigma_t^2$ → $a_t$ 倾向于大**（"tend"——方差大只是实现值大的概率高）→ 与波动率聚类吻合
- 例：马克/美元 10 分钟汇率变动（1989-06，T=2488）：序列本身无相关，但平方序列 PACF 有大尖峰 → ARCH 效应（图 3.3/3.4）
- 备注：有些作者用 $h_t$ 记条件方差，冲击写 $a_t = \sqrt{h_t}\epsilon_t$

### 3.4.1 ARCH(1) 的性质

$a_t = \sigma_t\epsilon_t$，$\sigma_t^2 = \alpha_0 + \alpha_1 a_{t-1}^2$：

1. **无条件均值 = 0**：$E(a_t) = E[\sigma_t E(\epsilon_t)] = 0$
2. **无条件方差**（叠期望）：
$$\text{Var}(a_t) = \frac{\alpha_0}{1-\alpha_1}, \quad \text{要求 } 0 \le \alpha_1 < 1$$
3. **四阶矩与厚尾**（正态 ε 下，用 $E(a_t^4|F_{t-1}) = 3\sigma_t^4$）：
$$E(a_t^4) = \frac{3\alpha_0^2(1+\alpha_1)}{(1-\alpha_1)(1-3\alpha_1^2)}$$
   - 四阶矩存在需 $1 - 3\alpha_1^2 > 0$，即 $0 \le \alpha_1^2 < 1/3$
   - **无条件峰度**：
$$\frac{E(a_t^4)}{[\text{Var}(a_t)]^2} = \frac{3(1-\alpha_1^2)}{1-3\alpha_1^2} > 3$$
→ **超额峰度为正、尾部厚于正态**——条件高斯 ARCH(1) 比高斯白噪声更容易产生"异常值"，与实证吻合！

高阶 ARCH 性质相同但公式更繁。$\alpha_i \ge 0$ 可放松为二次型形式：
$$a_t = \sigma_t\epsilon_t, \quad \sigma_t^2 = \alpha_0 + A_{m,t-1}'\Omega A_{m,t-1} \tag{3.6}$$
$A_{m,t-1} = (a_{t-1},\dots,a_{t-m})'$，Ω 非负定；Engle 原模型对应 Ω 对角（简约）。

### 3.4.2 ARCH 的弱点

1. **正负冲击影响对称**（依赖平方）——与实际不符（杠杆效应）
2. **约束强**：ARCH(1) 四阶矩存在需 $\alpha_1^2 < 1/3$；高阶更复杂；限制了高斯 ARCH 捕捉超额峰度的能力
3. **不提供波动来源的经济解释**——只是机械描述条件方差的行为
4. **对孤立大冲击反应慢** → 容易**高估**后续波动率

### 3.4.3 ARCH 建模

**定阶**：用 $a_t^2$ 的 **PACF**。理由：$a_t^2$ 是 $\sigma_t^2$ 的无偏估计，ARCH 模型可写成
$$a_t^2 = \alpha_0 + \alpha_1 a_{t-1}^2 + \cdots + \alpha_m a_{t-m}^2 + \eta_t$$
其中 $\eta_t = a_t^2 - \sigma_t^2$ 是**零均值不相关**序列（但非同分布）——形式上是 $a_t^2$ 的 AR(m)，故可用 PACF 定 m（注意 OLS 一致但不有效；小样本 PACF 可能不好用）。

**估计（条件 MLE）**：正态假设下略去复杂的初始联合密度，条件对数似然：
$$\ell = -\sum_{t=m+1}^{T}\left[\frac{1}{2}\ln\sigma_t^2 + \frac{1}{2}\frac{a_t^2}{\sigma_t^2}\right]$$
$\sigma_t^2$ 可递推算出。

**厚尾分布**：
- **标准化 Student-t**（自由度 v>2）：$\epsilon_t = x_v/\sqrt{v/(v-2)}$，密度
$$f(\epsilon_t|v) = \frac{\Gamma((v+1)/2)}{\Gamma(v/2)\sqrt{(v-2)\pi}}\left(1 + \frac{\epsilon_t^2}{v-2}\right)^{-(v+1)/2} \tag{3.7}$$
v 可预先指定（常取 4–8）或联合估计。对数似然见 (3.8) 及联合估计版。
- **偏斜 Student-t**（Fernández–Steel 1998 方法，Lambert–Laurent 2001 应用）：密度 (3.9)，$\xi$ 为偏度参数（$\xi^2$ = 众数上下概率质量之比）
- **GED（广义误差分布）**：
$$f(x) = \frac{v\exp(-\frac{1}{2}|x/\lambda|^v)}{\lambda 2^{(1+1/v)}\Gamma(1/v)}, \quad 0 < v \le \infty \tag{3.10}$$
v=2 退化为正态，v<2 厚尾。R fGarch 包有 `sstd`/`snorm`/`sged`。

**模型检验**：标准化残差
$$\tilde a_t = \frac{a_t}{\sigma_t}$$
应近似 iid。用 Ljung–Box 查 $\tilde a_t$（均值方程充分性）与 $\tilde a_t^2$（波动率方程充分性）；偏度、峰度、QQ 图查分布假设。

**预测**（类似 AR 递推）：
$$\sigma_h^2(\ell) = \alpha_0 + \sum_{i=1}^{m}\alpha_i\sigma_h^2(\ell-i), \quad \sigma_h^2(j) = a_{h+j}^2\ (j\le0) \tag{3.11}$$

### 3.4.4 例题

> **例 3.1（Intel 月对数收益 1973–2008）**：$a_t^2$ 的 PACF 提示 ARCH(3)。高斯 ARCH(3) 中 α₂、α₃ 不显著 → 简化为 **ARCH(1)**：
> $$r_t = 0.0126 + a_t, \quad \sigma_t^2 = 0.0111 + 0.3560a_{t-1}^2 \tag{3.12}$$
> 标准化残差 Q(10)=12.64（p=0.24），平方标准化残差 Q(10)=14.75（p=0.14）→ 充分。有意思的性质：① 月均对数收益约 1.26%（样本含互联网泡沫后时期，可观）；② $\hat\alpha_1^2 = 0.356^2 < 1/3$ → 四阶矩存在；③ 无条件标准差 $\sqrt{0.0111/(1-0.356)} \approx 0.1315$
>
> **t 新息版**：$r_t = 0.0169 + a_t$，$\sigma_t^2 = 0.0120 + 0.2845a_{t-1}^2$ (3.13)，自由度估计 6.01（标准误 1.50）。无条件标准差 ≈ 0.1295（接近高斯版）。均值方程 OK（Q(12)=14.88, p=0.25），但平方标准化残差 Q(12)=35.42（p=0.0004）→ **波动率方程不充分**（源于 lag-12 ACF=0.188）。两点结论：(a) 厚尾分布**降低 ARCH 系数**；(b) 本例两模型差异不大。更合适的是 GARCH(1,1)（下节）

> **例 3.2（马克/美元 10 分钟汇率）**：ARCH(3)：$\sigma_t^2 = 0.22\times10^{-2} + 0.322a_{t-1}^2 + 0.074a_{t-2}^2 + 0.093a_{t-3}^2$，系数均显著，标准化残差检验通过。

## 3.5 GARCH 模型（Bollerslev 1986）

动机：ARCH 常需很高阶（如 S&P 500 月超额收益需 ARCH(9)）→ 需要更简约的模型。

**GARCH(m,s)**：
$$a_t = \sigma_t\epsilon_t, \qquad \sigma_t^2 = \alpha_0 + \sum_{i=1}^{m}\alpha_i a_{t-i}^2 + \sum_{j=1}^{s}\beta_j\sigma_{t-j}^2 \tag{3.14}$$
- $\alpha_0 > 0$，$\alpha_i,\beta_j \ge 0$，$\sum_{i=1}^{\max(m,s)}(\alpha_i+\beta_i) < 1$（⇒ 无条件方差有限，条件方差随时间演化）
- $\alpha_i$ = ARCH 参数，$\beta_j$ = GARCH 参数；s=0 退化为 ARCH(m)

**关键表示**：令 $\eta_t = a_t^2 - \sigma_t^2$（可验证 $\{\eta_t\}$ 是**鞅差序列**：$E(\eta_t)=0$、$\text{cov}(\eta_t,\eta_{t-j})=0$），则
$$a_t^2 = \alpha_0 + \sum_{i=1}^{\max(m,s)}(\alpha_i+\beta_i)a_{t-i}^2 + \eta_t - \sum_{j=1}^{s}\beta_j\eta_{t-j} \tag{3.15}$$
→ **GARCH = 对 $a_t^2$ 应用 ARMA 思想**！无条件方差：
$$E(a_t^2) = \frac{\alpha_0}{1-\sum(\alpha_i+\beta_i)}$$

**GARCH(1,1) 的三条性质**：
$$\sigma_t^2 = \alpha_0 + \alpha_1 a_{t-1}^2 + \beta_1\sigma_{t-1}^2, \quad (\alpha_1+\beta_1)<1 \tag{3.16}$$
1. 大的 $a_{t-1}^2$ **或** $\sigma_{t-1}^2$ → 大的 $\sigma_t^2$ → 波动率聚类
2. 若 $1-2\alpha_1^2-(\alpha_1+\beta_1)^2 > 0$，峰度 $\dfrac{3[1-(\alpha_1+\beta_1)^2]}{1-(\alpha_1+\beta_1)^2-2\alpha_1^2} > 3$ → **厚尾**
3. 提供简约参数函数描述波动率演化

**预测**：1 步直接代入；多步用 $a_t^2 = \sigma_t^2\epsilon_t^2$ 改写后取期望（$E(\epsilon^2-1|F)=0$）：
$$\sigma_h^2(\ell) = \alpha_0 + (\alpha_1+\beta_1)\sigma_h^2(\ell-1), \quad \ell > 1 \tag{3.17}$$
（同 AR 多项式为 $1-(\alpha_1+\beta_1)B$ 的 ARMA(1,1) 的预测形式）⇒
$$\sigma_h^2(\ell) = \frac{\alpha_0[1-(\alpha_1+\beta_1)^{\ell-1}]}{1-\alpha_1-\beta_1} + (\alpha_1+\beta_1)^{\ell-1}\sigma_h^2(1) \;\xrightarrow{\ell\to\infty}\; \frac{\alpha_0}{1-\alpha_1-\beta_1}$$
多步波动率预测收敛到**无条件方差**（α₁+β₁<1 时）。

**弱点**：与 ARCH 相同——正负冲击对称；且高频数据显示即使用 t 新息，**GARCH 的尾部仍偏短**（见 3.16）。

### 3.5.1 示例（S&P 500 月超额收益 1926 起，T=792）

- 均值：$r_t$ 在 lag 1、3 有弱相关；先拟合 AR(3)：
$$r_t = 0.088r_{t-1} - 0.023r_{t-2} - 0.123r_{t-3} + 0.0066 + a_t \tag{3.18}$$
- 联合估计 AR(3)–GARCH(1,1) 后 AR 系数全不显著 → 简化为：
$$r_t = 0.0076 + a_t, \quad \sigma_t^2 = 0.000086 + 0.1216a_{t-1}^2 + 0.8511\sigma_{t-1}^2 \tag{3.19}$$
- 无条件方差 0.000086/(1−0.8511−0.1216) = 0.00314（与 AR(3) 的 0.00333 接近）
- 标准化残差 Q(12)=11.99（p=0.45）、平方的 Q(12)=13.11（p=0.36）→ 充分
- ⚠️ $\hat\alpha_1+\hat\beta_1 = 0.9772 \approx 1$ —— **实务中常见** → 引出 IGARCH（3.6 节）
- 预测（表 3.1）：波动率预测从 0.0536 缓慢收敛到无条件值 0.0560
- **t 新息（v=5 预设）**：$\sigma_t^2 = 0.00012 + 0.1121a_{t-1}^2 + 0.8432\sigma_{t-1}^2$ (3.20)，α+β≈0.95，残差检验通过
- **自由度也估计**：v̂ = 7.02（标准误 1.78）→ 5% 水平不能拒绝 v=5 (3.21)

### 3.5.2 预测评估的困难

波动率不可观测 → 比较难。有人用样本外 $\sigma_h^2(\ell)$ 对 $a_{h+\ell}^2$ 回归，常得**低 R²**——这不奇怪：$E(a_{h+1}^2|F_h) = \sigma_{h+1}^2$，$a_{h+1}^2$ 是 $\sigma^2$ 的**一致但极不准确**的估计（单个观测估不准方差）→ 这种评估方法**严格说不恰当**。参见 Andersen & Bollerslev (1998)。

### 3.5.3 两步估计法

基于 (3.15)：① 忽略 ARCH 效应先估均值方程得残差 $a_t$；② 把 $\{a_t^2\}$ 当观测序列按 ARMA 估计 (3.15)，则 $\hat\beta_i = \hat\theta_i$，$\hat\alpha_i = \hat\phi_i - \hat\theta_i$。是近似估计，理论性质未严格研究，但中大样本下近似效果好（S&P 例：$\hat\beta_1 = 0.8456$、$\hat\alpha_1 = 0.1127$，与 (3.19) 很接近）。

## 3.6 IGARCH（积分 GARCH）

当 $\alpha_1 + \beta_1 = 1$：**IGARCH(1,1)**：
$$\sigma_t^2 = \alpha_0 + \beta_1\sigma_{t-1}^2 + (1-\beta_1)a_{t-1}^2$$
- S&P 月超额收益拟合：$\sigma_t^2 = 0.000119 + 0.8059\sigma_{t-1}^2 + 0.1941a_{t-1}^2$
- ⚠️ **无条件方差不存在**（对超额收益序列难以从理论上合理化；IGARCH 现象可能源于**波动率的偶尔水平移动（level shifts）**，持续性的真正来源值得研究）
- 预测（由 (3.17) 反复代入）：
$$\sigma_h^2(\ell) = \sigma_h^2(1) + (\ell-1)\alpha_0 \tag{3.22}$$
→ 预测呈**斜率 α₀ 的直线**；$\sigma_h^2(1)$ 的影响**永久持续**
- Nelson (1990)：$\sigma_t^2$ 是**鞅**；某些条件下严平稳但非弱平稳（前两阶矩不存在）
- **特例 α₀=0**：所有预测 = $\sigma_h^2(1)$；这就是 **RiskMetrics（VaR 计算，第 7 章）** 用的模型！也是 $\{a_t^2\}$ 的**指数平滑**：
$$\sigma_t^2 = (1-\beta_1)(a_{t-1}^2 + \beta_1 a_{t-2}^2 + \beta_1^2 a_{t-3}^2 + \cdots)$$
β₁ 为贴现因子。

---

## 3.7 GARCH-M（均值中的 GARCH）

金融含义：**收益率可能依赖于自身波动率**（风险溢价）。

**GARCH(1,1)-M**：
$$r_t = \mu + c\sigma_t^2 + a_t, \quad a_t = \sigma_t\epsilon_t, \quad \sigma_t^2 = \alpha_0 + \alpha_1 a_{t-1}^2 + \beta_1\sigma_{t-1}^2 \tag{3.23}$$
- **c = 风险溢价参数**；c>0 表示收益率与波动率正相关
- 变体：$r_t = \mu + c\sigma_t + a_t$ 或 $\mu + c\ln\sigma_t^2 + a_t$（S-Plus 命令 `var.in.mean`/`sd.in.mean`/`logvar.in.mean`，表 3.2）
- 含义：$\{\sigma_t^2\}$ 的序列相关**给 $r_t$ 引入序列相关** → **风险溢价是历史收益率存在序列相关的另一个原因**
- 例（S&P 月超额收益）：$r_t = 0.0055 + 1.09\sigma_t^2 + a_t$，风险溢价为正但 **5% 水平不显著**（标准误 0.818）

## 3.8 EGARCH（指数 GARCH，Nelson 1991）

为捕捉**正负冲击的不对称影响**，Nelson 考虑**加权新息**：
$$g(\epsilon_t) = \theta\epsilon_t + \gamma[|\epsilon_t| - E(|\epsilon_t|)] \tag{3.24}$$
- $\epsilon_t$ 与 $|\epsilon_t|-E|\epsilon_t|$ 都是零均值 iid ⇒ $E[g(\epsilon_t)] = 0$
- 分段看不对称性：$\epsilon_t \ge 0$ 时斜率 $(\theta+\gamma)$；$\epsilon_t < 0$ 时斜率 $(\theta-\gamma)$
- 标准正态：$E|\epsilon_t| = \sqrt{2/\pi}$；标准化 t 的 $E|\epsilon_t|$ 有专门公式

**EGARCH(m,s)**：
$$\ln(\sigma_t^2) = \alpha_0 + \frac{1+\beta_1 B + \cdots + \beta_{s-1}B^{s-1}}{1-\alpha_1 B - \cdots - \alpha_m B^m}g(\epsilon_{t-1}) \tag{3.25}$$
- 对 $\ln\sigma_t^2$ 用 ARMA 参数化（多项式零点在单位圆外、无公因子）
- **两大优势**：① 取对数 → **无需参数非负约束**；② g(ε) → **不对称响应**
- $E[\ln\sigma_t^2] = \alpha_0$

**EGARCH(1,1)（正态 ε）**：
$$\sigma_t^2 = \sigma_{t-1}^{2\alpha}e^{\alpha^*} \times \begin{cases} \exp[(\gamma+\theta)\frac{a_{t-1}}{\sigma_{t-1}}] & a_{t-1}\ge0 \\ \exp[(\gamma-\theta)\frac{|a_{t-1}|}{\sigma_{t-1}}] & a_{t-1}<0 \end{cases}$$
$\alpha^* = (1-\alpha)\alpha_0 - \sqrt{2/\pi}\,\gamma$。形式类似门限自回归（TAR）的非线性函数；**θ≠0 即非线性；负冲击影响更大 → 预期 θ < 0**。

**替代形式（S-Plus 采用）**：
$$\ln\sigma_t^2 = \alpha_0 + \sum_{i=1}^{s}\alpha_i\frac{|a_{t-i}| + \gamma_i a_{t-i}}{\sigma_{t-i}} + \sum_{j=1}^{m}\beta_j\ln\sigma_{t-j}^2 \tag{3.28}$$
- 正 $a_{t-i}$ 贡献 $\alpha_i(1+\gamma_i)|\epsilon_{t-i}|$，负 $a_{t-i}$ 贡献 $\alpha_i(1-\gamma_i)|\epsilon_{t-i}|$ → **γᵢ 即杠杆效应参数，预期为负**

> **例 3.2 之二（Nelson 原例：价值加权指数日超额收益 1962–1987，T=6408）**：
> $$r_t = \phi_0 + \phi_1 r_{t-1} + c\sigma_t^2 + a_t, \quad \ln\sigma_t^2 = \alpha_0 + \ln(1+wN_t) + \frac{1+\beta B}{1-\alpha_1 B - \alpha_2 B^2}g(\epsilon_{t-1}) \tag{3.29}$$
> $N_t$ = 两交易日间的**非交易日数**（周末效应）；ε 取 GED。表 3.3：θ=−0.118（不对称显著），风险溢价 c=−3.361 为负但不显著。

> **例（IBM 月对数收益 1926–1997，T=864）**：AR(1)–EGARCH(1,1)：
> $$r_t = 0.0105 + 0.092r_{t-1} + a_t \tag{3.30}$$
> $$\ln\sigma_t^2 = \frac{-5.496 + g(\epsilon_{t-1})}{1-0.856B}, \quad g(\epsilon_{t-1}) = -0.0795\epsilon_{t-1} + 0.2647(|\epsilon_{t-1}| - \sqrt{2/\pi}) \tag{3.31}$$
> 残差检验全通过。反对数化后：$\epsilon_{t-1}\ge0$ 时系数 0.1852、<0 时 −0.3442。**量化杠杆**：两个标准差冲击（ε=±2）：
> $$\frac{\sigma_t^2(\epsilon_{t-1}=-2)}{\sigma_t^2(\epsilon_{t-1}=2)} = \frac{e^{0.6884}}{e^{0.3704}} = e^{0.318} = 1.374$$
> **同等大小的负冲击对波动率的影响比正冲击高约 37.4%**；冲击越大差异越大。
> 扩展样本（至 2003，GED 新息）的替代形式拟合：$\ln\sigma_t^2 = -0.557 + 0.220\frac{|a_{t-1}|}{\sigma_{t-1}} - 0.264\frac{a_{t-1}}{\sigma_{t-1}} + 0.929\ln\sigma_{t-1}^2$ (3.32)，杠杆参数 t=−2.094 显著为负。

**EGARCH(1,1) 多步预测**（正态）：利用
$$E\{e^{g(\epsilon)}\} = e^{-\gamma\sqrt{2/\pi}}\left[e^{(\theta+\gamma)^2/2}\Phi(\theta+\gamma) + e^{(\theta-\gamma)^2/2}\Phi(\gamma-\theta)\right]$$
递推公式：
$$\hat\sigma_h^2(j) = \hat\sigma_h^2(j-1)^{\alpha_1}e^{\omega}\left[e^{(\theta+\gamma)^2/2}\Phi(\theta+\gamma) + e^{(\theta-\gamma)^2/2}\Phi(\gamma-\theta)\right]$$
$\omega = (1-\alpha_1)\alpha_0 - \gamma\sqrt{2/\pi}$。IBM 例：原点 t=864 的预测 6.05→4.94×10⁻³，渐收敛到冲击样本方差 4.37×10⁻³。

## 3.9 TGARCH（门限 GARCH，GJR 模型）

**TGARCH(m,s)**（Glosten–Jagannathan–Runkle 1993；Zakoian 1994）：
$$\sigma_t^2 = \alpha_0 + \sum_{i=1}^{s}(\alpha_i + \gamma_i N_{t-i})a_{t-i}^2 + \sum_{j=1}^{m}\beta_j\sigma_{t-j}^2 \tag{3.34}$$
$$N_{t-i} = \begin{cases} 1 & a_{t-i}<0 \\ 0 & a_{t-i}\ge0 \end{cases}$$
- 正冲击贡献 $\alpha_i a_{t-i}^2$；**负冲击贡献 $(\alpha_i+\gamma_i)a_{t-i}^2$，γᵢ>0** → 门限 0 分离影响
- 也叫 **GJR 模型**

> **例（IBM 月对数收益 1926–2003，GED 新息）**：
> $$\sigma_t^2 = 3.45\times10^{-4} + (0.0658 + 0.0843N_{t-1})a_{t-1}^2 + 0.8182\sigma_{t-1}^2 \tag{3.35}$$
> GED 参数 1.51；Q(12)=18.34（p=0.106）、平方 Q(12)=5.36（p=0.95）→ 充分；**杠杆效应 5% 显著**。
> **与 EGARCH 比较**（±2 标准差冲击）：TGARCH 给出 1.312 vs EGARCH 1.264 → 杠杆幅度相近。

## 3.10 CHARMA（条件异方差 ARMA，Tsay 1987）

用**随机系数**产生条件异方差：
$$r_t = \mu_t + a_t, \qquad a_t = \delta_{1t}a_{t-1} + \cdots + \delta_{mt}a_{t-m} + \eta_t \tag{3.36}$$
- $\eta_t$ 高斯白噪声（方差 $\sigma_\eta^2$）；$\{\boldsymbol\delta_t\}$ iid 随机向量，均值 0、协方差阵 **Ω**（非负定），与 $\eta_t$ 独立
- 向量形式 $a_t = \boldsymbol a_{t-1}'\boldsymbol\delta_t + \eta_t$ ⇒ **条件方差**：
$$\sigma_t^2 = \sigma_\eta^2 + \boldsymbol a_{t-1}'\Omega\,\boldsymbol a_{t-1} = \sigma_\eta^2 + (a_{t-1},\dots,a_{t-m})\Omega(a_{t-1},\dots,a_{t-m})' \tag{3.37}$$
- m=1 → ARCH(1)；**Ω 对角 → 等价 ARCH(m)**；m=2 时多出**交叉项** $2\omega_{12}a_{t-1}a_{t-2}$
- **σ² 正性自动满足**（Ω 非负定 + σ²_η>0）
- 与 ARCH 的区别：交叉乘积项可刻画**前期收益率的交互作用**；但项数随 m 激增需约束；高阶性质比 ARCH 难推导
- 例（S&P 月超额收益）：$\sigma_t^2 \approx 0.00136 + 0.12a_{t-1}^2 - 0.12a_{t-1}a_{t-2} + 0.19a_{t-2}^2 + 0.30a_{t-3}^2$；交叉项显著 → $a_{t-1}a_{t-2}$ 为负时条件方差略大

**3.10.1 解释变量推广**：$a_t = \sum_{i=1}^{m}\delta_{it}x_{i,t-1} + \eta_t$ (3.38) ⇒ $\sigma_t^2 = \sigma_\eta^2 + \boldsymbol x_{t-1}'\Omega\boldsymbol x_{t-1}$。

## 3.11 RCA（随机系数自回归，Nicholls–Quinn 1982）

$$r_t = \phi_0 + \sum_{i=1}^{p}(\phi_i + \delta_{it})r_{t-i} + a_t \tag{3.39}$$
- 原本用于刻画不同个体间差异（类似面板数据/层次模型）
- 条件均值 = 普通 AR(p)；**条件方差** $\sigma_t^2 = \sigma_a^2 + (r_{t-1},\dots,r_{t-p})\Omega_\delta(r_{t-1},\dots,r_{t-p})'$
- **与 CHARMA 的细微区别**：RCA 的波动率是**观测到的滞后收益率** $r_{t-i}$ 的二次型；CHARMA 是**滞后新息** $a_{t-i}$ 的二次型

## 3.12 随机波动率（SV）模型

思路：给条件方差方程**加一个自身的新息**。为保证正性用 $\ln\sigma_t^2$：
$$a_t = \sigma_t\epsilon_t, \qquad (1-\alpha_1 B - \cdots - \alpha_m B^m)\ln\sigma_t^2 = \alpha_0 + v_t \tag{3.40}$$
- $\epsilon_t$ iid N(0,1)，$v_t$ iid N(0, $\sigma_v^2$)，两者独立；多项式零点模 > 1
- **优点**：新息 $v_t$ 大幅增加描述 $\sigma_t^2$ 演化的灵活性
- **代价**：估计困难——每个冲击 $a_t$ 对应**两个新息**（ε 和 v）→ 需 Kalman 滤波的**准似然法**或 **MCMC**（第 12 章）；JPR(1994) 比较了两种方法
- m=1 的性质（JPR 附录）：$\ln\sigma_t^2 \sim N\left(\frac{\alpha_0}{1-\alpha_1}, \frac{\sigma_v^2}{1-\alpha_1^2}\right)$；$E(a_t^2) = e^{\mu_h + \sigma_h^2/2}$；$\text{corr}(a_t^2, a_{t-i}^2) = \frac{\exp(\sigma_h^2\alpha_1^i)-1}{3\exp(\sigma_h^2)-1}$
- 经验：SV **拟合更好**，但**样本外预测贡献褒贬不一**

## 3.13 长记忆 SV 模型（LMSV）

动机：收益率平方/绝对值的 ACF **衰减缓慢**（Ding–Granger–Engle 1993；图 3.10：IBM 与 S&P 日绝对收益 ACF 缓慢衰减）。

$$a_t = \sigma_t\epsilon_t, \quad \sigma_t = \sigma\exp(u_t/2), \quad (1-B)^d u_t = \eta_t, \quad 0<d<0.5 \tag{3.41}$$
- 长记忆源于**分数差分** $(1-B)^d$：$u_t$ 的 ACF 以双曲速率衰减
- 变形：$\ln(a_t^2) = \mu + u_t + e_t$ = **高斯长记忆信号 + 非高斯白噪声**（Breidt–Crato–de Lima 1998）
- 估计复杂；d 可用准 MLE 或回归法
- 应用（Ray & Tsay 2000）：同行业公司有更多共同的长记忆成分（如大型美国银行/金融机构）

## 3.14 应用（IBM 与 S&P 500 月对数收益 1926–1999，T=888，百分比含分红）

> **例 3.4：股票夏季波动率是否更低？**（期权定价有实际含义）
>
> 基准 GARCH(1,1)：
> $$r_t = 1.23 + 0.099r_{t-1} + a_t, \quad \sigma_t^2 = 3.206 + 0.103a_{t-1}^2 + 0.825\sigma_{t-1}^2 \tag{3.42}$$
> 定义夏季哑变量 $u_t$（6/7/8 月=1）(3.43)，先在波动率方程放全套交互项 → 不显著 → 精炼为：
> $$\sigma_t^2 = 4.539 + 0.113a_{t-1}^2 + 0.816\sigma_{t-1}^2 \mathbf{- 5.154u_t} \tag{3.44}$$
> 系数 −5.154 显著（p=0.0067）→ **夏季效应 1% 水平显著，符号为负 → 夏季波动率确实更低**。
> 夏季的常数项 −0.615 反直觉 → 约束夏季常数为 0 重估：
> $$\sigma_t^2 = \alpha_1 a_{t-1}^2 + \beta_1\sigma_{t-1}^2 + \gamma(1-u_t) \tag{3.45}$$
> **定量结论**（用 1999 年中位数代入）：夏季 $\sigma_t^2 = 64.3$ vs 其他月 68.8 → **夏季波动率约低 7%**

> **例 3.5：成分股过去收益对指数波动率建模有无贡献？**
>
> S&P 500 基准（特殊 GARCH(2,1)）：$\sigma_t^2 = 0.717 + 0.147a_{t-2}^2 + 0.839\sigma_{t-1}^2$ (3.46)
> 加入 IBM 滞后 1 期收益作解释变量：$\sigma_t^2 = \cdots + \gamma x_{t-1}^2$ 类设定，γ 的 p=0.0039 → **1% 水平显著，负号**（用 IBM 过去收益可降低 S&P 波动率）。表 3.4：1999 年 7–12 月两模型波动率对比（如 12 月：22.46 vs 18.27）→ 确实有贡献。

## 3.15 其他波动率估计方法

### 3.15.1 高频数据（French–Schwert–Stambaugh 1987）

月收益 = 日收益之和：$r_t^m = \sum_{i=1}^{n}r_{t,i}$。
$$\text{Var}(r_t^m|F_{t-1}) = \sum_{i=1}^{n}\text{Var}(r_{t,i}) + 2\sum_{i<j}\text{Cov}(r_{t,i},r_{t,j}) \tag{3.48}$$
- 日收益白噪声假设：$\hat\sigma_m^2 = \dfrac{n}{n-1}\sum_{i=1}^{n}(r_{t,i}-\bar r_t)^2$ (3.49)
- MA(1) 假设：加协方差修正项 (3.50)
- **困难**：日收益模型未知（协方差难估）；每月约 21 个交易日样本小；日收益高峰度+序列相关时估计可能**不一致**（Bai–Russell–Tiao 2004）
- 例 3.6（S&P 月波动率 1980–1999）：基于日收益的估计**远高于**月收益 GARCH(1,1) 的估计；1987-10 日数据法估计高达 680
- **已实现波动率（Realized Volatility）**：若再设日均值 0，$\hat\sigma_m^2 \approx \sum r_{t,i}^2$ → 推广到日内：
$$RV_t = \sum_{i=1}^{n}r_{t,i}^2$$
（数学上是二次变差；假设日内收益 iid 零均值）。经验：$\ln(RV_t)$ 常近似高斯 ARIMA(0,1,q)，可用于预测。
  - **问题**：间隔太小 → 市场微观结构噪声（bid–ask bounce）→ 有偏；美国高流动性资产常用 **4–15 分钟**间隔；**隔夜收益可观，忽略会严重低估股票波动率**（指数/外汇的隔夜收益较小）
  - Barndorff-Nielsen & Shephard (2004)：用高频收益研究**双幂变差（bi-power variation）**检测跳跃

### 3.15.2 开、高、低、收价格（Range-based）

Garman–Klass (1980) 在无漂移扩散模型下比较多个估计量（C=收、O=开、H=高、L=低、Ct−1=前收）：
- $\hat\sigma_{0,t}^2 = (C_t-C_{t-1})^2$（基准）
- Parkinson：$\hat\sigma_{2,t}^2 = \dfrac{(H_t-L_t)^2}{4\ln 2} \approx 0.3607(H_t-L_t)^2$
- $\hat\sigma_{5,t}^2 = 0.5(H_t-L_t)^2 - [2\ln2 - 1](C_t-O_t)^2$
- **效率因子** Eff = Var(σ̂₀²)/Var(σ̂ᵢ²)：i=1,2,3,5,6 分别约 **2, 5.2, 6.2, 7.4, 8.4**——用价格区间信息效率提升数倍！

**Yang–Zhang (2000) 稳健估计**（标准化开/高/低/收：oₜ, uₜ, dₜ, cₜ）：
$$\hat\sigma_{yz}^2 = \hat\sigma_o^2 + k\hat\sigma_c^2 + (1-k)\hat\sigma_{rs}^2, \quad \hat\sigma_{rs}^2 = \frac{1}{n}\sum[u_t(u_t-c_t) + d_t(d_t-c_t)], \quad k = \frac{0.34}{1.34+(n+1)/(n-1)}$$
（$\hat\sigma_{rs}^2$ 来自 Rogers–Satchell 1991；k 使估计方差最小）

⚠️ **偏差**：实际观测的日高低于真实 Hₜ、日低高于真实 Lₜ → **观测区间低估真实区间 → 可能低估波动率**；偏差依赖交易频率与最小报价单位（高流动性股票可忽略）。

## 3.16 GARCH 模型的峰度

评估波动率估计的变动性需考虑模型的峰度。GARCH(1,1)：设 $E(\epsilon_t^4) = K_\epsilon + 3$（$K_\epsilon$ = 新息超额峰度）。对波动率方程平方取期望（需 $1-\alpha_1^2(K_\epsilon+2)-(\alpha_1+\beta_1)^2 > 0$），得 **$a_t$ 的超额峰度**：
$$K_a = \frac{(K_\epsilon+3)[1-(\alpha_1+\beta_1)^2]}{1-2\alpha_1^2-(\alpha_1+\beta_1)^2-K_\epsilon\alpha_1^2} - 3$$

**正态新息**（$K_\epsilon=0$）：
$$K_a^{(g)} = \frac{6\alpha_1^2}{1-2\alpha_1^2-(\alpha_1+\beta_1)^2}$$
含义：(a) 峰度存在需分母 > 0；(b) **α₁=0 ⇒ 无厚尾**——**α₁ 是决定尾部行为的关键**！

**非正态新息**（George Tiao 的结果，见 Bai–Russell–Tiao 2003，对所有 GARCH 成立）：
$$K_a = K_\epsilon + K_a^{(g)} + \frac{5}{6}K_\epsilon K_a^{(g)} \cdot \frac{1}{1-\frac{1}{6}K_\epsilon K_a^{(g)}}$$

**t 新息**（自由度 v>4）：$K_\epsilon = 6/(v-4)$；$K_a = \dfrac{6+(v+1)K_a^{(g)}}{v-4-K_a^{(g)}}$。这也是本书预设 t₅ 的部分原因。

| 模型 | 波动率方程 | 关键性质 |

| ARCH(m) | $\sigma_t^2 = \alpha_0 + \sum\alpha_i a_{t-i}^2$ | $\text{Var} = \alpha_0/(1-\sum\alpha_i)$；ARCH(1) 峰度 3(1−α₁²)/(1−3α₁²)>3 |
| GARCH(m,s) | +$\sum\beta_j\sigma_{t-j}^2$ | $a_t^2$ 的 ARMA；$\text{Var} = \alpha_0/(1-\sum(\alpha+\beta))$；预测 → 无条件方差 |
| IGARCH | α₁+β₁=1 | 无条件方差不存在；预测直线 (3.22)；α₀=0 ⇒ RiskMetrics/指数平滑 |
| GARCH-M | $r_t = \mu + c\sigma_t^2 + a_t$ | c = 风险溢价；波动率相关 ⇒ 收益率序列相关 |
| EGARCH | $\ln\sigma_t^2$ 的 ARMA + g(ε) | 无非负约束；杠杆效应 θ<0 |
| TGARCH/GJR | $(\alpha_i+\gamma_i N_{t-i})a_{t-i}^2$ | 负冲击多贡献 γᵢ；门限 0 |
| CHARMA | $\sigma_\eta^2 + \boldsymbol a'\Omega\boldsymbol a$ | 随机系数；σ² 自动为正；含交叉项 |
| RCA | 系数含随机扰动 | 波动率是观测滞后值的二次型 |
| SV | $\ln\sigma_t^2$ 有自己的新息 v_t | 灵活；需 Kalman/MCMC |
| LMSV | + 分数差分 (1−B)^d | 波动率长记忆 |
| 已实现波动率 | RV = Σr² | 高频；注意微观结构噪声与隔夜收益 |
| 区间法 | (H−L)²/4ln2 等 | 效率提升 2–8 倍；区间低估偏差 |
| GARCH 峰度 | $K_a^{(g)} = 6\alpha_1^2/(1-2\alpha_1^2-(\alpha_1+\beta_1)^2)$ | α₁ 决定尾部；t 新息 K_ε=6/(v−4) |
