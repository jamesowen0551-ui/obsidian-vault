## 章节定位

本章讲**线性时间序列的基本理论**（平稳性、动态依赖、ACF、建模、预测）与**简单计量模型**：AR、MA、ARMA、季节模型、单位根非平稳、带时间序列误差的回归、分数差分长记忆模型。对收益率 $r_t$ 而言，简单模型试图刻画 $r_t$ 与 t 之前信息之间的**线性关系**；相关（尤其序列相关/自相关）是理解这些模型的基本工具。参考书目：Box–Jenkins–Reinsel (1994)、Brockwell–Davis (1996)。

## 2.1 平稳性（Stationarity）

**严平稳（strict stationarity）**：对任意 k、任意时点 $(t_1,\dots,t_k)$ 和任意 t，$(r_{t_1},\dots,r_{t_k})$ 与 $(r_{t_1+t},\dots,r_{t_k+t})$ 的联合分布相同——即联合分布在**时间平移下不变**。条件很强，实证上难以验证。

**弱平稳（weak stationarity）**：均值与自协方差都不随时间变化：
- (a) $E(r_t) = \mu$（常数）
- (b) $\text{Cov}(r_t, r_{t-\ell}) = \gamma_\ell$（只依赖滞后 ℓ）

- 实践含义：时序图应表现为 T 个观测围绕**固定水平以恒定波动**起伏；弱平稳使对未来观测的推断（如预测）成为可能。
- 隐含假设：前两阶矩有限。
- **严平稳 + 前两阶矩有限 ⇒ 弱平稳**；反之一般不成立；但若序列**正态**，弱平稳 ⇔ 严平稳。
- 本书主要关心弱平稳序列。

**自协方差** $\gamma_\ell = \text{Cov}(r_t, r_{t-\ell})$ 的两条重要性质：
- (a) $\gamma_0 = \text{Var}(r_t)$
- (b) $\gamma_{-\ell} = \gamma_\ell$（对称性）

**金融应用**：文献通常假设资产收益率弱平稳；可用**分子样本检验一致性**来实证检查（把数据分段，看各段结果是否一致）。

## 2.2 相关系数与自相关函数（ACF）

**样本相关系数**：$\hat\rho_{x,y} = \dfrac{\sum_t (x_t-\bar x)(y_t-\bar y)}{\sqrt{\sum_t(x_t-\bar x)^2 \sum_t (y_t-\bar y)^2}}$

### 滞后 ℓ 自相关

对弱平稳序列 $r_t$：
$$\rho_\ell = \frac{\text{Cov}(r_t, r_{t-\ell})}{\sqrt{\text{Var}(r_t)\text{Var}(r_{t-\ell})}} = \frac{\text{Cov}(r_t, r_{t-\ell})}{\text{Var}(r_t)} = \frac{\gamma_\ell}{\gamma_0} \tag{2.1}$$

性质：$\rho_0 = 1$，$\rho_\ell = \rho_{-\ell}$，$-1 \le \rho_\ell \le 1$；**$r_t$ 无序列相关 ⇔ 所有 ℓ>0 有 $\rho_\ell = 0$**。

**样本 ACF**：设 $\bar r = \sum r_t / T$，
$$\hat\rho_\ell = \frac{\sum_{t=\ell+1}^{T}(r_t-\bar r)(r_{t-\ell}-\bar r)}{\sum_{t=1}^{T}(r_t-\bar r)^2}, \quad 0 \le \ell < T-1 \tag{2.2}$$

**渐近性质**：
- 若 $\{r_t\}$ iid 且 $E(r_t^2) < \infty$，则 $\hat\rho_\ell \overset{a}{\sim} N(0, 1/T)$（Brockwell & Davis 定理 7.2.2）
- 更一般地，若 $r_t = \mu + \sum_{i=0}^{q}\psi_i a_{t-i}$（白噪声驱动），则对 $\ell > q$：$\text{Var}(\hat\rho_\ell) = (1 + 2\sum_{i=1}^{q}\rho_i^2)/T$ —— 即 **Bartlett 公式**

### 单个 ACF 检验

$H_0: \rho_\ell = 0$ vs $H_a: \rho_\ell \neq 0$，统计量：
$$t = \frac{\hat\rho_\ell}{\sqrt{(1 + 2\sum_{i=1}^{\ell-1}\hat\rho_i^2)/T}}$$
渐近标准正态；$|t| > Z_{\alpha/2}$ 拒绝。许多软件对所有 ℓ 直接用 1/T（即默认 iid）。有限样本下 $\hat\rho_\ell$ 有 $O(1/T)$ 的偏差，金融样本 T 大、通常不严重。

### 混合检验（Portmanteau Test）

联合检验 $H_0: \rho_1 = \cdots = \rho_m = 0$。

- **Box–Pierce**：$Q^*(m) = T\sum_{\ell=1}^{m}\hat\rho_\ell^2 \overset{a}{\sim} \chi^2(m)$
- **Ljung–Box**（有限样本下功效更高）：
$$Q(m) = T(T+2)\sum_{\ell=1}^{m}\frac{\hat\rho_\ell^2}{T-\ell} \tag{2.3}$$
拒绝规则：$Q(m) > \chi^2_\alpha(m)$（或 p 值 < α）。
- **m 的选择**：模拟研究显示 $m \approx \ln(T)$ 功效较好；**季节序列**应取季节周期倍数的 m。

### 实证例子（IBM vs 价值加权指数，月收益率 1926–2008）

- **图 2.1**：IBM 月简单/对数收益率的样本 ACF 都很小，全在 ±2 倍标准误内；$Q(5)=3.37$（p=0.64），$Q(10)=13.99$（p=0.17）→ **IBM 月收益率无显著序列相关**
- **图 2.2**：价值加权指数月收益率的 ACF 有若干显著；$Q(5)=29.71$、$Q(10)=39.55$（简单），$Q(5)=28.38$、$Q(10)=36.16$（对数），p 均 < 0.0001 → **指数月收益率有序列相关**
- 结论：**市场指数的序列依赖强于个股**
- 联系 CAPM/有效市场：CAPM 的一个版本认为收益率不可预测、应无自相关；检验零自相关被用作**有效市场检验工具**。但价格决定方式与指数构建方式本身可能引入自相关（高频数据中 bid–ask bounce、非同步交易 → 第 5 章）

**R 演示**：`Box.test(sibm, lag=5, type='Ljung')` → X²=3.3682, p=0.6434；对数收益率 Q(5)=3.5236, p=0.6198。

## 2.3 白噪声与线性时间序列

**白噪声**：iid、均值方差有限的序列；若 $r_t \sim N(0, \sigma^2)$ 则称**高斯白噪声**。白噪声的所有 ACF 为零。由图 2.1/2.2：IBM 月收益率**接近白噪声**，价值加权指数**不是**。

**线性时间序列**：$r_t$ 可写成
$$r_t = \mu + \sum_{i=0}^{\infty}\psi_i a_{t-i} \tag{2.4}$$
- $\psi_0 = 1$；$\{a_t\}$ 白噪声（均值 0、方差 $\sigma_a^2$）
- $a_t$ = t 时刻的**新信息**，称**新息（innovation）或冲击（shock）**
- 系数 $\psi_i$ 称 **ψ 权重（psi weights）**

**均值与方差**（利用 $\{a_t\}$ 独立性）：
$$E(r_t) = \mu, \qquad \text{Var}(r_t) = \sigma_a^2\sum_{i=0}^{\infty}\psi_i^2 \tag{2.5}$$
- 方差有限 ⇒ $\psi_i^2 \to 0$（$i\to\infty$）→ **遥远冲击的影响逐渐消失**

**自协方差**（推导用 $E(a_t a_s)=0$, $t\neq s$）：
$$\gamma_\ell = \sigma_a^2\sum_{j=0}^{\infty}\psi_j\psi_{j+\ell} \tag{2.6}$$

**ACF 与 ψ 权重的关系**：
$$\rho_\ell = \frac{\sum_{i=0}^{\infty}\psi_i\psi_{i+\ell}}{1 + \sum_{i=1}^{\infty}\psi_i^2}, \quad \ell \ge 0 \tag{2.7}$$

- 线性时间序列模型就是**描述 ψ 权重模式**的模型；平稳序列 $\rho_\ell \to 0$（ℓ→∞），即当前收益率对遥远过去的线性依赖逐渐消失。

## 2.4 简单 AR 模型

动机：价值加权指数月收益率滞后 1 阶自相关显著 → 可用 $r_{t-1}$ 预测 $r_t$。

**AR(1)**：
$$r_t = \phi_0 + \phi_1 r_{t-1} + a_t \tag{2.8}$$
- 形式上同简单线性回归（$r_{t-1}$ 作解释变量）；也广泛用于随机波动率建模（$r_t$ 换成对数波动率，第 3、12 章）
- **条件性质**：$E(r_t|r_{t-1}) = \phi_0 + \phi_1 r_{t-1}$，$\text{Var}(r_t|r_{t-1}) = \sigma_a^2$
- **马尔可夫性**：给定 $r_{t-1}$，$r_t$ 与 $r_{t-i}$（i>1）不相关

**AR(p)**：
$$r_t = \phi_0 + \phi_1 r_{t-1} + \cdots + \phi_p r_{t-p} + a_t \tag{2.9}$$
过去 p 个滞后值共同决定条件期望；形式上同多元线性回归。

### 2.4.1 AR 模型的性质

**AR(1) 的均值**：对 (2.8) 取期望（$E(a_t)=0$），平稳下 $E(r_t)=E(r_{t-1})=\mu$：
$$\mu = \phi_0 + \phi_1\mu \;\Rightarrow\; E(r_t) = \mu = \frac{\phi_0}{1-\phi_1}$$
含义：① 均值存在需 $\phi_1 \neq 1$；② $\mu = 0$ ⇔ $\phi_0 = 0$；③ $\phi_0 = (1-\phi_1)\mu$。

**均值调整形式**：用 $\phi_0 = (1-\phi_1)\mu$ 重写：
$$r_t - \mu = \phi_1(r_{t-1} - \mu) + a_t \tag{2.10}$$

**MA(∞) 表示**（反复代入）：
$$r_t - \mu = a_t + \phi_1 a_{t-1} + \phi_1^2 a_{t-2} + \cdots = \sum_{i=0}^{\infty}\phi_1^i a_{t-i} \tag{2.11}$$
即 ψ 权重 $\psi_i = \phi_1^i$。推论：$E[(r_{t-1}-\mu)a_t] = 0$（$r_{t-1}$ 发生在 $a_t$ 之前）。

**方差**：对 (2.10) 平方取期望，利用 $\text{Cov}(r_{t-1}, a_t)=0$ 与 $\text{Var}(r_t)=\text{Var}(r_{t-1})$：
$$\text{Var}(r_t) = \frac{\sigma_a^2}{1-\phi_1^2}, \quad \text{要求 } \phi_1^2 < 1$$

**平稳性充要条件**：$|\phi_1| < 1$（证明两个方向：平稳 ⇒ 方差有界非负 ⇒ $|\phi_1|<1$；$|\phi_1|<1$ ⇒ 由 (2.11) 与 (2.5)/(2.6) 均值、方差、自协方差均有限且不随时间变）。

金融文献常用写法 $r_t = (1-\phi_1)\mu + \phi_1 r_{t-1} + a_t$，**φ₁ 度量动态依赖的持续性（persistence）**。

**AR(1) 的 ACF**：(2.10) 乘 $(r_{t-\ell}-\mu)$ 取期望：
$$\gamma_\ell = \begin{cases} \phi_1\gamma_1 + \sigma_a^2 & \ell = 0 \\ \phi_1\gamma_{\ell-1} & \ell > 0 \end{cases} \;\Rightarrow\; \rho_\ell = \phi_1^\ell$$
**ACF 以速率 φ₁ 指数衰减**；φ₁>0 时单调指数衰减，φ₁<0 时呈**两个交替的指数衰减**（速率 $\phi_1^2$）。图 2.3：φ₁=0.8 与 φ₁=−0.8 的 ACF。

**AR(2)**：
$$r_t = \phi_0 + \phi_1 r_{t-1} + \phi_2 r_{t-2} + a_t \tag{2.12}$$
- 均值：$E(r_t) = \dfrac{\phi_0}{1-\phi_1-\phi_2}$（要求 $\phi_1+\phi_2 \neq 1$）
- **矩方程**：$\gamma_\ell = \phi_1\gamma_{\ell-1} + \phi_2\gamma_{\ell-2}$（ℓ>0）
- **ACF 差分方程**：$\rho_\ell = \phi_1\rho_{\ell-1} + \phi_2\rho_{\ell-2}$（ℓ>0）(2.13)，即 $(1-\phi_1 B - \phi_2 B^2)\rho_\ell = 0$，其中 **B = 后移算子**（$B\rho_\ell = \rho_{\ell-1}$；有人记作 L，lag operator）
- 初值：$\rho_0 = 1$，$\rho_1 = \dfrac{\phi_1}{1-\phi_2}$，$\rho_\ell$（ℓ≥2）递推

**特征方程与特征根**：对应二阶多项式方程
$$1 - \phi_1 x - \phi_2 x^2 = 0 \tag{2.14}$$
解 $x = \dfrac{\phi_1 \pm \sqrt{\phi_1^2 + 4\phi_2}}{-2\phi_2}$；两解的**倒数** $\omega_1, \omega_2$ 称**特征根**。
- 两实根：模型可分解为 $(1-\omega_1 B)(1-\omega_2 B)$，相当于两个 AR(1) 叠加 → ACF 是**两个指数衰减的混合**
- $\phi_1^2 + 4\phi_2 < 0$：**共轭复根** → ACF 呈**阻尼正余弦波** → 对应**商业周期（business cycles）**！经济时间序列模型常有复特征根
- 复根时**随机周期的平均长度**：
$$k = \frac{2\pi}{\cos^{-1}[\phi_1/(2\sqrt{-\phi_2})]}$$
（复解写 $a\pm bi$ 时 $\phi_1=2a$，$\phi_2=-(a^2+b^2)$，$k = 2\pi/\cos^{-1}(a/\sqrt{a^2+b^2})$）

图 2.4：四个 AR(2) 的 ACF：(b) $(1-0.6B+0.4B^2)$ 因 $0.36+4(-0.4)=-1.24<0$ 有复根、ACF 阻尼波动；其余三个实根、ACF 指数衰减。

> **例 2.1（美国季度实际 GNP 增长率，1947.II–1991.I，季节调整）**：拟合 AR(3)：
> $$r_t = 0.0047 + 0.348r_{t-1} + 0.179r_{t-2} - 0.142r_{t-3} + a_t, \quad \hat\sigma_a = 0.0097 \tag{2.15}$$
> 特征多项式分解：$1 - 0.348B - 0.179B^2 + 0.142B^3 \approx (1+0.521B)(1 - 0.869B + 0.274B^2)$
> - 第一个因子 → 指数衰减成分
> - 第二个因子：$0.869^2 + 4(-0.274) = -0.341 < 0$ → **随机商业周期存在**
> - 平均周期长度 $k = 2\pi/\cos^{-1}[0.869/(2\sqrt{0.274})] \approx \mathbf{10.62}$ **个季度 ≈ 3 年**
> - 与第 4 章非线性模型结果对照：收缩期平均约 3 个季度、扩张期约 3 年；10.62 个季度是两者的折中。OECD 国家增长率也有类似周期特征

**AR(2) 平稳性条件**：两特征根的模都 < 1 ⇔ 特征方程两解的模都 > 1。此条件保证 $\rho_\ell \to 0$。AR(1) 是特例：特征根 $\omega = \phi_1$。

**AR(p) 推广**：
- 均值 $E(r_t) = \dfrac{\phi_0}{1-\phi_1-\cdots-\phi_p}$
- 特征方程 $1 - \phi_1 x - \cdots - \phi_p x^p = 0$，所有解模 > 1（⇔ 特征根模 < 1）→ 平稳
- ACF 满足 $(1-\phi_1 B - \cdots - \phi_p B^p)\rho_\ell = 0$（ℓ>0），图形 = 阻尼正余弦 + 指数衰减的混合

### 2.4.2 AR 模型的定阶（Identifying AR Models）

**① 偏自相关函数（PACF）**：依次拟合 AR(1), AR(2), …：
- 第 j 个方程中 $r_{t-j}$ 系数的估计 $\hat\phi_{j,j}$ 就是 **lag-j 样本 PACF**
- 含义：lag-2 PACF = $r_{t-2}$ 在 AR(1) 之上的**新增贡献**；lag-3 = 在 AR(2) 之上的新增贡献……（类似多元回归中的偏 F 检验思想）
- **AR(p) 的 PACF 性质**：$\hat\phi_{p,p} \to \phi_p$；$\hat\phi_{\ell,\ell} \to 0$（ℓ>p）；ℓ>p 时渐近方差为 1/T → **PACF 在 lag p 后截尾（cuts off）**
- 例：价值加权指数月收益（T=996，渐近标准误 ≈ 0.032）：5% 水平下识别 AR(3) 或 AR(9)；1% 水平下 AR(3)。表 2.1：PACF 前 12 阶为 0.115, −0.030, −0.102, 0.033, …

**② 信息准则**：
- **AIC**（Akaike 1973）：
$$\text{AIC} = -\frac{2}{T}\ln(\text{likelihood}) + \frac{2}{T}\times(\text{参数个数}) \tag{2.16}$$
高斯 AR(ℓ) 下简化为 $\text{AIC}(\ell) = \ln(\tilde\sigma_\ell^2) + \dfrac{2\ell}{T}$
  - 第一项度量拟合优度，第二项是**惩罚函数**（按参数个数惩罚）
- **BIC**（Schwarz–Bayesian）：$\text{BIC}(\ell) = \ln(\tilde\sigma_\ell^2) + \dfrac{\ell\ln(T)}{T}$
  - 每参数惩罚：AIC 为 2，BIC 为 ln T → **样本中/大时 BIC 倾向选更低阶**
- **选择规则**：对 ℓ=0,…,P 计算，取最小者
- 表 2.1 例：AIC 最小在 p=9（−5.849）；BIC 最小在 p=1（−5.833），p=3 紧随其后（−5.831）→ **不同准则可能给出不同阶**；实际选择还要考虑问题背景与简洁性
- GNP 例：R 的 `ar(gnp, method='mle')` 基于 AIC 选 AR(3)（注意 R 的 AIC 已调整为最小值为 0）

**参数估计**：常用**条件最小二乘**（从第 p+1 个观测开始）：条件于前 p 个观测，
$$r_t = \phi_0 + \phi_1 r_{t-1} + \cdots + \phi_p r_{t-p} + a_t, \quad t = p+1,\dots,T$$
按多元回归 OLS 估计。拟合值 $\hat r_t$、残差 $\hat a_t = r_t - \hat r_t$、
$$\hat\sigma_a^2 = \frac{\sum_{t=p+1}^{T}\hat a_t^2}{T - 2p - 1}$$
条件似然法 φ 估计相同，但 $\tilde\sigma_a^2 = \hat\sigma_a^2 \times (T-2p-1)/(T-p)$（有些软件除以 T）。

- 例（价值加权指数 AR(3)）：
$$r_t = 0.0091 + 0.116r_{t-1} - 0.019r_{t-2} - 0.104r_{t-3} + \hat a_t, \quad \hat\sigma_a = 0.054$$
标准误 0.002, 0.032, 0.032, 0.032；除 lag-2 外都在 1% 水平显著。AR 系数虽小但显著；$\hat\phi_0$ 显著 ⇒ 期望收益为正：$\hat\mu = 0.0091/(1-0.116+0.019+0.104) = 0.009$。
- **长期含义**：月均收益 0.9% ⇒ 年均简单总收益率 $\left[\prod_{t=1}^{996}(1+R_t)\right]^{12/996} - 1 \approx 9.3\%$；**1926 年初 1 美元 → 2008 年底约 1593 美元**（支持"股市长期向好"的常识）

**模型检验（Model Checking）**：
- 模型充分 ⇒ 残差应近似**白噪声**；用残差 ACF + Ljung–Box Q(m) 检查
- AR(p) 残差的 Q(m) 渐近 $\chi^2(m-g)$，g = AR 系数个数（自由度调整源于对残差的约束；**多数软件不做此调整**，m ≤ g 时可理解）
- 不充分则要改进：删不显著系数、扩展模型吸收残余相关
- 例：AR(3) 残差 Q(12)=16.35，按 χ²₉ p=0.060 → 勉强不拒绝；删掉不显著的 lag-2 后：
$$r_t = 0.0088 + 0.114r_{t-1} - 0.106r_{t-3} + a_t, \quad \hat\sigma_a = 0.0536$$
Q(12)=16.83，按 χ²₁₀ p=0.078 → 模型充分
- R 技巧：`arima(vw, order=c(3,0,0), fixed=c(NA,0,NA,NA))` 用 fixed 把 AR2 系数固定为 0；R 中 "intercept" 是**均值** μ，常数项要换算 $\phi_0 = (1-\sum\phi_i)\mu$

### 2.4.3 拟合优度

$$R^2 = 1 - \frac{\text{residual SS}}{\text{total SS}} = 1 - \frac{\sum_{t=p+1}^{T}\hat a_t^2}{\sum_{t=p+1}^{T}(r_t-\bar r)^2}$$
- $0 \le R^2 \le 1$；越大拟合越好——**仅对平稳序列成立**。⚠️ 对单位根非平稳序列，AR(1) 的 R² 随样本增大趋于 1，**与真实模型无关**
- R² 随参数个数不减 → **调整 R²**：
$$\text{Adj-}R^2 = 1 - \frac{\hat\sigma_a^2}{\hat\sigma_r^2}$$
（不再介于 0 和 1 之间）

### 2.4.4 预测

设定：预测原点（forecast origin）h，预测步长（horizon）ℓ；$F_h$ = h 时刻可得信息。**最小均方误差预测** = 条件期望。

**1 步**：
$$\hat r_h(1) = E(r_{h+1}|F_h) = \phi_0 + \sum_{i=1}^{p}\phi_i r_{h+1-i}, \quad e_h(1) = a_{h+1}, \quad \text{Var}[e_h(1)] = \sigma_a^2$$
- 正态时 95% 区间预测：$\hat r_h(1) \pm 1.96\sigma_a$
- $a_{t+1}$ 也是 t 为原点的 1 步预测误差 → 计量文献称 $a_{t+1}$ 为 t+1 时刻的**冲击**
- 实务用估计参数代入 → **条件预测**（忽略参数不确定性；理论上可用 MCMC 贝叶斯预测处理，第 12 章）

**2 步**：
$$\hat r_h(2) = \phi_0 + \phi_1\hat r_h(1) + \phi_2 r_h + \cdots, \quad e_h(2) = a_{h+2} + \phi_1 a_{h+1}, \quad \text{Var} = (1+\phi_1^2)\sigma_a^2$$
→ **预测步长越大、不确定性越大**（符合常识）。

**多步**：递推计算
$$\hat r_h(\ell) = \phi_0 + \sum_{i=1}^{p}\phi_i\hat r_h(\ell-i), \quad \hat r_h(i) = r_{h+i}\ (i \le 0)$$
- **均值回归（mean reversion）**：平稳 AR(p) 有 $\hat r_h(\ell) \to E(r_t)$（ℓ→∞），预测误差方差 → 序列无条件方差
- **半衰期（half-life）**（AR(1)）：$\ell = \ln(0.5)/\ln(|\phi_1|)$——均值调整序列的预测衰减到一半所需步长（由 $\phi_1^\ell = 1/2$ 解出）
- 表 2.2：价值加权指数 AR(3) 在原点 h=984（2007-12）的 1–12 步预测（0.0076, 0.0161, … → 0.0096），标准误快速收敛到 0.0540（= 数据标准差）；2008 年实际值多在 ±2 标准误内
- 图 2.7：样本外预测图（原点 2007-12，预测 o、实际 •、虚线 ±2 标准误）

## 2.5 简单 MA 模型

动机：① 白噪声的简单扩展；② **带约束的无穷阶 AR**（本书采用）：设 $\phi_i = -\theta_1^i$：
$$r_t = \phi_0 - \theta_1 r_{t-1} - \theta_1^2 r_{t-2} - \cdots + a_t \tag{2.17}$$
- 平稳需 $|\theta_1| < 1$（否则 $\theta_1^i$ 爆炸）；贡献随 i 指数衰减
- 把 $r_{t-1}$ 的方程乘 θ₁ 相减 ⇒ 除常数项外 $r_t$ 是 $a_t, a_{t-1}$ 的加权平均

**MA(1)**：
$$r_t = c_0 + a_t - \theta_1 a_{t-1} = c_0 + (1-\theta_1 B)a_t \tag{2.20}$$
**MA(2)**：$r_t = c_0 + a_t - \theta_1 a_{t-1} - \theta_2 a_{t-2}$ (2.21)
**MA(q)**：
$$r_t = c_0 + a_t - \theta_1 a_{t-1} - \cdots - \theta_q a_{t-q} = c_0 + (1-\theta_1 B - \cdots - \theta_q B^q)a_t \tag{2.22}$$

### 2.5.1 MA 模型性质

**平稳性**：MA **总是弱平稳**（白噪声的有限线性组合，前两阶矩不随时间变）。
- $E(r_t) = c_0$（**常数项就是均值**）
- $\text{Var}(r_t) = (1 + \theta_1^2 + \cdots + \theta_q^2)\sigma_a^2$

**ACF**（MA(1)，设 $c_0=0$）：模型乘 $r_{t-\ell}$ 取期望：
$$\gamma_1 = -\theta_1\sigma_a^2, \quad \gamma_\ell = 0\ (\ell>1) \;\Rightarrow\; \rho_0=1,\ \rho_1 = \frac{-\theta_1}{1+\theta_1^2},\ \rho_\ell = 0\ (\ell>1)$$
**ACF 在 lag 1 截尾**。MA(2)：
$$\rho_1 = \frac{-\theta_1 + \theta_1\theta_2}{1+\theta_1^2+\theta_2^2}, \quad \rho_2 = \frac{-\theta_2}{1+\theta_1^2+\theta_2^2}, \quad \rho_\ell = 0\ (\ell>2)$$
一般地 **MA(q) 的 ACF 在 lag q 截尾** → MA 是**"有限记忆"模型**。

**可逆性（Invertibility）**：零均值 MA(1) 写成 $a_t = r_t + \theta_1 a_{t-1}$，反复代入：
$$a_t = r_t + \theta_1 r_{t-1} + \theta_1^2 r_{t-2} + \cdots$$
直观上遥远收益对当前冲击影响应衰减 → 要求 $|\theta_1| < 1$，此时称 MA(1) **可逆**；$|\theta_1| = 1$ 不可逆。

### 2.5.2 MA 定阶

ACF 定阶：$\rho_q \neq 0$ 但 $\rho_\ell = 0$（ℓ>q）→ MA(q)。

- 例（CRSP **等权**指数月简单收益 1926–2008，图 2.8）：ACF 在 lag 1、3、9 显著 → 识别
$$r_t = c_0 + a_t - \theta_1 a_{t-1} - \theta_3 a_{t-3} - \theta_9 a_{t-9}$$
- 注意：**ACF 能指出 MA 非零滞后位置**（PACF 做不到）

### 2.5.3 估计

MA 用**极大似然**：
- **条件似然**：假设初始冲击 $a_t = 0$（t≤0），递推 $a_1 = r_1 - c_0$，$a_2 = r_2 - c_0 + \theta_1 a_1$, …
- **精确似然**：把初始冲击当作额外参数联合估计；接近不可逆时更优，但计算量大；大样本两者接近
- 例（等权指数 MA(9)）：
  - 条件似然：$r_t = 0.012 + a_t + 0.189a_{t-1} - 0.121a_{t-3} + 0.122a_{t-9}$，$\hat\sigma_a = 0.0714$ (2.23)；Q(12)=17.5，χ²₉ 下 p=0.041（χ²₁₂ 下 p=0.132）→ 勉强充分
  - 精确似然：系数几乎相同（0.191/−0.120/0.123）→ 本例两法差异可忽略

### 2.5.4 MA 预测

- MA(1) 1 步：$\hat r_h(1) = c_0 - \theta_1 a_h$，$e_h(1)=a_{h+1}$，方差 $\sigma_a^2$（$a_h$ 可递推或取残差）
- MA(1) 2 步起：$\hat r_h(\ell) = c_0$（ℓ≥2），方差 $(1+\theta_1^2)\sigma_a^2$ = 序列方差 → **均值回归只需 1 期**
- MA(2)：$\hat r_h(1) = c_0 - \theta_1 a_h - \theta_2 a_{h-1}$，$\hat r_h(2) = c_0 - \theta_2 a_h$，ℓ>2 后为 $c_0$
- 一般：**MA(q) 多步预测 q 步后回到均值**
- 表 2.3：等权指数 MA(9)（精确似然，原点 2008-02, h=986）10 步预测 = 样本均值 0.0128；标准误收敛到序列 SD 0.0734。实际值因**次贷危机 + 雷曼倒闭**大幅偏离点预测

**AR/MA 小结**：
- MA 定阶用 ACF（lag q 截尾）；AR 定阶用 PACF（lag p 截尾）
- MA 永远平稳；AR 平稳要求特征根模 < 1
- 平稳序列：多步预测 → 均值，预测误差方差 → 序列方差

## 2.6 简单 ARMA 模型

动机：纯 AR 或纯 MA 可能需要高阶、多参数；ARMA 把两者结合实现**参数简约（parsimony）**。收益率直接用 ARMA 的机会不多，但 **GARCH 可看作 $a_t^2$ 的非标准 ARMA**（第 3 章），概念极其重要。

**ARMA(1,1)**：
$$r_t - \phi_1 r_{t-1} = \phi_0 + a_t - \theta_1 a_{t-1} \tag{2.25}$$
左边 AR 部分、右边 MA 部分；需 $\phi_1 \neq \theta_1$，否则约分退化为白噪声。

### 2.6.1 ARMA(1,1) 性质

- **均值**：$E(r_t) = \mu = \dfrac{\phi_0}{1-\phi_1}$（与 AR(1) 相同）
- **方差**（设 $\phi_0=0$，用 $E(r_t a_t) = \sigma_a^2$ (2.26)）：
$$\text{Var}(r_t) = \frac{(1 - 2\phi_1\theta_1 + \theta_1^2)\sigma_a^2}{1-\phi_1^2}$$
方差为正 ⇒ **平稳条件 $|\phi_1|<1$**（与 AR(1) 相同）
- **ACF**：$\gamma_1 - \phi_1\gamma_0 = -\theta_1\sigma_a^2$（与 AR(1) 不同）；$\gamma_\ell - \phi_1\gamma_{\ell-1} = 0$（ℓ>1）(2.27) ⇒
$$\rho_1 = \phi_1 - \frac{\theta_1\sigma_a^2}{\gamma_0}, \qquad \rho_\ell = \phi_1\rho_{\ell-1}\ (\ell>1)$$
→ ACF 类似 AR(1)，但**指数衰减从 lag 2 开始**；**ACF 不在有限滞后截尾**
- **PACF**：也不截尾，类似 MA(1) 但衰减从 lag 2 开始

### 2.6.2 一般 ARMA(p,q)

$$r_t = \phi_0 + \sum_{i=1}^{p}\phi_i r_{t-i} + a_t - \sum_{i=1}^{q}\theta_i a_{t-i}$$
算子形式：
$$(1-\phi_1 B - \cdots - \phi_p B^p)r_t = \phi_0 + (1-\theta_1 B - \cdots - \theta_q B^q)a_t \tag{2.28}$$
- 左 = AR 多项式，右 = MA 多项式；要求**无公因子**（否则可降阶）
- 平稳条件：AR 特征方程所有解模 > 1；无条件均值 $E(r_t) = \phi_0/(1-\sum\phi_i)$

### 2.6.3 ARMA 定阶：EACF

ACF/PACF 对 ARMA 都不截尾、不提供信息。**Tsay & Tiao (1984) 提出扩展自相关函数（EACF）**：思路是先一致估计 AR 部分、导出 MA 序列，再用 ACF 定 MA 阶。
- 输出是 p（行）× q（列）的**二维表**；理论特征：**从 (p,q) 位置开始出现一个"O 三角形"**（表 2.4：ARMA(1,1) 的 O 三角顶点在 (1,1)）
- 简化表记号：X = |EACF| ≥ 2/√T（2 倍渐近标准误），O = 小于
- 例（3M 月对数收益率 1946-02–2008-12，T=755，表 2.5）：O 三角顶点在 (0,0)；q=2,5,9,11 处的 X 对应 ACF 仅约 0.08–0.09、刚超 $2/\sqrt{755}=0.073$，用 1% 临界值即变 O → **EACF 识别为 ARMA(0,0)（白噪声）**，与 ACF 结论一致
- 也可用 AIC/BIC 在 0≤p≤P、0≤q≤Q 网格上选最小；缺点是需估计大量模型、可能过拟合
- 估计后模型检验：残差 Q(m) ~ χ²(m−g)，g = AR+MA 系数个数

### 2.6.4 ARMA 预测

$$\hat r_h(1) = \phi_0 + \sum_{i=1}^{p}\phi_i r_{h+1-i} - \sum_{i=1}^{q}\theta_i a_{h+1-i}, \quad e_h(1) = a_{h+1},\ \text{Var} = \sigma_a^2$$
$$\hat r_h(\ell) = \phi_0 + \sum_{i=1}^{p}\phi_i\hat r_h(\ell-i) - \sum_{i=1}^{q}\theta_i a_h(\ell-i)$$
（约定：$\hat r_h(j) = r_{h+j}$ 若 j≤0；$a_h(j) = 0$ 若 j>0，$= a_{h+j}$ 若 j≤0）→ 递推计算。

### 2.6.5 ARMA 的三种表示

对 $\phi(B) = 1-\sum\phi_i B^i$、$\theta(B) = 1-\sum\theta_i B^i$ 做**多项式长除法**：
$$\frac{\theta(B)}{\phi(B)} = 1 + \psi_1 B + \psi_2 B^2 + \cdots \equiv \psi(B) \tag{2.29}$$
$$\frac{\phi(B)}{\theta(B)} = 1 - \pi_1 B - \pi_2 B^2 - \cdots \equiv \pi(B) \tag{2.30}$$
（ARMA(1,1) 例：$\psi(B) = 1 + (\phi_1-\theta_1)B + \phi_1(\phi_1-\theta_1)B^2 + \cdots$；$\psi(B)\pi(B) = 1$；常数 c 满足 Bc = c）

**① ARMA 表示 (2.28)**：紧凑，用于估计与递推预测。

**② AR 表示**：
$$r_t = \frac{\phi_0}{1-\theta_1-\cdots-\theta_q} + \pi_1 r_{t-1} + \pi_2 r_{t-2} + \cdots + a_t \tag{2.31}$$
- $\{\pi_i\}$ = **π 权重**，刻画当前收益率对过去收益率的依赖
- **可逆性**：$\pi_i \to 0$（i→∞）；充分条件 = $\theta(B)$ 所有零点模 > 1（MA(1) 即 $|\theta_1|<1$）
- 可逆 ARMA = 当前冲击 + 过去值的指数衰减加权平均

**③ MA 表示**：
$$r_t = \mu + a_t + \psi_1 a_{t-1} + \psi_2 a_{t-2} + \cdots = \mu + \psi(B)a_t \tag{2.32}$$
- $\{\psi_i\}$ = **脉冲响应函数（impulse response function）**，显式刻画过去冲击对当前收益率的影响
- 平稳 ⇒ ψᵢ 指数衰减 ⇒ **冲击无永久影响**
- 预测应用：ℓ 步预测与误差
$$\hat r_h(\ell) = \mu + \psi_\ell a_h + \psi_{\ell+1}a_{h-1} + \cdots \tag{2.33}$$
$$e_h(\ell) = a_{h+\ell} + \psi_1 a_{h+\ell-1} + \cdots + \psi_{\ell-1}a_{h+1}$$
$$\text{Var}[e_h(\ell)] = (1 + \psi_1^2 + \cdots + \psi_{\ell-1}^2)\sigma_a^2 \tag{2.34}$$
（预测步长的非减函数）
- **均值回归的简单证明**：ψᵢ→0 ⇒ 由 (2.33) $\hat r_h(\ell) \to \mu$；且 $\text{Var}[e_h(\ell)] \to \text{Var}(r_t)$。$\hat r_h(\ell)$ 趋于 μ 的速度 = 均值回归速度

## 2.7 单位根非平稳（Unit-Root Nonstationarity）

动机：利率、汇率、**价格**序列常非平稳——价格没有固定水平。此类称**单位根非平稳**序列。

### 2.7.1 随机游走（Random Walk）

$$p_t = p_{t-1} + a_t \tag{2.35}$$
- p₀ 为起始值（如 IPO 时的对数价格）；$a_t$ 分布关于 0 对称 ⇒ 给定 $p_{t-1}$，涨跌各 50% 概率
- 视为 AR(1) 则系数 = 1，不满足 $|\phi_1|<1$ → **非平稳**，称单位根非平稳
- **预测**：任意步长 $\hat p_h(\ell) = p_h$（原点值）→ **不可预测、不均值回归**
- MA 表示：$p_t = a_t + a_{t-1} + a_{t-2} + \cdots$，三个重要含义：
  1. $e_h(\ell) = a_{h+\ell}+\cdots+a_{h+1}$，$\text{Var} = \ell\sigma_a^2 \to \infty$ → 区间预测长度随步长发散，点预测越来越没用
  2. $p_t$ 无条件方差无界 → t 足够大时可取任何实值（对个股对数价格尚可，对市场指数则负对数价格不合理 → 随机游走对指数的充分性存疑）
  3. **所有 $\psi_i = 1$** → 过去冲击的影响不衰减 → **强记忆**；经济学上称冲击有**永久效应（permanent effect）**。样本 ACF 全部趋近 1

### 2.7.2 带漂移的随机游走（Random Walk with Drift）

市场指数对数收益有小的正均值 ⇒ 对数价格模型：
$$p_t = \mu + p_{t-1} + a_t \tag{2.36}$$
- μ = $E(p_t - p_{t-1})$，称**漂移（drift）**，代表对数价格的**时间趋势**
- 递推：$p_t = t\mu + p_0 + \sum_{i=1}^{t}a_i$ = **时间趋势 tμ + 纯随机游走**
- 条件标准差 $\sqrt{t}\sigma_a$ 比条件期望增长慢 → $p_t$ 对 t 作图呈斜率 μ 的趋势；μ>0 → 对数价格最终趋于 ∞
- 例（3M，由 EACF 知无序列相关）：$r_t = 0.0103 + a_t$，$\hat\sigma_a = 0.0637$ (2.37)，t 比率 4.44 → 均值显著为正。图 2.10：$p_t = \sum r_i$ vs $p_t^* = \sum a_i$（去均值）+ 直线 $y_t = 0.0103t + 1946$ → **常数项 = 上升趋势斜率**，重要性一目了然

**常数项的三种解释**（重要！）：
1. MA(q)：常数项 = **均值**
2. 平稳 AR(p)/ARMA：常数项经 $\mu = \phi_0/(1-\sum\phi_i)$ 与均值关联
3. 带漂移随机游走：常数项 = **时间斜率**

### 2.7.3 趋势平稳序列（Trend-Stationary）

$$p_t = \beta_0 + \beta_1 t + r_t,\quad r_t \text{ 平稳（如 AR(p)）}$$
- 同样呈线性趋势，与带漂移随机游走**形似**，但有本质区别：固定 p₀ 时，带漂移随机游走的均值/方差都随 t 增长（冲击永久），趋势平稳序列只是围绕确定性趋势平稳波动（冲击暂时）

### 2.7.4 一般单位根非平稳模型：ARIMA

- ARIMA = AR 多项式含单位根；MA 表示中 ψᵢ 不衰减 → 强记忆、冲击永久
- **差分（Differencing）**：$y_t$ 的**一阶差分** $c_t = y_t - y_{t-1} = (1-B)y_t$ 若为平稳可逆 ARMA(p,q)，则 $y_t$ 是 **ARIMA(p,1,q)**
- 金融应用：价格非平稳，对数收益 $r_t = \ln P_t - \ln P_{t-1}$ 平稳 → 对数价格可视为 ARIMA
- 多重单位根：二阶差分 $s_t = c_t - c_{t-1} = y_t - 2y_{t-1} + y_{t-2}$ 平稳 → **ARIMA(p,2,q)**；若 $s_t$ 均值非零，$y_t$ 含**二次时间趋势**。例：美国 GDP 平减指数可能有双单位根（其二阶差分均值不显著非零，见习题）

### 2.7.5 单位根检验

检验对数价格是否随机游走（带漂移）：
$$p_t = \phi_1 p_{t-1} + e_t \tag{2.38} \qquad p_t = \phi_0 + \phi_1 p_{t-1} + e_t \tag{2.39}$$
$H_0: \phi_1 = 1$ vs $H_a: \phi_1 < 1$。

**Dickey–Fuller (DF) 检验**：
$$DF = \frac{\hat\phi_1 - 1}{\text{std}(\hat\phi_1)} = \frac{\sum_{t=1}^{T}p_{t-1}e_t}{\hat\sigma_e\sqrt{\sum p_{t-1}^2}}$$
- ⚠️ 渐近分布**非标准**：收敛到标准布朗运动的函数（Chan & Wei 1988; Phillips 1987）；临界值靠**模拟**（Fuller 1976 第 8 章）
- φ₀=0 却用 (2.39)：t 比率收敛到另一个非标准分布；φ₀≠0 且用 (2.39)：t 比率渐近正态，但需很大样本

**ADF（增广 DF）检验**：对 AR(p)，回归
$$x_t = c_t + \beta x_{t-1} + \sum_{i=1}^{p-1}\phi_i \Delta x_{t-i} + e_t \tag{2.40}$$
- $c_t$ = 确定性函数：0 / 常数 / $\omega_0 + \omega_1 t$；$\Delta x_j = x_j - x_{j-1}$
- $H_0: \beta = 1$ vs $H_a: \beta < 1$；ADF 统计量 = $\dfrac{\hat\beta - 1}{\text{std}(\hat\beta)}$
- 等价形式：$\Delta x_t = c_t + \beta_c x_{t-1} + \sum \phi_i \Delta x_{t-i} + e_t$，$\beta_c = \beta - 1$，检验 $H_0: \beta_c = 0$

> **例 2.2（美国季度对数 GDP，1947.I–2008.IV）**：上升趋势 + 高序列相关；一阶差分（GDP 增长率）围绕固定水平波动。按差分序列 PACF 选 p=10，ADF = −1.701，p=0.4297 → **不能拒绝单位根**；$\hat\beta = 1 + \hat\beta_c = 1 - 0.0008 = 0.9992$
>
> **S&P 500 对数日度（1950-01-03–2008-04-16，T=14,462）**：用 $c_t = \omega_0 + \omega_1 t$、p=15，ADF = −1.998，p=0.602 → 不能拒绝单位根；常数项显著、时间趋势 5% 水平不显著（10% 显著）→ **对数 S&P 500 含单位根与正漂移，无强时间趋势证据**

## 2.8 季节模型（Seasonal Models）

- 例：公司**季度每股盈利**呈周期性 → 季节时间序列。图 2.13：J&J 季度 EPS（1960–1980）：**指数增长 + 强季节性 + 波动随时间增大**，周期 4（月度数据则周期 12）
- 应用：天气衍生品与能源期货定价（环境序列强季节性）
- 两种处理路线：**季节调整**（剔除季节性后用调整序列推断；美国官方公布数据多为季节调整后）vs **显式建模季节性**（预测目的时必须；本书走后者）

### 2.8.1 季节差分

对数变换的两个作用（对 J&J EPS）：① 把指数增长变线性；② **稳定波动**。若数据非正需先加正数常数。

- $x_t$ = 对数 EPS。ACF（图 2.14a）序列相关强 → 常规做法先做**常规差分** $\Delta x_t = (1-B)x_t$；其 ACF 在**滞后为周期 4 的倍数处**仍强（季节序列典型行为）
- 再做**季节差分**：
$$\Delta_4(\Delta x_t) = (1-B^4)\Delta x_t = x_t - x_{t-1} - x_{t-4} + x_{t-5}$$
一般地周期 s 的季节差分 $\Delta_s y_t = (1-B^s)y_t$；$\Delta = (1-B)$ 称**常规差分**
- $(1-B^4)(1-B)x_t$ 的 ACF：lag 1 显著负、lag 4 边缘负相关（图 2.14d）

### 2.8.2 乘法季节模型

上述 ACF 形态催生了经典的**航空公司模型（airline model）**：
$$(1-B^s)(1-B)x_t = (1-\theta B)(1-\Theta B^s)a_t \tag{2.41}$$
s = 周期，$|\theta|<1$，$|\Theta|<1$。AR 部分 = 常规+季节差分；MA 部分两个参数。

**wt 的 ACF 结构**：$w_t = (1-\theta B)(1-\Theta B^s)a_t = a_t - \theta a_{t-1} - \Theta a_{t-s} + \theta\Theta a_{t-s-1}$：
- $E(w_t)=0$，$\text{Var}(w_t) = (1+\theta^2)(1+\Theta^2)\sigma_a^2$
- 自协方差只在 ℓ = 1, s−1, s, s+1 非零：
$$\text{Cov}_1 = -\theta(1+\Theta^2)\sigma_a^2,\ \text{Cov}_{s-1} = \theta\Theta\sigma_a^2,\ \text{Cov}_s = -\Theta(1+\theta^2)\sigma_a^2,\ \text{Cov}_{s+1} = \theta\Theta\sigma_a^2$$
$$\rho_1 = \frac{-\theta}{1+\theta^2}, \quad \rho_s = \frac{-\Theta}{1+\Theta^2}, \quad \rho_{s-1} = \rho_{s+1} = \rho_1\rho_s = \frac{\theta\Theta}{(1+\theta^2)(1+\Theta^2)}$$
其余为零。季度数据（s=4）则只有 lag 1, 3, 4, 5 非零。

- 与 MA(1)（$\rho_1(y) = -\theta/(1+\theta^2)$）和 MA(s)（$\rho_s(z) = -\Theta/(1+\Theta^2)$）对比：$\rho_{s\pm1} = \rho_1(y)\rho_s(z)$ → s±1 处是**lag-1 与 lag-s 依赖的交互作用**，故称**乘法**模型；含义：常规与季节成分的动态**近似正交**
- 非乘法版本 $w_t = (1-\theta B - \Theta B^s)a_t$ (2.42) 有 $\rho_{s+1} = 0$；**乘法模型更简约**（同参数个数、更多非零 ACF）

> **例 2.3（J&J 季度对数 EPS，1960–1980）**：精确似然估计：
> $$(1-B)(1-B^4)x_t = (1-0.678B)(1-0.314B^4)a_t, \quad \hat\sigma_a = 0.089$$
> 两 MA 参数标准误 0.080、0.101；残差 Q(12)=10.0，p=0.44 → 模型充分。预测评估：前 76 个观测重新估计、留 8 个点；对数预测经**反对数变换**（用第 1 章正态/对数正态关系）还原成 EPS 预测（图 2.15：实际实线、点预测圆点、虚线 95% 区间）

**确定性季节性**：季节形态稳定（近似确定函数）时可用**哑变量**。⚠️ 注意：确定性季节性是乘法模型的特例——(2.41) 中 **Θ = 1** 即含确定性季节成分。季节形态确定时两种方法预测相同；**形态不确定时哑变量预测较差**。实践建议用**精确似然**估计乘法季节模型（尤其小样本或可能有确定性成分时）。

> **例 2.4（CRSP Decile 1 指数月简单收益 1970–2008，T=468）**：时序图无明显季节形态，但 ACF 在 lag 12、24、36 及 1 显著。识别
> $$(1-\phi_1 B)(1-\phi_{12}B^{12})R_t = (1-\theta_{12}B^{12})a_t$$
> - 条件似然：$(1-0.18B)(1-0.87B^{12})R_t = (1-0.74B^{12})a_t$，$\tilde\sigma_a = 0.069$（季节 AR、MA 系数大小相近！）
> - 精确似然：$(1-0.188B)(1-0.951B^{12})R_t = (1-0.997B^{12})a_t$，$\tilde\sigma_a = 0.063$ → **季节 AR/MA 因子几乎对消** → 强烈暗示季节性是**确定性的**，并凸显精确似然的价值
> - 验证：定义一月哑变量 Janₜ，回归 $R_t = \beta_0 + \beta_1 \text{Jan}_t + e_t$ 得 $R_t = 0.0029 + 0.1253\text{Jan}_t + e_t$（$\beta_1$ 的 t ≈ 10.85，高度显著）；残差 ACF 中 lag 12/24/36 基本消失 → Decile 1 收益的季节性主要就是**一月效应（January effect）**

## 2.9 带时间序列误差的回归模型

动机：关心两个时间序列的关系——金融**市场模型**（个股超额收益 ~ 市场超额收益）、利率期限结构。模型：
$$y_t = \alpha + \beta x_t + e_t \tag{2.43}$$
- 若 $e_t$ 白噪声：OLS 一致；**实务中 $e_t$ 常有序列相关** → "带时间序列误差的回归"，OLS 可能**不一致**
- 这是经济金融中应用最广、也**最常被误用**的模型之一（误用点 = 忽视 $e_t$ 的序列依赖）

**案例：美国周度利率（1 年期 r₁ₜ 与 3 年期 r₃ₜ 国债恒定期限利率，1962-01-05–2009-04-10，T=2467，圣路易斯联储）**

1. **水平回归**：$r_{3t} = 0.832 + 0.930r_{1t} + e_t$，$\hat\sigma_e = 0.523$，R²=96.5% (2.44)
   - 看似漂亮，但残差 ACF 高度显著且**缓慢衰减**——单位根非平稳形态（图 2.19）→ 模型严重不足
   - 现代计量语言：两利率若均为单位根序列，则残差形态表明**两者不协整（not cointegrated）**（第 8 章）——不存在长期均衡关系；数据区间内出现过**倒挂收益率曲线（inverted yield curve）**，并不奇怪
2. **差分后回归**：$c_{1t} = (1-B)r_{1t}$，$c_{3t} = (1-B)r_{3t}$，
$$c_{3t} = 0.792c_{1t} + e_t, \quad \hat\sigma_e = 0.0690,\ R^2 = 82.5\% \tag{2.45}$$
残差仍有弱的序列相关（图 2.21）
3. **加 MA(1) 误差**：
$$c_{3t} = \beta c_{1t} + e_t, \quad e_t = a_t - \theta_1 a_{t-1} \tag{2.46}$$
联合 MLE 估计：
$$c_{3t} = 0.794c_{1t} + e_t, \quad e_t = a_t + 0.1823a_{t-1}, \quad \hat\sigma_a = 0.0678,\ R^2 = 83.1\% \tag{2.47}$$
残差 lag-1 ACF 不再显著（lag 4、6、7 略有残余，加参数的增量改进很小）

**三点观察**：
1. (2.44) 的高 R² 和 0.930 系数是**误导性**的（残差强序列相关）
2. 差分序列上 (2.45) 与 (2.47) 的 R²、系数接近——加 MA(1) 只带来边际改进（MA 系数数值小，尽管高度显著）
3. 线性回归分析中**检查残差序列依赖非常重要**

由 (2.47)：$r_{3t} = r_{3,t-1} + 0.794(r_{1t}-r_{1,t-1}) + a_t + 0.182a_{t-1}$——两利率**同期相关且序列相关**。

**建模一般步骤**：
1. 拟合线性回归，检查残差序列相关
2. 残差若单位根非平稳 → 因变量与解释变量都取一阶差分，回步骤 1；残差若平稳 → 为残差识别 ARMA 模型并相应修改回归
3. 极大似然**联合估计**，检查模型做进一步改进

**残差检验建议用 Ljung–Box 而非 Durbin–Watson**（DW 只考虑 lag-1；季节数据高阶滞后可能相关）。

> **备注**：DW 统计量 $DW = \dfrac{\sum_{t=2}^{T}(e_t-e_{t-1})^2}{\sum_{t=1}^{T}e_t^2} \approx 2(1-\hat\rho_1)$。

历史注记：现代计算机之前估计困难，曾有 Cochrane–Orcutt 等特殊方法（Greene 2003, p. 273）；现在只要时间序列模型平稳可逆即可联合 MLE。S-Plus 中 AR 误差可用 `OLS` + `tslag(r,1)`。

## 2.10 协方差矩阵的一致估计

场景：$e_t$ 有序列相关和/或条件异方差，但分析目标是**对回归系数做推断**。两种广泛使用的稳健协方差估计：

模型向量形式：$y_t = \boldsymbol x_t'\boldsymbol\beta + e_t$ (2.48)，$\boldsymbol x_t$ = k 维解释变量（含常数）。OLS：
$$\hat{\boldsymbol\beta} = \left[\sum \boldsymbol x_t \boldsymbol x_t'\right]^{-1}\sum \boldsymbol x_t y_t, \quad \text{Cov}(\hat{\boldsymbol\beta}) = \sigma_e^2\left[\sum \boldsymbol x_t\boldsymbol x_t'\right]^{-1}$$
序列相关/异方差下该协方差估计**不一致**，常导致 t 比率**虚高**。

**① White (1980) HC 估计量**（heteroscedasticity consistent；Eicker 1967）：
$$\text{Cov}(\hat{\boldsymbol\beta})_{HC} = \left[\sum \boldsymbol x_t\boldsymbol x_t'\right]^{-1}\left[\sum_{t=1}^{T}\hat e_t^2\,\boldsymbol x_t\boldsymbol x_t'\right]\left[\sum \boldsymbol x_t\boldsymbol x_t'\right]^{-1} \tag{2.49}$$

**② Newey–West (1987) HAC 估计量**（heteroscedasticity and autocorrelation consistent）：
$$\text{Cov}(\hat{\boldsymbol\beta})_{HAC} = \left[\sum \boldsymbol x_t\boldsymbol x_t'\right]^{-1}\hat{\boldsymbol C}_{HAC}\left[\sum \boldsymbol x_t\boldsymbol x_t'\right]^{-1} \tag{2.50}$$
$$\hat{\boldsymbol C}_{HAC} = \sum_{t=1}^{T}\hat e_t^2\boldsymbol x_t\boldsymbol x_t' + \sum_{j=1}^{\ell}w_j\sum_{t=j+1}^{T}(\boldsymbol x_t\hat e_t\hat e_{t-j}\boldsymbol x_{t-j}' + \boldsymbol x_{t-j}\hat e_{t-j}\hat e_t\boldsymbol x_t')$$
- ℓ = 截断参数；$w_j$ = 权重函数，如 **Bartlett 权重** $w_j = 1 - \dfrac{j}{\ell+1}$
- Newey–West 建议 ℓ 取 $4(T/100)^{2/9}$ 的整数部分；本质是对 $\{\sum \hat e_t \boldsymbol x_t\}$ 协方差的**非参数估计**

**例**（利率差分回归 (2.45)，$c_{1t}$ 系数的 t 比率）：忽略一切 = **107.91**；用 HC = **48.44**；用 HAC = **39.92** → 稳健修正后 t 值大幅缩水（但都仍显著）。

**辅助回归技巧**：k>1 时 $\hat\beta_j$ 的 HC 方差可用辅助回归 $x_{jt} = \boldsymbol x_{-j,t}'\boldsymbol\gamma + v_t$ 的残差 $\hat v_t$ 计算：
$$\text{Var}(\hat\beta_j)_{HC} = \frac{\sum \hat e_t^2\hat v_t^2}{(\sum \hat v_t^2)^2}$$
（辅助回归实现 $\hat v_t$ 与其余解释变量的正交化）

## 2.11 长记忆模型（Long-Memory Models）

- 平稳序列：ACF **指数**衰减；单位根序列：样本 ACF 对所有固定滞后 → 1（Chan & Wei 1988; Tiao & Tsay 1983）
- 存在一类序列：ACF 以**多项式速率**缓慢衰减 → **长记忆序列**

**分数差分过程（fractionally differenced process）**：
$$(1-B)^d x_t = a_t, \quad -0.5 < d < 0.5 \tag{2.52}$$
性质（Hosking 1981）：
1. **d < 0.5**：弱平稳，无穷 MA 表示 $x_t = a_t + \sum_{i=1}^{\infty}\psi_i a_{t-i}$，$\psi_k = \dfrac{d(1+d)\cdots(k-1+d)}{k!} = \dfrac{(k+d-1)!}{k!(d-1)!}$
2. **d > −0.5**：可逆，无穷 AR 表示，$\pi_k = \dfrac{-d(1-d)\cdots(k-1-d)}{k!} = \dfrac{(k-d-1)!}{k!(-d-1)!}$
3. **ACF**：
$$\rho_k = \frac{d(1+d)\cdots(k-1+d)}{(1-d)(2-d)\cdots(k-d)}, \quad \rho_1 = \frac{d}{1-d}, \quad \rho_k \approx \frac{(-d)!}{(d-1)!}k^{2d-1}\ (k\to\infty)$$
→ $\rho_k \sim k^{2d-1}$，**多项式衰减**（故称长记忆）
4. **PACF**：$\phi_{k,k} = d/(k-d)$
5. **谱密度**：$f(\omega) \sim \omega^{-2d}$（ω→0）(2.53)——**频率 0 处发散**；而平稳 ARMA 的谱密度处处有界

**工具**：非整数次幂二项展开
$$(1-B)^d = \sum_{k=0}^{\infty}(-1)^k\binom{d}{k}B^k, \quad \binom{d}{k} = \frac{d(d-1)\cdots(d-k+1)}{k!}$$

**ARFIMA(p,d,q)**：$(1-B)^d x_t$ 服从 ARMA(p,q)，d 非整数——ARIMA 的推广。

**实证识别**：样本 ACF 数值不大但衰减很慢 → 可能有长记忆。图 2.22：CRSP 价值/等权指数**日简单收益率绝对值**序列（1970–2008）的 ACF——幅度小但 **300 阶后仍显著**（参 Ding, Granger & Engle 1993）。d 的估计：MLE 或用**低频对数周期图回归**。长记忆模型受金融文献关注，部分源于连续时间模型中分数布朗运动的研究。
