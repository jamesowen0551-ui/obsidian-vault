## 引言

- 金融风险三大类：**信用风险、操作风险、市场风险**；VaR 主要针对市场风险（概念也适用于其他）。
- 推动背景：金融危机（VIX 飙升、指数暴跌）→ 风险度量与保证金设置成为监管核心议题。

## 7.1 VaR 的定义

$\Delta V(\ell)$ = 头寸从 $t$ 到 $t+\ell$ 的价值变化，$L(\ell)$ = 损失函数（多头=负收益，空头=正收益），$F_\ell(x)$ 为其 CDF。**VaR = 给定持有期 $\ell$、尾部概率 $p$ 下**：
$$p = \Pr[L(\ell) \ge \mathrm{VaR}] \tag{7.1}$$
两种等价表述：机构视角 = "正常市场下给定概率的最大损失"；监管视角 = "极端市场下的最小损失"。

- VaR 就是损失分布的 **$(1-p)$ 分位数**：$\mathrm{VaR} = x_{1-p}$；分位数定义 $x_q = \inf\{x | F_\ell(x)\ge q\}$。
- **关键备注**：① 多头用**负对数收益**分析；② VaR(美元) = 头寸价值 × VaR(对数收益)，精确版为 $\text{Value}\times(e^{\mathrm{VaR}_{log}}-1)$；③ 严格说应用**预测分布**（含参数不确定性），但多数方法忽略；④ **VaR 只是一个分位数，不描述超越它之后的尾部**——两个资产 VaR 相同、尾部风险可完全不同 → 需要 ES（期望损失）。

## 7.2 RiskMetrics（J.P. Morgan 方法）

**模型假设**：日对数收益 $r_t = \sigma_t\epsilon_t$，无漂移 **IGARCH(1,1)**：
$$\mu_t = 0,\qquad \sigma_t^2 = \alpha\sigma_{t-1}^2 + (1-\alpha)r_{t-1}^2,\quad \alpha\in(0.9,1),\ \text{典型 } 0.94 \tag{7.2}$$
**k 期收益的优美性质**：改写 $\sigma_t^2 = \sigma_{t-1}^2 + (1-\alpha)\sigma_{t-1}^2(\epsilon_{t-1}^2-1)$，因 $E(\epsilon^2-1|F)=0$ 得 $E(\sigma_{t+i}^2|F_t) = \sigma_{t+1}^2$（$i\ge1$），故
$$r_t[k]|F_t \sim N(0,\ k\sigma_{t+1}^2)\ \Rightarrow\ \boxed{\mathrm{VaR}(k) = \sqrt{k}\times\mathrm{VaR}}\ \textbf{（平方根时间规则）}$$
- 1% 尾部：VaR = 头寸 × $2.326\sigma_{t+1}$；5%：× $1.65\sigma_{t+1}$。
- **例 7.1**：马克/美元汇率日波动 0.53%，\$1000 万多头 1 日 5% VaR = $10^7 \times 1.65\times0.0053 = \$87,450$；10 日 = $\sqrt{10}$ 倍 = \$276,541。
- **例 7.2（IBM，RATS 估计）**：$\hat\sigma_{9190}^2(1) = 0.000336$ → 5% VaR = \$302,500，1% VaR = \$426,500。（S-Plus `mgarch(ibm~-1,~ewma1)` 估计 $\hat\alpha=0.964$，得略高值 \$311,520 / \$439,187。）

### 7.2.1–7.2.2 讨论与多头寸

- 优点：**简单透明**；缺点：正态假设在厚尾收益下**低估 VaR**。
- **平方根时间规则的失效条件**：均值非零（分位数 $= k\mu + 1.65\sqrt k\sigma_{t+1}$，不是 $\sqrt k$ 比例）或波动模型不是无漂移 IGARCH。
- **多头寸**：$m$ 个工具，$\mathrm{VaR} = \sqrt{\sum_i \mathrm{VaR}_i^2 + 2\sum_{i<j}\rho_{ij}\mathrm{VaR}_i\mathrm{VaR}_j}$（多元正态假设）。

### 7.2.3 期望损失（ES）

RiskMetrics 下损失条件截尾正态：$E(X|X>\mathrm{VaR}_q) = f(\mathrm{VaR}_q)/p$。故
$$\mathrm{ES}_q = \frac{f(\mathrm{VaR}_q)}{p}\sigma_t$$
$p=0.05$：$\mathrm{ES}_{0.95} = 2.0627\sigma_t$；$p=0.01$：$\mathrm{ES}_{0.99} = 2.6652\sigma_t$。

## 7.3 计量经济学方法（ARMA–GARCH）

一般模型（式 7.5/7.6）：均值 ARMA + 波动 GARCH；$r_{t+1}|F_t \sim N[\hat r_t(1), \hat\sigma_t^2(1)]$，分位数 = $\hat r_t(1) + 1.65\hat\sigma_t(1)$。

**标准化 t 分布的分位数换算**：$t_v$ 的 $p$ 分位数为 $q$，则标准化 $t_v^*$ 的分位数为 $q/\sqrt{v/(v-2)}$。

**例 7.3（IBM，多头 \$1000 万，用负收益 $r_t=-r_t^c$）**：
- **Case 1（高斯 AR(2)–GARCH(1,1)）**：$\hat r(1) = -0.00071$，$\hat\sigma^2(1) = 0.0003211$ → 95% 分位数 0.02877 → **VaR = \$287,700**；99% → \$409,738；
- **Case 2（标准化 $t_5$）**：$t_5$ 的 95% 分位数 2.015，标准化后 $2.015/\sqrt{5/3} = 1.5608$ → VaR = \$283,520（与正态几乎相同）；但 99%：$3.3649/\sqrt{5/3}$ → **\$475,943**——**厚尾效应在小尾部概率时放大 VaR**。

### 7.3.1 多期 VaR

$k$ 期收益预测均值 $\hat r_h[k] = \sum_{\ell=1}^k r_h(\ell)$；预测误差（用 MA 表示的 $\psi$ 权重）：
$$e_h[k] = a_{h+k} + (1+\psi_1)a_{h+k-1} + \cdots + \Big(\sum_{i=0}^{k-1}\psi_i\Big)a_{h+1} \tag{7.7}$$
$$\mathrm{Var}(e_h[k]|F_h) = \sigma_h^2(k) + (1+\psi_1)^2\sigma_h^2(k-1) + \cdots + \Big(\sum_{i=0}^{k-1}\psi_i\Big)^2\sigma_h^2(1) \tag{7.8}$$
特例（无常数项以外动态，$\psi_i=0,\ i>0$）：$\mathrm{Var} = \sum_{\ell=1}^k\sigma_h^2(\ell)$，GARCH(1,1) 递推 $\sigma_h^2(\ell) = \alpha_0 + (\alpha_1+\beta_1)\sigma_h^2(\ell-1)$，闭式解见式 7.10。

**例 7.3 续（15 日 VaR）**：条件均值 −0.00998、方差 0.0047948 → 95% 分位数 0.10392 → **VaR = \$1,039,191 < \$287,700×√15 = \$1,114,257**——再次说明平方根规则只在特定 IGARCH 下成立。

### 7.3.2 条件正态下的 ES

$$\mathrm{ES}_q = \mu_t + \frac{f(x_q)}{p}\sigma_t\quad(p=0.01:\ \mathrm{ES}_{0.99} = \mu_t + 2.6652\sigma_t)$$

## 7.4 分位数估计（非参数）

### 7.4.1 分位数与次序统计量

次序统计量 $r_{(1)}\le\cdots\le r_{(n)}$；$\ell = np$ 时（式 7.11）：
$$r_{(\ell)} \overset{\cdot}{\sim} N\left(x_p,\ \frac{p(1-p)}{n[f(x_p)]^2}\right)$$
非整数 $np$ 用**线性插值**（式 7.12）：$\hat x_p = \frac{p_2-p}{p_2-p_1}r_{(\ell_1)} + \frac{p-p_1}{p_2-p_1}r_{(\ell_2)}$。

- **例 7.4（Intel 1972–2008，9096 个）**：负收益 95% 经验分位数 0.04295（R：`quantile(nintc,0.95)`）。
- **例 7.5（IBM）**：95% 分位数 = $(r_{(8730)}+r_{(8731)})/2 = 0.021603$ → VaR = **\$216,030**；99% 插值得 3.630（百分比）→ VaR = \$363,000。
- **经验 ES**：$\mathrm{ES}_q = \frac{1}{N_q}\sum x_{(i)}I[x_{(i)}>\hat x_q]$；IBM $p=0.01$：$\mathrm{ES}_{0.99} = 5.097$。

**优缺点**：简单、无分布假设；但假设分布不变（预测损失不超过历史损失，实践中不成立）、小 $p$ 时效率低、无法纳入解释变量。

### 7.4.2 分位数回归（Koenker & Bassett 1978）

经验分位数可写成最优化：$\hat x_p = \arg\min_\beta\sum_i w_p(r_i-\beta)$，检验函数
$$w_p(z) = \begin{cases} pz & z\ge0 \\ (p-1)z & z<0 \end{cases}$$
推广到回归 $r_t = \beta'\mathbf{x}_t + a_t$：**条件分位数** $\hat x_p|F_{t-1} = \inf\{\beta_o'\mathbf{x} | R_p(\beta_o)=\min\}$，$\beta_o = \arg\min_\beta\sum_t w_p(r_t - \beta'\mathbf{x}_t)$（式 7.13/7.14）。R 包 `quantreg`。

## 7.5 极值理论（EVT）★ 本章理论核心

**问题**：$n$ 个收益的**最大值** $r_{(n)}$ 的分布？iid 时 $F_{n,n}(x) = [F(x)]^n$（式 7.15），但 $n\to\infty$ 时退化。需找规范化序列：$r_{(n*)} = (r_{(n)}-\beta_n)/\alpha_n$ 收敛到非退化分布。

**Fisher–Tippett–Gnedenko 定理 / Jenkinson (1955) 的 GEV**：
$$F_*(x) = \begin{cases} \exp[-(1+\xi x)^{-1/\xi}] & \xi\ne0 \\ \exp[-e^{-x}] & \xi=0 \end{cases} \tag{7.16}$$
- $\xi$ = **形状参数**；$\alpha = 1/\xi$ = **尾部指数（tail index）**。
- 三族（Gnedenko 1943）：**Type I Gumbel**（$\xi=0$，指数尾：正态、对数正态）；**Type II Fréchet**（$\xi>0$，幂律尾：稳定分布、t 分布——**风险管理最关心的**）；**Type III Weibull**（$\xi<0$，有限端点）。
- **尾部行为（而非具体分布）决定极限**；**Feller 证明尾指数在时间聚合下不变**——对 VaR 跨期换算有用。
- 序列相关：Berman(1964) 证明正态平稳序列只要 $\sum\rho_i^2<\infty$ 极限不变；Leadbetter 等给出一般理论（见 7.8 极值指数）。

### 7.5.2 经验估计

**分块思想**：$T$ 个观测分成 $g$ 个长度为 $n$ 的子区间，取**子区间最大（小）值** $\{r_{n,i}\}_{i=1}^g$ 拟合 GEV。

1. **最大似然**：GEV pdf（式 7.19）做变换后连乘，非线性优化；MLE 渐近无偏、正态、最小方差（Embrechts et al. 1997；Coles 2001）。
2. **回归法（Gumbel）**：用次序统计量性质 $E\{F_*(r_{n(i)})\} = i/(g+1)$（式 7.21），取两次对数得回归
$$\ln\left[-\ln\frac{i}{g+1}\right] = -\frac{1}{\xi_n}\ln\left(1 + \xi_n\frac{r_{n(i)}-\beta_n}{\alpha_n}\right) + e_i \tag{7.23}$$
（$\xi=0$ 时简化为线性）。一致但不如 MLE 有效。
3. **非参数（直接对原序列）**：
   - **Pickands 估计量**（式 7.24）：$\xi_p(q) = \frac{1}{\ln 2}\ln\frac{r_{(T-q+1)}-r_{(T-2q+1)}}{r_{(T-2q+1)}-r_{(T-4q+1)}}$；
   - **Hill 估计量**（式 7.25，仅 Fréchet 族）：$\xi_h(q) = \frac1q\sum_{i=1}^q[\ln r_{(T-i+1)} - \ln r_{(T-q)}]$；$\sqrt q(\xi_h(q)-\xi) \to N(0,\xi^2)$。**实务：画 Hill 图（$\xi_h(q)$ vs $q$）找稳定段**。

### 7.5.3 股票收益应用（IBM）

- **Hill 估计**（表 7.1）：$q=190,200,210$ 时正负收益的 $\hat\xi \approx 0.30$（SE≈0.021），显著非零 → **Fréchet 族，拒绝正态**；负极值 $\xi$ 略大 → **左尾更厚**。与 Longin(1996) 结论一致。
- **GEV 的 MLE**（表 7.2，$n=21/63/126/252$）：$\beta_n,\alpha_n$ 随 $n$ 增大（最大值量级随区间增大）；**负极值 $\hat\xi_n$ 稳定在 ≈0.33（$n\ge63$）**；正极值较不稳定（0.17–0.35）；$n=252$ 时 $g=36$ 太小、方差大。
- **模型诊断**：GEV 残差 $w_i = [1+\hat\xi_n(r_{n,i}-\hat\beta_n)/\hat\alpha_n]^{-1/\hat\xi_n}$ 应 iid **标准指数**——散点图 + QQ 图检验（图 7.5 通过）。

## 7.6 基于传统 EVT 的 VaR

**两步**：
① 子区间最大值的 GEV 分位数（式 7.26）：
$$r_n^* = \begin{cases} \beta_n - \frac{\alpha_n}{\xi_n}\left\{1-[-\ln(1-p^*)]^{-\xi_n}\right\} & \xi_n\ne0 \\ \beta_n - \alpha_n\ln[-\ln(1-p^*)] & \xi_n=0 \end{cases}$$
② 利用 $1-p^* = P(r_{n,i}\le r_n^*) = [P(r_t\le r_n^*)]^n$（式 7.27）反解出**单笔收益**的 VaR（式 7.28）：
$$\mathrm{VaR} = \begin{cases} \beta_n - \frac{\alpha_n}{\xi_n}\left\{1-[-n\ln(1-p)]^{-\xi_n}\right\} & \xi_n\ne0 \\ \beta_n - \alpha_n\ln[-n\ln(1-p)] & \xi_n=0 \end{cases}$$

**例 7.6（IBM，负对数收益，\$1000 万多头，1% VaR）**：
- $n=63$（$\hat\alpha=0.945,\hat\beta=2.583,\hat\xi=0.335$）：VaR = 3.0497% → **\$304,969**；5%：\$166,641；
- $n=21$（0.823/1.902/0.197）：**\$340,013**；5%：\$184,127。**VaR 对子区间长度 $n$ 的选择敏感**（$n$ 大→极限定理更准但 $g$ 小→估计方差大，需权衡）。

### 7.6.1 各种方法大比较（IBM，\$1000 万多头，1 日 1%）

| 方法 | VaR(1%) | VaR(0.1%) |
|---|---|---|
| RiskMetrics | \$426,500 | \$566,443 |
| 高斯 AR(2)–GARCH(1,1) | \$409,738 | \$546,641 |
| $t_5$ AR(2)–GARCH(1,1) | \$475,943 | **\$836,341** |
| 经验分位数 | \$365,709 | \$780,712 |
| 传统 EVT（$n=21$） | \$340,013 | \$666,590 |

差异巨大——**尾部估计天然不确定；建议同时用多种方法看 VaR 的"区间"**。0.1% 时经验分位数样本不足（9190 个观测里只有约 9 个超界），而厚尾 t 给出最保守估计。

### 7.6.2 α 次根时间规则

EVT 下多期 VaR：$\mathrm{VaR}(\ell) = \ell^{1/\alpha}\mathrm{VaR} = \ell^{\xi}\mathrm{VaR}$（Danielsson & de Vries 1997a）。IBM 例：$\mathrm{VaR}(30) = 30^{0.335}\times\$304,969 = \$952,997$。**因 $\ell^{0.335}<\ell^{0.5}$，厚尾时比平方根规则小**——注意 $\alpha$ 此处是尾指数 $1/\xi$，不是尺度参数。

### 7.6.3 回归水平（Return Level）

**$gn$ 子区间回归水平** $L_{n,g}$：每 $g$ 个子区间被超越一次的水平，$P(r_{n,i}>L_{n,g}) = 1/g$：
$$L_{n,g} = \beta_n - \frac{\alpha_n}{\xi_n}\left\{1-\left[-\ln\left(1-\frac1g\right)\right]^{-\xi_n}\right\}$$
即式 7.26 取 $p^*=1/g$。**回归水平作用于子区间最大值，VaR 作用于原始收益**——这是两者的区别。IBM 负收益 $n=21, g=12$：回归水平 = **4.4835%**（R：`rlevel.gev(m1, k.blocks=12)`）。

## 7.7 POT 新方法（Peaks Over Thresholds）★

传统 EVT 的缺陷：子区间长度 $n$ 难选；无条件（不能用解释变量）；只用最大值浪费数据。**POT（Davison & Smith 1990；Smith 1989）**：关注**超过高门限 $\eta$ 的超越量与超越时刻** $(t_i, r_{t_i}-\eta)$。

**门限选择**：$\eta$ 太小→渐近理论失效；太大→超越次数太少。经验：超越数约占样本 5%；稳定序列 2.5%，高波动可到 10%。

### 7.7.1 统计理论：GPD

核心结果（式 7.30）：若最大值极限为 GEV（参数 $\xi,\beta,\alpha$），则**条件超越分布** $r-\eta \mid r>\eta$ 近似为**广义 Pareto 分布（GPD）**：
$$G_{\xi,\psi(\eta)}(x) = \begin{cases} 1 - \left[1+\frac{\xi x}{\psi(\eta)}\right]^{-1/\xi} & \xi\ne0 \\ 1-\exp[-x/\psi(\eta)] & \xi=0 \end{cases} \tag{7.31}$$
其中 $\psi(\eta) = \alpha + \xi(\eta-\beta)$。**GPD 关键性质（门限稳定性）**：若门限 $\eta_o$ 上超越服从 GPD($\xi,\psi(\eta_o)$)，则任意更高门限 $\eta>\eta_o$ 上仍为 GPD，形状不变、尺度 $\psi(\eta) = \psi(\eta_o) + \xi(\eta-\eta_o)$。$\xi=0$ 退化为**指数分布**——故可用**指数 QQ 图**判断尾部：直线 ⇔ $\xi=0$；IBM 负收益的 QQ 图明显弯曲 → $\xi\ne0$、左尾厚于正态。

### 7.7.2 均值超越函数与 meplot

$e(\eta) = E(r-\eta|r>\eta)$；GPD 下对 $\eta>\eta_o$ 是**线性函数**：$e(\eta) = \frac{\psi(\eta_o)+\xi(\eta-\eta_o)}{1-\xi}$。**均值超越图（mean excess plot，`meplot`）在恰当门限之上应近似直线**——IBM 例显示 $\eta\approx3\%$ 合理。

### 7.7.3 二维 Poisson 过程建模（Smith 1989；Tsay 1999）

把 $\{(t_i, r_{t_i})\}$ 看作**二维 Poisson 过程**，基期 $D$（美股一年 = 252 交易日），强度测度：
$$\Lambda[(D_2,D_1)\times(r,\infty)] = \frac{D_2-D_1}{D}S(r;\xi,\alpha,\beta),\quad S(r) = \left[1+\frac{\xi(r-\beta)}{\alpha}\right]_+^{-1/\xi} \tag{7.33}$$
其隐含的条件超越概率恰是式 7.30 的 GPD 生存函数——**新方法与 GEV 直接连通**。似然（式 7.35）：
$$L(\xi,\alpha,\beta) = \left[\prod_{i=1}^{N_\eta}\frac{1}{D}g(r_{t_i};\xi,\alpha,\beta)\right]\exp\left[-\frac{T}{D}S(\eta;\xi,\alpha,\beta)\right]$$
$g$ 为式 7.34 的强度函数；估计时对 $\alpha$ 用 $\ln\alpha$ 保证非负。

**例 7.7（IBM 负收益，表 7.3）**：

| 门限 | 超越数 | $\hat\xi$ | $\ln\hat\alpha$ | $\hat\beta$ |
|---|---|---|---|---|
| 3.0% | 175 | 0.307(0.090) | 0.307(0.124) | 4.692(0.191) |
| 2.5% | 310 | 0.264(0.065) | 0.315(0.113) | 4.741(0.180) |
| 2.0% | 554 | 0.188(0.044) | 0.277(0.099) | 4.810(0.172) |

（去样本均值后估计几乎不变。）日跌 ≥2.5% 的概率 ≈ 310/9190 ≈ **3.4%**。

**VaR 计算**（例 7.8，\$1000 万多头）：$p=0.05$ 时 \$212,981–\$232,094；$p=0.01$ 时 \$359,303–\$372,372——**对门限选择相当稳健**（传统 EVT 对 $n$ 敏感得多）。建议先去均值。R 演示：`pot(nibm, 0.025)`；`riskmeasures(m3, c(0.95,0.99,0.999))` 同时给出 VaR 与 ES（0.999：分位数 0.0702、ES 0.0970）。

### 7.7.5 另一参数化与 ES

evir 的 `gpd` 用 $(\xi, \psi(\eta))$ 参数化。VaR 的显式公式（式 7.37）：
$$\mathrm{VaR}_q = \eta - \frac{\psi(\eta)}{\xi}\left\{1-\left[\frac{T}{N_\eta}(1-q)\right]^{-\xi}\right\}$$
**GPD 下 ES 有简洁闭式**（用 GPD 门限稳定性）：
$$E(r-\mathrm{VaR}_q|r>\mathrm{VaR}_q) = \frac{\psi(\eta)+\xi(\mathrm{VaR}_q-\eta)}{1-\xi}\ \Rightarrow\ \boxed{\mathrm{ES}_q = \frac{\mathrm{VaR}_q}{1-\xi} + \frac{\psi(\eta)-\xi\eta}{1-\xi}} \tag{7.38}$$
IBM $\eta=2.5\%$：$\mathrm{VaR}_{0.95}=0.0221,\mathrm{ES}=0.0316$；$\mathrm{VaR}_{0.99}=0.0362,\mathrm{ES}=0.0508$。

### 7.7.6 加入解释变量（非齐次 Poisson 模型）★

让三参数时变、线性依赖 $t-1$ 时刻可得的解释变量 $\mathbf{x}_t$：
$$\xi_t = \gamma_0 + \boldsymbol\gamma'\mathbf{x}_t,\qquad \ln\alpha_t = \delta_0 + \boldsymbol\delta'\mathbf{x}_t,\qquad \beta_t = \theta_0 + \boldsymbol\theta'\mathbf{x}_t \tag{7.39}$$
检验 $\boldsymbol\gamma=0$ 即检验解释变量对形状参数的贡献。似然为式 7.35 的推广（式 7.41，假设参数在每个交易日内不变）。

**例（IBM 去均值收益，门限 2.5%，334 次超越，表 7.4）**，5 个解释变量：
- $x_{1t}$：10/11/12 月指示（年末效应）；
- $x_{2t}$：前一日跌 ≥2.5% 指示（**恐慌抛售**）；
- $x_{3t}$：前 5 日中 $|r^o|\ge2.5\%$ 的天数（波动定性度量）；
- $x_{4t}$ = (年份−1961)/38（年度趋势）；
- $x_{5t} = \sigma_t$：GARCH(1,1) 拟合波动（$\sigma_t^2 = 0.04565 + 0.0807a_{t-1}^2 + 0.9031\sigma_{t-1}^2$）。

估计结果：
$$\beta_t = 0.3202 + 1.4772x_{3t} + 2.1991x_{5t}$$
$$\ln\alpha_t = -0.8119 + 0.3305x_{4t} + 1.0324x_{5t}$$
$$\xi_t = 0.1805 + 0.2118x_{3t} + 0.3551x_{4t} - 0.2602x_{5t}$$
发现：① **三参数都显著依赖年度趋势**；**$\xi_t$ 的趋势为负……注意解读：位置与尺度随时间增大**；② 年末效应与恐慌抛售**不显著**；③ **GARCH 波动 $x_{5t}$ 显著影响位置与形状**（波动大 → 收益变异大 → 对尾指数的依赖降低）；④ $x_{3t}$ 影响尺度与形状。

**VaR（$t=9190$）**：$\hat\xi=0.01195, \ln\hat\alpha=0.19331, \hat\beta=6.105$ → 5% VaR = **\$303,756**，1% VaR = **\$497,425**。**参数随市场状况自适应**：用前一日（12/30）的 $x_3=1, x_4=0.9737, x_5=1.8757$ 得 5% VaR = \$269,139——**齐次模型会低估 VaR**。

### 7.7.7 模型检验（三要素）

1. **超越率**：相邻超越的时间间隔变换 $z_{t_i}$（式 7.42，按强度积分）应 iid **指数分布**——QQ 图；
2. **超越量分布**：变换（式 7.43）
$$w_{t_i} = \frac{1}{\xi_{t_i}}\ln\left(1 + \xi_{t_i}\frac{r_{t_i}-\eta}{\psi_{t_i}}\right)_+\quad(\xi=0\text{ 时 } w = (r_{t_i}-\eta)/\psi_{t_i})$$
应 iid **均值 1 的指数分布**——QQ 图验证 GPD 假设；
3. **独立性**：$z_{t_i}, w_{t_i}$ 的 ACF 应无显著相关。

齐次模型 ACF 有显著尖峰（图 7.8a/b）→ **不合格**；非齐次模型（图 7.8c/d）全部落在两倍标准误内、QQ 图改善 → **充分**。

## 7.8 极值指数（Extremal Index）★ 处理序列相关

**问题**：现实中极端事件**成簇出现**（波动聚集），iid 假设不成立。

### 7.8.1 $D(u_n)$ 条件与 Leadbetter 定理

直观论证：把数据分成 $k$ 大小的块，样本最大值 = 块最大值的最大值（式 7.44）；若长程相关快速衰减、块足够大，块最大值近似独立 → **平稳序列最大值的极限分布仍是 GEV 族**。

**$D(u_n)$ 条件**（式 7.45）：相隔 $\ell_n$（$\ell_n/n\to0$）的两组指标上的"最大值 ≤ $u_n$"事件渐近独立（$|\cdot|\le\delta_{n,\ell_n}\to0$）。较弱；高斯序列若 $\rho_n\ln n\to0$ 即满足（Berman 1964）。

**Leadbetter 定理 2**：存在 iid 伴随序列 $\{\tilde x_i\}$（同边缘分布），其最大值极限为 $\tilde F_*(x)$，则
$$P\left[\frac{x_{(n)}-\beta_n}{\alpha_n}\le x\right] \to F_*(x) = \tilde F_*^{\,\theta}(x),\qquad \theta\in(0,1]$$
**$\theta$ = 极值指数**。代数推导（式 7.46）表明：$F_*$ 仍是 GEV，**形状参数 $\xi^* = \xi$ 不变**，但位置与尺度改变：
$$\alpha^* = \alpha\theta^\xi,\qquad \beta^* = \beta - \frac{\alpha}{\xi}(1-\theta^\xi)$$
（$\xi=0$ 时 $\alpha^*=\alpha$，$\beta^* = \beta + \alpha\ln\theta$。）

**正式定义**（式 7.47/7.48）：存在门限序列 $u_n$ 使 $n[1-F(u_n)]\to\tau$ 且 $P(x_{(n)}\le u_n)\to e^{-\theta\tau}$（iid 时为 $e^{-\tau}$）。**解读：$\theta$ ≈ 1/平均簇大小**——极端事件平均成簇出现 $1/\theta$ 次。

### 7.8.2 $\theta$ 的估计

- **块方法**：$G(u_n)$ = 块最大值超门限的块数，$N(u_n)$ = 总超越数：
$$\hat\theta_b^{(1)} = \frac{1}{k}\cdot\frac{\ln[1-G(u_n)/g]}{\ln[1-N(u_n)/n]}\quad\text{（式 7.50）},\qquad \hat\theta_b^{(2)} = \frac{G(u_n)}{N(u_n)}$$
（$\hat\theta_b^{(2)}$ 恰为**极限复合 Poisson 过程平均簇大小的倒数**，Hsing et al. 1988。）
- **游程方法**（O'Brien 1987）：$\hat\theta_r^{(3)} = \frac{\sum I(A_{i,n})}{N(u_n)}$，$A_{i,n}$ = "超越后连续 $k$ 个观测低于门限"的游程事件。

**IBM 负收益**：$k=10$、门限 0.025 时 $\hat\theta_b^{(1)} = 0.823$——极端日平均成簇约 1.2 天；估计对门限和块长敏感。

### 7.8.3 平稳时间序列的 VaR

由 $P(x_{(n)}\le u_n) \approx [F(u_n)]^{n\theta}$，修正 VaR 公式（式 7.51）：
$$\mathrm{VaR} = \begin{cases} \beta_n - \frac{\alpha_n}{\xi_n}\left\{1-[-n\theta\ln(1-p)]^{-\xi_n}\right\} & \xi_n\ne0 \\ \beta_n - \alpha_n\ln[-n\theta\ln(1-p)] & \xi_n=0 \end{cases}$$
**忽略 $\theta$ 会低估 VaR**。IBM 例：$\hat\theta=0.823$、$n=63$ → 1% VaR = **3.2714%**（忽略 $\theta$ 时为 3.0497，例 7.6）。R：`exindex(nibm,10)`。

|---|---|
| VaR 定义 | 损失分布的 $(1-p)$ 分位数；多头用负对数收益；VaR(美元)=头寸×VaR(%) |
| VaR 缺陷 | 只是分位数，不刻画尾部内部；需配合 ES |

| 传统 EVT-VaR | 分块最大值 → GEV → 式 7.28；**对 $n$ 敏感** |
| POT/GPD | 超越条件分布 ≈ GPD，$\psi(\eta)=\alpha+\xi(\eta-\beta)$；门限稳定性；meplot 选门限 |
