# 第三章 风险（Risk）· 精读笔记

> 书目：Grinold & Kahn《Active Portfolio Management》
> 范围：Chapter 3，正文第 41–70 页 + 技术附录 72–85 页
> 定位：预期收益是主角，风险是反派。兑现第一章"风险预测外包"的承诺：定义风险 → 结构化多因子风险模型。

## 本章六要点
1. 风险 = 收益的标准差；
2. **风险不可加**（Risks don't add）；
3. 机构更关心主动/残差风险而非总风险；
4. **主动风险取决于主动头寸大小，与基准权重无关**；
5. 风险的代价与方差成正比；
6. 风险模型识别风险来源并分解风险。

---

## 一、定义风险

### 四条标准
- **普适非个人**：机构经理是代理人链条的一环，不能有个人化风险观——本书度量的是"不确定性"；
- **对称**：相对基准/同业被评判，漏掉上涨与超配下跌同罪；
- **灵活**：个股与组合通用、可回溯可预测任意期限；
- **可预测可加总**：能从资产构建到任意组合。

### 候选度量过堂（Magellan 基金 1973.1–1994.9 为例）
| 度量 | 问题 |
|---|---|
| 标准差/方差 ✅ | Markowitz 标准；无歧义、可聚合、时序稳定、预测工具强 |
| 下行风险/半方差 | 定义歧义；**资产→组合聚合极难**；对称时与标准差成正比无新信息；不对称性不稳定难预测；只用一半数据 |
| 不足概率 | 目标越低越难预测，极端情形由一两个观测决定 |
| VaR | 不足概率的对偶（Magellan 最差 1% 月亏 >20.8% → VaR $208/$1000），同优缺点 |
| 正态分布 | 真实收益厚尾；但厚尾是否**可预测**是另一回事（第七节：否） |

月度：σ=6.3%，μ=1.6%；年化：μ=19.2%，σ=21.8%。

## 二、标准差的性质

### 1. 风险不可加
σ_P = √(0.5²σ₁²+0.5²σ₂²+2·0.5σ₁·0.5σ₂·ρ) ≤ 0.5σ₁+0.5σ₂（等号仅 ρ=1）。
**整体小于部分之和 = 分散化的钥匙。**

### 2. 分散化定量
- 不相关 N 股等权：σ_P = σ/√N；
- 等相关 ρ：σ_P = σ√[(1+ρ(N−1))/N] → N→∞ 时 **σ√ρ（风险下限）**；
- 实证：1992.12 MMI 20 股平均风险 27.8%，等权组合 20.4% ⇒ 平均相关性 ≈ 0.54。

### 3. 跨时间：方差可加、标准差按 √T
- 自相关≈0 ⇒ 方差∝期限，风险∝√期限；
- 5% 年主动风险 = 2.5%/季 = 10%/4年；**σ_年 = √12·σ_月**。

### 4. 主动风险的误区 ⭐
- 常见做法：按基准市值设主动限额（大盘股 ±2%、小盘股 ±0.3%）；
- **纠正：主动风险 = 主动暴露 × 股票风险，与基准权重无关**；主动持仓加总恒为零。

### 5. 量级感（表 3.1，BARRA HICAP ~1200 股，1980/1990/1998）
- 总风险典型 25–40%；残差风险 20–35%；β 典型 0.80–1.35；
- 分布跨时稳定；**中位数 β ≠ 1，只有市值加权 β = 1**。

### 6. 风险代价 ∝ 方差
- 主动风险厌恶 0.1 时，4% 主动风险 ⇔ 0.1×(4%)² = **1.6% 预期收益损失**。

## 三、初级风险模型（为何不够）

规模问题：N 只股票需 N(N−1)/2 个相关系数。

1. **单因子对角模型**（Sharpe 1963）：r_n = β_n r_M + θ_n，假设残差互不相关；Cov = β_nβ_mσ²_M。内在矛盾：残差市值加权和恒为零 ⇒ 残差相关总体为负。优点：隔离市场/残差、残差协方差估计保守（取 0）。注：≠ CAPM（CAPM 是收益模型，不假设残差不相关）。
2. **等相关模型**：Cov = σ_nσ_mρ̄。quick & dirty，忽略行业/属性联系。
3. **历史协方差**：T≤N 时存在"看似零风险"的主动头寸 ⇒ 需 T>N（S&P 500 月度需 40 年+）；且：期限错配（日/周数据 vs 季/年预测）；公司变化（并购分拆）处理不了；选择偏差（剔除被收购/破产公司）；样本偏差致虚假低风险。

## 四、结构化多因子风险模型 ⭐

### 思想
收益 = 共同因子 + 特有成。**降维：6000 只股票（1800 万协方差）→ 68 个因子**。"股票在变，因子不变"。

### 结构方程
$$r_n(t) = \sum_k X_{n,k}(t)\,b_k(t) + u_n(t)$$
- X：期初已知的因子暴露（标准化：截面均值 0、标准差 1）；
- b：因子收益；u：特有收益（模型不解释 u，但显式预测其风险）；
- **无因果含义**：因子只是分析风险的维度。

### 风险结构
假设 u 与 b 不相关、u 彼此不相关：
$$\mathbf{V} = \mathbf{XFX}^T + \mathbf{\Delta}$$

## 五、选因子

**唯一硬约束：暴露必须期初已知（a priori）。**

| 类别 | 例子 | 评价 |
|---|---|---|
| 外部响应（宏观） | 债券 beta、通胀意外、油价、汇率、工业产出 | 三宗罪：响应系数回归估计有误差；非平稳；宏观数据质量差（延迟、低频） |
| **横截面比较**（主推） | 基本面（股息率、E/P、分析师预测）；市场（动量、波动率、隐含波动率、换手率） | 暴露直接可算，绕开估计误差；动量因子用于**风险刻画**而非收益预测 |
| 纯统计因子 | PCA、最大似然、EM | 通常避免：难解释、易伪相关、假设暴露恒定（抓不住动量） |

**三 I 标准**：Incisive（能区分收益）、Intuitive（有可信故事）、Interesting（统计/投资显著性）。

**两类因子**：
- **行业因子**：互不重叠划分；公司数/市值/市场惯例三标准（表 3.2：1998.8 BARRA 52 个行业、11,000+ 股）；暴露 0/1（可扩展多行业归属）；
- **风险指数八类**：波动率、动量、规模、流动性、成长、价值、盈利波动率、财务杠杆；
- **描述符机制**：指数 = 若干描述符加权（如波动率含日收益波动率、隐含波动率、价格区间、beta），权重最大化解释力/预测力；
- 暴露统一标准化：x = (x_raw − mean)/Std。

## 六、风险模型三大用途

### 现在：当前组合分析 ⭐
- 分解：市场/残差、主动（跟踪误差）、模型/特有；
- **三类主动赌注**：
  - **固有（Inherent）**：必须承担基准本身的波动，不受经理控制；
  - **有意（Intentional）**：最高预期收益的股票应对应最高边际风险贡献——若是，则组合与信念一致；
  - **附带（Incidental）**：头寸的无意副作用（隐藏的行业/风格暴露）——风险分析负责揪出。
- 表 3.3 示例（MMI vs S&P 500，1992 末）：组合 σ=20.5%、指数 20.1%、**跟踪误差 4.2%**、β=0.96；边际贡献：AT&T 最小（−0.009，最分散化）、IBM 最大（0.074，最集中）。

### 未来：组合构建的设计参数（→ 第 14 章）
### 过去：业绩评价（→ 第 17 章）

## 七、实证检验

两级逻辑：先证**只有标准差可预测**，再证**结构模型优于历史法**。

- **Kahn (1997)**：29 只基金；组合法 vs 三年历史 σ，跟踪一年。组合法意外更少、与次年已实现风险相关性远强；无系统性高/低估（准确 ⇒ 少意外而非零意外）。
- **Kahn & Stefek (1996)**：290 股票基金 + 185 债券基金 + 1160 个股，连续两个五年期。半方差等替代度量的持续性**完全由方差的持续性解释**——方差之外无可预测的风险信息；"分布更宽的组合是否持续更宽"——**否**。

## 八、技术附录要点

### 估计
- **r = Xb + u**；每期**横截面回归**估因子收益（BARRA：~1500 股、65 因子、月度；R² 30–40%，大行情月更高）；
- 行业因子 = 截距（吸收市场收益，波动最大）；风险指数捕捉市场外收益（波动较小）；
- GLS：b = (XᵀΔ⁻¹X)⁻¹XᵀΔ⁻¹r ⇒ **因子收益 = 因子组合收益**（单位暴露目标因子、零暴露其他因子、最小风险；多空、不可投资；多因子版特征组合）；
- F 的预测：历史加权 + 贝叶斯先验；高级：ARCH 族条件方差（Engle 1982）；
- 特有风险：u²_n(t) = S(t)[1+v_n(t)]——S 时序模型，v 横截面多因子模型（含风险指数 + 近期特有收益平方）。

### 分析公式
- x_P = Xᵀh_P；σ²_P = x_PᵀFx_P + h_PᵀΔh_P；主动头寸 h_PA = h_P − h_B；
- **β 分解**：β = Xb + d（因子贡献 + 特有贡献；行业因子通常主导 β）；
- 边际贡献：MCTR = Vh_P/σ_P；MCAR = Vh_PA/ψ_P（可再分市场/残差）；
  - **预告第 5 章：边际残差风险贡献 ∝ alpha，比例常数依赖 IR**；
- 因子级：FMCAR = F·x_PA/ψ_P（近似）；
- 板块层面归因无唯一解（建议按组合总行业权重）；
- 归因：资产 n 占主动风险 = h_PA(n)·MCAR(n)/ψ_P = 相对边际贡献（RMCAR）；
- 应用：β=1、等残差风险时 ρ = σ²_M/(σ²_M+ω²) → **市场波动升则相关性升**（危机时相关性奔向 1 的简化解释）；
- 计算命脉：V⁻¹ = Δ⁻¹ − Δ⁻¹X(XᵀΔ⁻¹X+F⁻¹)⁻¹XᵀΔ⁻¹——N×N 求逆降为 K×K。
