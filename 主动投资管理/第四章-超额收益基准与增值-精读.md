# 第四章 超额收益、基准与增值（Exceptional Return, Benchmarks, and Value Added）· 精读笔记

> 书目：Grinold & Kahn《Active Portfolio Management》
> 范围：Chapter 4，正文第 87–105 页 + 技术附录 106–108 页
> 定位：前三章工具（CAPM 共识、多因子风险模型）合流；从理论迁移到机构实践。核心产出：**增值目标函数 VA**。

## 本章五大结论
1. 预期收益的成分：超额预期收益 = 我们的预测 − 共识；
2. 基准组合是主动经理的标准；
3. **增值 = 预期超额收益 − 主动方差惩罚**；
4. 总风险/收益管理 ≠ 主动风险/收益管理；
5. 基准择时 ≠ 选股。

- 反基准的读者：基准取无风险资产 F 即回到传统总风险框架（一般化）；
- 本章不做：基准选择标准；战略资产配置（SAA）。

---

## 一、基准（Benchmarks）

- S&P 500 也只是世界股票的一部分 → 弃用 market，改用 **benchmark**（别名 bogey / normal portfolio）；
- 制度起源：发起人雇多个专业化经理（债券/被动/成长/价值/小盘…），**基准 = 发起人传达职责与限制的最佳方式**；
  - 例：国际股票经理 → MSCI EAFE；小盘经理 → Russell 2000；澳洲资源股经理 → 资源板块专门指数；
- 实践收益：① 经理专业化、发起人管资产配置；② 聚焦相对表现。

### beta 相对化 ⭐
- β_n = Cov(r_n, r_B)/Var(r_B)——**相对基准**的 beta；残差也变为"对基准的残差"；
- 主动持仓 h_PA = h_P − h_B；主动现金 = −eᵀh_PA；
- **主动方差**：ψ²_P = h_PAᵀVh_PA = σ²_P + σ²_B − 2σ_PB；
- 用基准 beta 重写：**ψ²_P = β²_PA·σ²_B + ω²_P**，β_PA = β_P − 1（主动 beta），ω²_P 残差方差。

---

## 二、预期收益四成分 ⭐

$$E\{R_n\} = \underbrace{1+i_F}_{\text{时间溢价}} + \underbrace{\beta_n\mu_B}_{\text{风险溢价}} + \underbrace{\beta_n\Delta f_B}_{\text{超额基准收益}} + \underbrace{\alpha_n}_{\text{alpha}}$$

| 成分 | 含义 | 备注 |
|---|---|---|
| 时间溢价 i_F | 让渡资金的补偿 | 期初已知 |
| 风险溢价 β_nμ_B | 借自 CAPM；μ_B 用 70+ 年均值 | 股市合理 3–7%/年 |
| 超额基准收益 β_nΔf_B | Δf_B = 近期预期 − 长期共识 | **择时**输入 |
| alpha α_n = E{θ_n} | 预期残差收益 | **选股**能力 |

### 重要组合
- 共识预期超额收益 β_nμ_B → 优化器输出"基准+现金"（consensus in, consensus out）；
- 预期超额收益 f_n = β_nμ_B + β_nΔf_B + α_n；
- **超额预期收益 = β_nΔf_B + α_n = 择时 + 选股 ← 主动管理的钥匙**。

### 分解配方
- Step 1：f_B = Σh_B(n)[E{R_n}−(1+i_F)]；Step 2：Δf_B = f_B − μ_B；
- 表 4.2 示例：i_F=3.16%、μ_B=6%、历史 α/β → 预期收益差异极大（可口可乐 +29.2% vs IBM −12.0%）——历史 alpha 波动大；现金与基准 alpha 恒为零。

## 三、总风险/收益管理及其失败

- 共识下：基准 B 是夏普比率最高的全投资组合；有信息（f≠μ）时 **B 掉下有效前沿**，Q 最优 → 主动管理的几何表达；
- 期望效用：U[P] = f_P − λ_Tσ²_P；
- λ_T 定标：无信息时应选基准 ⇒ **λ_T = μ_B/(2σ²_B)**（μ_B=6%、σ_B=20% ⇒ 0.0075）；
- 允许现金：P = Q 与 F 的混合；最优 beta：

$$\beta_P = 1 + \frac{\Delta f_B}{\mu_B}$$

（主动 beta = 对基准的异见 / 共识预期超额收益）

- **失败** ⭐：λ_T=0.0075 下 MMI 优化组合对机构太激进；问题不在 σ_P 而在 ω_P——"**少量信息 → 极高残差风险**"（预告第 5 章：ω* = IR/(2λ_T)，IR=0.75、λ_T=0.01 ⇒ 37.5%！）。

## 四、聚焦增值：双重标准 ⭐（本章思想精华）

### 业务风险 vs 投资风险
- 谜题：经理坦然接受基准 20% 风险，却拒绝总风险 21%（=20% 基准 + 6.4% 残差）的组合（方差 400→441）；
- 解释：**风险归属不同**——
  - 基准风险由**资金所有者**承担（选择基准时已承担）；
  - 残差风险由**经理**负责；
  - "S&P 500 是涨落所有船的潮水"——区分经理的只有残差收益；高残差风险 ⇒ 大概率掉进业绩榜末尾 ⇒ **被解雇**（业务风险）→ 经理压低残差风险。

### 目标三分解与增值定义
- 固有项：f_B − λ_Tσ²_B（不可控）；
- 择时项：β_PAΔf_B − λ_BTβ²_PAσ²_B；
- 残差项：α_P − λ_Rω²_P；

$$\boxed{VA = \{\beta_{PA}\Delta f_B - \lambda_{BT}\beta_{PA}^2\sigma_B^2\} + \{\alpha_P - \lambda_R\omega_P^2\}}$$

**增值 = 剔除基准贡献后的风险调整预期收益；主动管理的目标 = 最大化 VA。**

## 五、基准择时

- 定义：逐期选择主动 beta；本书聚焦残差（例外：第 18、19 章）；
- 分离理由：① 简化讨论；② "追两只兔子一只也抓不到"（俄罗斯谚语）；③ 第 6 章：择时广度低，难产生增值；
- 最优主动 beta：

$$\beta_{PA} = \frac{\Delta f_B}{2\lambda_{BT}\sigma_B^2}$$

λ_BT 很高或 Δf_B=0 ⇒ 不择时。

---

## 六、主动 vs 残差

- 残差：θ_P = r_P − β_P r_B，ω_P = Std{θ_P}；
- 主动：r_PA = r_P − r_B = θ_P + β_PA r_B；ψ_P = √(ω²_P + β²_PAσ²_B)；
- **β_PA=0（不择时）⇒ 主动 = 残差**——多数机构股票经理如此（理由见第 6 章）。

---

## 七、技术附录：VA 目标推导

- 三分解：h_P = β_P h_B + h_RP；f_P = β_P f_B + α_P；σ²_P = β²_Pσ²_B + ω²_P；
- 代入 β_P = 1+β_PA、Δf_B = f_B − μ_B → 收益四项：
  1. f_B（无能为力）；
  2. β_PA·μ_B（有行动无信息——交叉项）；
  3. β_PA·Δf_B（行动+信息，择时）；
  4. α_P（行动+信息，选股）。
- 方差四项：σ²_B；2β_PAσ²_B；β²_PAσ²_B；ω²_P；
- 从 U = f − λσ² 出发，收益项与方差项**配对**（1+5, 2+6, 3+7, 4+8），引入三种厌恶 λ_T、λ_BT、λ_R：
  - 项 9（f_B − λ_Tσ²_B）：常数，忽略；
  - 项 10（β_PA{μ_B − 2λ_Tσ²_B}）：要求共识预测下选基准 ⇒ 花括号必为零 ⇒ **λ_T = μ_B/(2σ²_B)**；
  - 项 11（择时）+ 项 12（选股）= **VA[P]**。

---

## 八、逻辑骨架

```
基准取代市场（制度产物）→ β 相对化；ψ² = β²_PAσ²_B + ω²
预期收益 = i_F + βμ_B + βΔf_B + α（超额预期收益 = 择时 + 选股）
传统效用 U = f − λ_Tσ²（λ_T=μ_B/2σ²_B）→ 太激进（少量信息→37.5% 残差风险）
根源：双重标准（客户担基准风险/潮水；经理担残差风险/排名）
VA = {β_PAΔf_B − λ_BTβ²_PAσ²_B} + {α_P − λ_Rω²_P} → 最大化
β*_PA = Δf_B/(2λ_BTσ²_B)；不择时 ⇒ 主动 = 残差
```

## 九、习题直觉

- 第 3 题：σ_B=20%、σ_P=21%、β=1 → 残差=主动=**6.4%**（≫"只差 1%"的错觉）；
- 第 5 题：确定性等价 = 6% − 0.0075×400 = **3%**。
