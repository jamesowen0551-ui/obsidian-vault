# 第二章 共识预期收益：资本资产定价模型（Consensus Expected Returns: The CAPM）· 精读笔记

> 书目：Grinold & Kahn《Active Portfolio Management》
> 范围：Chapter 2，正文第 11–40 页（含技术附录 27–38 页）
> 定位：Part One "Foundations" 首章。作用是立标杆——CAPM 是主动管理者必须翻越的共识基准；展示而非辩护。

---

## 〇、本章双重目的

1. **确立谦逊原则**：做成功的主动管理者绝非易事；
2. **化敌为友**：为支持 CAPM 发展的分析工具可掉过头来服务量化主动管理；本书对 CAPM 的使用**与其有效性争论无关**（参见 Black 1993、Grinold 1993，回应 Fama-French 1992 之争）。

**CAPM 最有价值的副产品**：确定**共识预期收益**的程序——共识收益是主动管理的**比较基准**（主动决策 = 我们的预期 − 共识预期）。

### 本章 7 要点
1. 收益可分解为市场成分 + 残差成分，**无需任何理论**；
2. CAPM：残差成分期望为零；
3. CAPM 易懂、易实施；
4. CAPM 背后是市场有效性的强逻辑；
5. CAPM 把举证责任推给主动管理者；被动管理是更低风险的替代；
6. CAPM 提供共识预期——主动成功 = 预测优于 CAPM 共识的程度；
7. **CAPM 是关于预期收益的，不是关于风险的。**

### 替代方案为何不取
- **历史平均收益**：股票池在变、股票自身在变，劣质替代；
- **APT**：留待第 7 章；对主动管理有趣，但不适合当共识来源。

### "共识"的精确定义 ⭐
- CAPM 预期收益输入均值/方差优化器 → 最优组合 = 市场组合 + 无风险资产；
- **最优组合偏离"市场+现金" ⟺ 预测超额收益偏离 CAPM 共识超额收益**；
- "**市场组合就是共识组合，CAPM 给出使市场组合均值/方差最优的那组预期收益。**"

---

## 一、收益的分解

### 构件
- **市场组合 M**：理论上含一切资产；实践用广泛市值加权指数；本章示例用 S&P 500；
- 所有收益为**超额收益**（减无风险收益）。

### Beta

$$\beta_P = \frac{\mathrm{Cov}(r_P, r_M)}{\mathrm{Var}(r_M)} \tag{2.1}$$

- 前瞻性概念；β_M = 1，无风险资产 β = 0；
- 名称来自历史回归：

$$r_P(t) = \alpha_P + \beta_P r_M(t) + \epsilon_P(t) \tag{2.2}$$

- 回归得**历史/已实现** β、α；历史 β 是未来 β 的合理预测，但可做得更好（Rosenberg 1985）。

### 表 2.1：历史 β vs BARRA 预测 β（MMI 成分股，1992.12）
- AT&T：0.96 → 0.69；IBM：0.64 → **1.30**；柯达：0.60 → 0.93；
- 教训：历史 β 与前瞻 β 可以有实质分歧 → 用谁、怎么预测，是现实问题（→ 第 3 章）。

### 分解公式

$$r_P = \beta_P r_M + \theta_P \tag{2.3}$$

θ_P 与 r_M 不相关 ⇒

$$\sigma_P^2 = \beta_P^2\sigma_M^2 + \omega_P^2 \tag{2.4}$$

（ω² = 残差方差）

> **关键**：到此为止**没有 CAPM**。分解不需要任何理论；CAPM 的贡献是聚焦市场并对残差收益说了一个特殊命题。

---

## 二、CAPM 命题

**所有股票与任何组合的预期残差收益为零**：E{θ_P} = 0，故

$$E\{r_P\} = \beta_P E\{r_M\} = \beta_P\mu_M \tag{2.5}$$

- 隐含假设：所有投资者预期相同，仅风险容忍度不同；
- 区分两层：残差收益的**市值加权总和恒为零**（会计恒等式）vs CAPM 额外断言**每只股票**期望残差为零。

---

## 三、CAPM 为什么合理：A / B / C 三个投资者

- A 承担残差风险（相对市场超配/低配）；其他参与者 = B（与 A 等量、头寸正好相反的"对手盘"）+ 巨型 C（持有市场）；
- **A 的残差期望为正 ⇒ B 的必为负**——残差是零和博弈；
- 给一方残差赋予正期望 ≈ **博傻理论（greater fool theory）**；
- 推论：**无信息优势者应持有市场**——"知道自己是傻瓜，就通过不下场保护自己"；
- CAPM 下偏离市场 = 零和游戏：多担风险、无额外预期收益 → 通向被动投资；
- 有效市场三形式（弱式/半强式/强式）与 CAPM 视角互补：只要没有博傻者，偏离市场的双方谁也跑不赢。

---

## 四、预期收益 ⟺ 组合

- 正向：CAPM 收益 → 优化器 → 市场组合；反向：假设市场最优 → 反推出 CAPM 收益；
- **主动管理者按定义不持有共识组合 ⇒ 其预期收益必异于共识。**

---

## 五、事前 vs 事后

- **图 2.1 证券市场线（SML，事前）**：E{r} 对 β 为直线，截距 = i_F，斜率 = μ_M（示例：i_F=5%，μ_M=7%）；
- **图 2.2 "insecurity" 市场线（事后）**：连接无风险收益与已实现市场收益的直线；市场跑输无风险利率时**斜率为负**；组合实际点与线上点之差 = 已实现残差收益；全体股票偏离的市值加权和为零；P₃ 在线上 = 经理本期增值。

## 六、实例：美国运通 vs S&P 500（1988.1–1992.12，60 个月）

| 指标 | 数值 |
|---|---|
| 历史 β | 1.21（标准误 0.24） |
| 已实现残差收益 | −78 bp/月（标准误 96 bp）→ **95% 置信下不显著** |
| 月度残差波动率 | 7.05% |
| R² | 0.31（69% 方差为残差/公司特有风险） |

**教训**：看似 −9%/年的 alpha，噪声大到无法拒绝 alpha=0 → 区分运气与技能极难（→ 第 17 章）。

---

## 七、CAPM 到底有多好用？

- 分解能力取决于 β 预测能力（OK）；"残差期望为零"有争议；
- 对比天真假设：**表现很好**；统计检验下：也不错，只是没那么好；
- 存活 25+ 年 → robust and rugged；
- 真问题："怎样利用 CAPM 的概念为我所用？"——CAPM 忠实信徒做主动管理，"不是精神分裂就是极度玩世不恭"。

---

## 八、对主动管理者的三大帮助 ⭐

1. **聚焦**：举证责任逼你深挖——更不把运气当技能，更快淘汰经不起效率市场检验的点子；
2. **市场/残差分离**：自认无择时能力的经理把 β 控在 1 附近，避免主动市场头寸；
3. **免预测 μ_M**：β=1 时市场超额收益不进入主动收益 → 研究火力全集中于残差预测。

## 九、技术附录：特征组合机器（后续所有附录的数学基石）

### 记号与假设
- **h** 持仓向量；**f** 预期超额收益；**μ** CAPM 共识收益；**V** 协方差矩阵（非奇异）；**β** beta 向量；**e** 全 1 向量；
- 假设：A₁ 存在无风险资产；A₂ 矩存在；A₃ 无零风险全投资组合；A₄ 组合 C 预期超额收益为正（后文放松）；
- 单期、不再平衡。

### 特征组合（Characteristic Portfolios）
- 每个资产属性 **a** 配对唯一组合 h_a：**风险最小且对 a 单位暴露**；

$$\mathbf{h}_a = \frac{\mathbf{V}^{-1}\mathbf{a}}{\mathbf{a}^T\mathbf{V}^{-1}\mathbf{a}} \tag{2A.1}$$

- 性质：σ²_a = 1/(aᵀV⁻¹a)；**所有资产相对 h_a 的 beta = a**（属性↔组合互译的关键）；σ_{a,d} = a_dσ²_a = d_aσ²_d；属性缩放/线性组合 → 组合相应缩放/方差加权组合；
- 特征组合可多空、可高杠杆。

### 三兄弟 C / B / Q + A

| 组合 | 属性 | 含义 |
|---|---|---|
| **C** | e（全 1） | 最小方差全投资组合；所有资产相对 C 的 β=1 |
| **B（基准）** | β | β=1 的最小风险组合（基准=beta 的特征组合） |
| **q** | f | 预期收益的特征组合；**最大夏普比率** |
| **Q** | e_q·f | q 的全投资版（f_C>0 时存在） |
| **A** | α = f − βf | 纯 alpha 组合；与 B 不相关、β_A=0 |

### 夏普比率与命题 2
- SR_P = f_P/σ_P；
- q 使 SR 最大化：SR_q = (fᵀV⁻¹f)^{1/2}；
- **f = Vh_q/σ²_q**（q"解释"预期收益的精确形式）；
- **SR_P = ρ_{P,q} · SR_q** ⭐——任何组合的夏普比率 = 与 q 的相关性 × q 的夏普比率。

### 命题 3（f_C > 0）
- q 净多头；Q = h_q/e_q 全投资且 SR_Q = SR_q；**f = f_Q·β（相对 Q）**——全投资版"预期收益 ∝ beta"。

### 有效前沿
- 前沿组合 = C 与 Q 的加权组合（两基金分离）；
- h_P = w_P h_C + (1−w_P) h_Q；σ²_P = σ²_C + κ(f_P − f_C)²（抛物线）。

### CAPM 定理
- 假设：均值/方差偏好 + 全资产 + 预期一致 + 方差共识 + 无成本无税 ⇒ **Q = M**，即

$$\mathbf{f} = \boldsymbol{\mu} = \beta\mu_M$$

- 证明：人人持有 F 与 Q 的混合（FQF′ 线上）；借贷净额为零 ⇒ 加总 = 市场 M 且 = Q ⇒ M = Q。

## 十、逻辑骨架

```
收益分解（无理论）：r = β·r_M + θ → σ² = β²σ_M² + ω²
 │
CAPM 唯一断言：E{θ} = 0 → E{r} = β·μ_M（SML）
 │
合理性：残差零和（A/B/C）→ 无信息优势就买市场
 │
共识精确含义：市场 = 共识组合；CAPM 收益 ⟺ 使市场最优的收益
 │
实证：远胜天真假设；统计检验尚可；25 年不倒
 │
三份礼物：① 举证责任 ② 市场/残差分离（β→1）③ 免预测 μ_M
 │
附录：特征组合（C/B/Q/A）+ 最大夏普组合 + 两基金分离 + CAPM 定理
```

## 十一、核心公式速查

| 公式 | 含义 |
|---|---|
| β_P = Cov(r_P,r_M)/Var(r_M) | beta 定义 |
| r_P = β_P r_M + θ_P | 收益分解 |
| σ²_P = β²_Pσ²_M + ω²_P | 方差分解 |
| E{r_P} = β_P μ_M | CAPM / SML |
| h_a = V⁻¹a / (aᵀV⁻¹a) | 特征组合 |
| SR_P = ρ_{P,q}·SR_q | 夏普比率分解 |
| f = βμ_M | CAPM 向量形式 |
