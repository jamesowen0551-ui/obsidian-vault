# 第五章 残差风险与残差收益：信息比率（The Information Ratio）· 精读笔记

> 书目：Grinold & Kahn《Active Portfolio Management》
> 范围：Chapter 5，正文第 109–132 页 + 技术附录 134–145 页
> 定位：全书第一个高潮。两个构件——**IR（机会）**与**λ_R（利用机会的意愿）**——给出 ω\* 与 VA\* 的封闭解。

## 开场：荒岛寓言
经济学家打开罐头的方式："假设我们有一把开罐器。"**主动管理者的开罐器 = 假设成功**；成功由信息比率量化——**IR 说的是"你认为自己有多行"**。
本章立场：战略层面，暂不考虑交易成本、约束、流动性、卖空、alpha 来源（实施章节处理）。

---

## 一、Alpha
- 事前：残差收益的预测；事后：已实现残差收益的均值；
- 回归 r_P = α_P + β_P r_B + ε_P 给出历史 α、β；θ_P(t) = α_P + ε_P(t)；
- alpha 有组合性质：α_P = Σh_P(n)α_n；
- **基准中性**：α_B = 0（基准残差恒为零）、α_F = 0 ⇒ "基准+现金"的任何组合 alpha 为零。

## 二、IR 的两种面孔
- **事后（成就）**：IR = 年化残差收益/年化残差风险（例：2.3%/3.45% = 0.67）；可以为负；基准 IR ≡ 0；
- **事前（机会）**：IR = max_P{α_P/ω_P}（隐含信息被高效使用）。

## 三、IR 的通用分布（表 5.1）⭐

| 分位 | IR | 评级 |
|---|---|---|
| 90 | 1.0 | 卓越 exceptional |
| 75 | 0.5 | 好（前 1/4） |
| 50 | 0.0 | 中位（零和 ⇒ 零中心对称） |
| 25 | −0.5 | |
| 10 | −1.0 | |

- "前四分之一 IR=0.5，值得记住"；分级：**0.5 好 / 0.75 很好 / 1.0 卓越**；
- 新经理案例：风险目标 5.5%（争议小）；收益目标是"希望 vs 谦逊"的搏斗（0 太谦逊、10% 太做梦）→ IR≈0.64。

## 四、IR 的性质
- **独立于激进程度**：主动持仓放大 k 倍 ⇒ α 与 ω 同增 k 倍，比值不变（表 5.2，P vs L）；现实中约束会破坏（→ 第 15 章）；
- **随 √T 增长**：统一用年度；季度 IR = 年度/2，月度 ≈ 年度×0.288；
- 用途之一：**给 alpha 定标**（使命 5.6 算出合理 IR）。

## 五、残差前沿与目标
- 残差前沿：**α_P = IR·ω_P**（过原点直线；B 与现金在原点）——主动管理者的**预算约束**；
- 目标（第 4 章）：**VA[P] = α_P − λ_R ω²_P**；等增值线 = 抛物线；VA 即**确定性等价收益**；
- 相切分析（图 5.5）：IR=0.75、λ_R=0.10 ⇒ 最优 VA=1.40%（P\*）。

## 六、核心结果 ⭐⭐

$$\omega^* = \frac{IR}{2\lambda_R} \qquad VA^* = \frac{IR^2}{4\lambda_R}$$

- 机会越大越激进；λ_R 翻倍则 ω\* 减半；
- **增值 ∝ IR²**；
- **人人该选最高 IR 的策略/经理，差异只在实施激进程度**；
- 表 5.3（ω\*）：IR=1/λ=0.05 → 10%；IR=0.5/λ=0.15 → 1.67%；
- 表 5.4（VA\*）：最好 5.00%/年；最差 42bp/年——**好经理+保守实施可能不够付管理费**；
- 反解：λ_R = IR/(2ω\*)（例：0.64/11 = 0.058，激进）。

## 七、β=1 前沿与约束
- 不择时 ⇒ 组合在 **β=1 前沿**（B 为铰链/最小风险 β=1 组合）；
- 全投资前沿上看似有支配 β=1 前沿的组合，但主动风险大 → **业务风险**（第 4 章）；
- 加"无主动现金"约束 ⇒ 过 B 与 Y 的抛物线，机会减少——**约束有代价**。

## 八、直接预测 alpha
- 目的：避免预测最终不影响组合的量（如 μ_B）；
- 五级配方：强买/买/持/卖/强卖 → +2/+1/0/−1/−2% → **基准中性化**（减基准均值×β）→ 无约束时导出 β=1 组合；可按板块分组细化；
- 启示：**alpha 不需激光精度；正确预测难，直接预测不难**。

## 九、实证（Kahn & Rudd 1995/97）
- 股票前 1/4：费前 IR 0.63–0.78、费后 0.48–0.58（标准误 ~0.05；估计误差放宽分布）→ 表 5.1 大致成立；
- 债券：费前类似，**费后惨淡**（Kahn 1998）；
- 主动风险：股票中位 4–5%；债券基金 1.33%、机构 0.61%。

## 十、技术附录要点

### 组合 A（alpha 的特征组合）十性质
1. β_A = 0（纯残差，多空）；
2. IR_A = √(αᵀV⁻¹α) = 最大 IR；
3. ω_A = 1/IR；
4. h_P = β_P h_B + κh_A（κ>0）⇒ IR_P = IR（β 任意）；
5. Q = 基准 + A 的混合 ⇒ IR_Q = IR；
6. e_A ≠ 0 一般（可能净现金）→ 引出 Y；
7. **IR_P = IR·Corr{θ_P, θ_A}**；
8. **IR = SR_Q·(ω_Q/σ_Q)**；
9. **α = IR·MCRR** ⭐——alpha ∝ 边际残差风险贡献，比例常数 = IR（手工组合体检：IR=0.5 时 MCRR 应≈α 的一半）；
10. **SR²_Q = SR²_B + IR²**。

### 命题 2：最优解
- max{hᵀα − λ_R hᵀVRh} ⇒ h_P = β_P h_B + (IR/2λ_R)(h_A/ω_A)；VA\*=IR²/(4λ_R)；ω\*=IR/(2λ_R)。

### 组合 Y（无主动现金、无主动 beta）
- Y = A 与 C 的残差持仓 CR 的组合；β_Y=0、现金为零（多空相抵）；
- **IR_Y = IR·√(1 − Corr²{θ_Q, θ_C})**——约束的代价 = IR 打折；
- 命题 4：β=1 + 全额投资约束下的最优解 h_P = h_B + (IR/2λ_R)h_Y。

### 尺度性质
- 命题 5：IR ∝ √T（各期独立同分布）；
- 命题 6：**IR 对 α 线性**——alpha 太乐观（隐含 IR=2.46）→ 按 η=0.75/2.46 整体缩水再优化。

## 逻辑骨架

```
IR：事后成就 / 事前机会；与激进无关；∝√T；分布 0.5/0.75/1.0
预算约束 α=IR·ω + 目标 VA=α−λ_Rω²
⇒ ω*=IR/(2λ_R)；VA*=IR²/(4λ_R)（人人追最高 IR）
β=1 前沿（B 铰链）；约束版 → 组合 Y（IR 打折 √[1−ρ²]）
直接预测 alpha：五级打分+基准中性化
实证：费前前 1/4 ≈ 0.6–0.8；费后 ~0.5；主动风险股票 4–5%/债券 <1.5%
附录：A 十性质（α=IR·MCRR；SR²_Q=SR²_B+IR²）；IR 线性 → 缩水校正
```
