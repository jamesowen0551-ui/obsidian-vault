# A Macroeconomic Model with a Financial Sector — 详细笔记

> [!abstract] 一句话总结
> 在含金融摩擦的连续时间宏观模型中，**风险是内生的**：净资产-价格反馈环产生放大效应，使经济呈现高度非线性、周期性进入波动区。**"波动率悖论"**——外生风险越低，专家杠杆越高，系统反而越容易爆发系统性波动；证券化改善了个体风险分担却抬高了内生系统性风险。

## 研究问题

标准代表性家庭宏观模型没有金融部门，无法解释危机。继承 Fisher (1933)、Keynes、Minsky、Bernanke-Gertler 传统，本文问：**把"专家（中介）+ 家庭"的借贷结构放进完整均衡动态，会产生什么样的宏观动力学？**

## 模型与核心机制

- **专家（experts）**：管理/持有生产性资产能力更强，但净资产有限 → 向家庭借款（杠杆）。
- **放大环（amplification loop）**：不利冲击 → 专家净资产下降（杠杆放大）→ 抛售资产 → 资产价格下跌 → 净资产进一步下降 → …… 由此产生的资产价格波动被称为**内生风险（endogenous risk）**。
- **非线性**：小冲击时专家可用净资产吸收，放大有限；损失超过阈值后专家被迫减仓，价格-净资产反馈启动 → 波动率陡增。**资产价格的厚尾来自内生系统性风险而非外生稀有事件**（期权市场表现为低波动时期的"波动率微笑偏斜"）。
- **危机中相关性飙升**：现金流冲击是个体的，但价格反馈影响专家持有的**所有**资产 → 危机时截面相关性远高于常态。

## 核心结论

1. **波动率悖论（volatility paradox）**：外生基本面风险越低，专家选择的杠杆越高，系统对系统性波动尖峰的易感性反而上升——"稳定孕育不稳定"（Minsky 的形式化）。
2. **系统周期性偏离稳态是正常的**：无论外生风险多小，经济都会偶发进入远离稳态的波动区；在稳态附近做对数线性化会严重误判系统风险。
3. **证券化的双刃剑**：加入个体冲击后，若专家之间能对冲个体风险（证券化、CDS、银投行整合、复杂中介链），个体约束放松 → **杠杆上升 → 系统更不稳定**。证券化降低了个体冲击成本和利差，却在均衡中放大系统性风险。
4. **外部性与低效率**：金钱外部性（pecuniary externality）——个体把价格当给定，集体却改变价格；专家不维持充足资本缓冲，互相施加负外部性 → 均衡资本不足。
5. 历史维度：Kindleberger 统计西欧四百年金融危机约每 10 年一次；央行+存款保险+资本监管后频率下降，但本轮危机再次凸显。

## 对"美国实际利率"研究的含义

1. **实际利率的内生波动成分**：均衡利率与风险溢价随金融部门净资产状态大幅波动——低实际利率可能既是"储蓄过剩"也是"杠杆过高"的表象。
2. **"大缓和"与低利率的共生**：波动率悖论提示，低宏观波动（大缓和）+ 低利率环境鼓励加杠杆，埋下危机种子——危机后实际利率进一步塌陷（零下限），与 [[Summers_2014_详细笔记|长期停滞]]叙事互补。
3. **QE/金融条件渠道**：央行压低利率 → 杠杆上升 → 内生风险累积——评估宽松政策时需计入内生风险成本。

## 局限

- 定性机制强、定量校准弱；无名义刚性与货币政策细则。
- 专家/家庭二分抽象掉银行体系细节。
