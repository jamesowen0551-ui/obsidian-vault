# Liquidity and Leverage — 详细笔记

> [!abstract] 一句话总结
> 在盯市（mark-to-market）会计下，资产价格变动立即变成净资产变动，金融中介随之主动调整资产负债表规模——**中介杠杆强烈顺周期**。**总流动性可定义为中介总资产负债表的增长率**；交易商 repo（资产负债表调整的主要边际）的变化能预测 VIX 所衡量的金融市场风险变化。

## 研究问题

金融中介的资产负债表如何随资产价格调整？这种微观调整加总后对"金融市场流动性"和"金融周期"意味着什么？

## 核心发现

1. **杠杆顺周期性**：盯市杠杆（资产/净资产）与资产负债表规模正相关——资产价格上涨 → 净资产上升 → 杠杆反而上升（扩表）；下跌时被迫去杠杆（缩表）。这与家庭"逆周期杠杆"（被动效应）形成对照，是主动管理的结果。
2. **资产负债表调整的主要边际是 repo**：证券交易商通过回购协议扩张/收缩资产负债表；**交易商 repo 变化预测 VIX 创新的变化**——资产负债表扩张先于风险偏好/波动率变化。
3. **总流动性的新定义**：Aggregate liquidity = 金融中介总资产负债表的增长率。流动性不是货币的存量的概念，而是**资产负债表扩张的速率**——把"流动性"从货币总量转向金融部门资产负债表容量。
4. 金融周期的实证基础：杠杆周期、资产负债表周期与风险溢价周期同步，为"金融周期"文献奠基。

## 对"美国实际利率"研究的含义

1. **短端利率 → 资产负债表 → 风险溢价的传导链**：政策利率变化改变中介融资成本与扩表空间，进而改变期限溢价与风险溢价——实际利率传导不只经储蓄-投资，也经金融部门资产负债表。
2. **流动性螺旋与危机期利率**：缩表去杠杆 → 抛售 → 价格下跌 → 进一步缩表；危机期安全资产利率被避险与流动性需求双重压低（衔接 [[DKW_2018_TIPS_详细笔记|TIPS 流动性溢价]]）。
3. 为 [[Brunnermeier_Sannikov_2014_详细笔记|B-S (2014)]]、[[He_Krishnamurthy_2013_详细笔记|H-K (2013)]] 提供微观实证基础。
